# 論文スキル（Academic Research Skills）導入メモ

Claudeで論文を書く人向けの大型スキル集。
本家：https://github.com/Imbad0202/academic-research-skills

やれること（research → write → review → revise → finalize の5段階）：
1. **Deep research** … arXiv / Semantic Scholar / DBLP などを横断して関連研究を集める
2. **Drafting** … 論文を「章ごと（section by section）」に書き進める
3. **Integrity check** … 引用やデータを検証する
4. **Peer review** … 5人ぶんの査読＋反対意見役（Devil's Advocate）で自分の文章を壊しにくる
5. **Export** … APA / IEEE / Chicago / MLA / Vancouver 形式に整える

> Xで polydao さんが紹介していたものは、これで合っています。

---

## なぜAIが代わりに入れてくれないの？

インストールは `/plugin ...` という**スラッシュコマンド**（あなたが入力欄に打つ専用コマンド）。
AIエージェントの側からは実行できない仕組みです。**下の手順は自分の手で**実行してください。
コマンドは2行だけなので、コピペすれば大丈夫です。

おすすめは**自分のパソコンのClaude Code（ローカル版）**で入れること。
Web版（ブラウザ）は使い捨て環境なので、入れても終了すると消えます。

## 事前準備

1. Claude Code を**最新版**にしておく（古いとプラグインが動かない）。
   ```bash
   claude --version
   ```
2. `ANTHROPIC_API_KEY` を用意して設定する。
   （Anthropicのサイトで取得した鍵を、最初の `claude` 起動時に入力すればOK）
3. （任意）出力形式を増やしたい人だけ：
   - Word(DOCX)で出したい → **Pandoc** を入れる
   - APA 7.0 のPDFを出したい → **Tectonic + Source Han Serif TC** を入れる
   - ※ Markdown（テキスト）で良ければ、この任意ツールは不要

---

## インストール手順（Claude Codeの入力欄で実行）

```text
/plugin marketplace add Imbad0202/academic-research-skills
/plugin install academic-research-skills
```

- 1行目：配布元（マーケットプレイス）を登録
- 2行目：スキル本体をインストール

---

## 入れたあとの使い方（最初の一歩）

迷ったらこれ。質問に答えていくと論文の骨組みを一緒に作ってくれる：
```text
/ars-plan
```

そのほかの入り口：
- `/ars-lit-review "調べたいテーマ"` … 関連研究をまとめて調査
- `/ars-research` … 研究パイプライン全体を開始
- `/ars-write` … 執筆を始める
- `/ars-review` … 既にある論文を査読してもらう
