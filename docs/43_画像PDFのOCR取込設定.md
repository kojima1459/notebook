> **この文書は誰向けか**: スキャンした資料(画像として保存されたPDF)を本棚に入れたい**利用者・保守担当**向けです。
> **何が分かるか**: 画像PDFをAIに読ませる(OCR)ための準備と、かかる時間・コストの目安、うまくいかないときの見分け方が分かります。

---

## 0. これは何の話か

紙をスキャンしたPDFや、画像を貼り付けただけのPDFは、**中に文字のデータが入っていません**。
そのまま本棚に追加しても「このPDFは画像として保存されていて、そのままでは文字を読み取れませんでした」と表示され、
マイ本棚のカードには 🖼 のしるしが付きます。

このツールは、この種のPDFを **1ページずつ画像にしてAIに読ませ(OCR)、本棚に取り込めます**。
そのために **Ghostscript**(ゴーストスクリプト。PDFを画像に変換する道具)を使いますが、
**配布物にあらかじめ同梱されている**ため、利用者側での準備は基本的に不要です。

---

## 1. 準備(通常は不要)

**リポジトリのZIPをダウンロード→解凍→`dist` フォルダの中の `.xlsm` を開くだけ**で使えます。
`dist` フォルダの中には、開く `.xlsm` の隣に `Ghostscript` フォルダ(`gswin32c.exe` 等一式)が
最初から並んでいて、起動時に自動的に見つけて使います。

```
（解凍した状態の例）
dist\
    ├── MyBookshelf.xlsm     ← これを開く
    └── Ghostscript\         ← 同梱済み(何もしなくてよい)
            ├── gswin32c.exe
            ├── gsdll32.dll
            ├── LICENSE.txt
            └── README.txt
```

あわせて、`config` シートの **`feature_vision` が `TRUE`** になっていることを確認してください(初期値はTRUEです)。

### 1-1. 「Ghostscript が見つかりません」という案内が出たら

`Ghostscript` フォルダを`.xlsm`の隣から動かした・削除した等でGhostscriptが見つからない場合だけ、
赤いエラーではなく **丁寧な案内カード**(1回だけ)が出ます。
「フォルダを選ぶ」の案内でOKを押すとフォルダ選択画面が開くので、`Ghostscript` フォルダ
(または `gswin32c.exe` が入っている `bin` フォルダの1つ上)を選んでください。
見つかれば `config` の `ghostscript_path` に自動で保存され、そのまま処理が続きます。

**手動で設定したい場合**は、`config` シートの `ghostscript_path` に `gswin32c.exe` のフルパスを
直接入れても構いません(例: `C:\Tools\Ghostscript\gswin32c.exe`)。こちらが設定されていれば最優先で使われます。

> `config` シートの出し方: シート見出しを右クリック →「再表示」→ `config` を選ぶ。
> 変更したら上書き保存してください。

---

## 2. 使い方

準備が終わったら、**普通の資料と同じ**です。
ナレッジ画面の「📄 資料を追加」から画像PDFを選ぶ(またはフォルダ同期に任せる)だけで、
「🖼 PDFを画像に変換しています…」「🖼 OCR中… 3/12 ページ」のように進み、読み取れた本文が本棚に入ります。

取り込めたページは、質問したときの出典に **元のページ番号** で出ます(「p.7」など)。

---

## 3. 時間とコストの目安(だいじ)

**1ページ = AIを1回呼び出します。** 20ページのPDFなら20回です。
普通のテキストPDFの取込(AIの呼び出しは埋め込みのみ)に比べると、時間もコストもはっきり増えます。

| 項目 | 既定値 | 変えたいとき |
|---|---|---|
| 読み取るページ数の上限 | 先頭 **20ページ** | `config` の `vision_pdf_max_pages` |
| ページ画像の解像度 | **150** dpi | `config` の `vision_pdf_dpi`(300にすると処理時間は約2倍) |
| **処理が止まった**と見なすまでの時間(本文抽出) | **120秒** | `config` の `vision_pdf_timeout_sec` |
| 待ち時間そのものの絶対上限 | **1200秒**(20分) | `config` の `gs_abs_timeout_sec` |

- 上限を超えた分は取り込まれません。その資料は **⏳(一部だけ完了)** の表示になります。
  全部入れたい場合は `vision_pdf_max_pages` を大きくしてから、もう一度追加してください。
- **分厚い資料をまるごと入れる前に、まず数ページのPDFで試す**ことをおすすめします。
- 文字が小さくて読み取り漏れが多いときだけ `vision_pdf_dpi` を 300 にしてください。
  150 で読めているうちは上げる必要はありません。
- `vision_pdf_timeout_sec` は**「120秒で打ち切る」ではありません**。**進捗が観測できる
  場合は**ページが1枚でも進んでいるあいだ待ち続け、**まったく進まなくなってから**
  この秒数で見切ります(2026-08-03に意味を変更)。
  それでも終わらない場合の最後の壁が `gs_abs_timeout_sec`(**絶対上限・既定1200秒**)で、
  進んでいても必ずここで打ち切ります。数百ページの資料を入れるときだけ大きくしてください。
- **OCR経路(画像PDFをページ画像にする待ち)は、`gs_abs_timeout_sec`(絶対上限)だけを
  使います**。この経路は途中経過を見ていないため、無進捗の許容秒数を壁にすると
  分厚いスキャン資料が処理の途中で切られてしまうからです(2026-08-03)。
- 待っているあいだは画面のバナーに「本文抽出中… 12/44ページ (経過 35秒)」のように
  今どこまで進んだかが出ます。ただし端末によっては Ghostscript の途中経過が
  こちらから見えないことがあり、その場合は経過秒だけの表示になります。

## 3-1. テキストPDFについて

Ghostscriptはテキストが含まれたPDF(Word等から出力されたもの)も読み取ります。このような**テキストPDF**は、Word で開く必要はなく、自動的にGhostscriptで抽出されます。スキャン資料など**文字の無い画像PDF**の場合だけが、自動でOCR経路へ回ります。

## 4. うまくいかないときの見分け方

マイ本棚のカードのメモ、または追加したときのメッセージに、次のどれかが出ます。

| 出たメッセージ | 意味 | どうすればよいか |
|---|---|---|
| Ghostscript が見つかりませんでした | 道具が見つからない(通常は同梱済み) | `Ghostscript` フォルダが`.xlsm`の隣にあるか確認する。案内カードが出たら「1-1」の手順でフォルダを選ぶ |
| 画像解析機能が有効なときだけ使えます | `feature_vision` が FALSE | `config` の `feature_vision` を `TRUE` にして開き直す |
| ページ画像を作れませんでした | PDFが壊れている/パスワード保護 | PDFを開けるか確認する。保護されている場合は解除したものを用意する |
| ○秒以内に終わりませんでした | 変換に時間がかかりすぎた | ページ数を減らして分割する。または `gs_abs_timeout_sec` を大きくする(OCR経路の壁は絶対上限です) |
| 進まなくなりました(○ページ中○ページまで) | 処理が途中で固まった | どこまで進んだかがメッセージに出る。そのページ付近が壊れていないか確認する。または `vision_pdf_timeout_sec` を大きくする |
| 文字を読み取れませんでした | 画像は作れたがAIが読めなかった | 時間を置いて再実行する。それでも駄目なら解像度(`vision_pdf_dpi`)を上げてみる |
| mockモードでは利用できません | 動作確認用のビルド | `config` の `mock_llm` を `FALSE` にする(配布版は最初からFALSEです) |

**急ぐときの回避策**: 1ページだけ欲しいなら、その画面をコピー(Win+Shift+S)して、
ナレッジ画面の「📸 スクショ取込」から入れるのが一番早いです(準備不要)。

### 4-1. zipファイルを展開するときの注意

GitHub の「Code → Download ZIP」で取得したzipファイルを使う場合:

- **zipの中から直接 MyBookshelf.xlsm を開かないでください**。先に「右クリック → [すべて展開]」でフォルダ全体を展開し、展開先の `dist\MyBookshelf.xlsm` を開いてください。

### 4-2. セキュリティでブロックされた場合

Windowsが「インターネットからダウンロードしたファイル」とマークした場合、ファイルがブロックされることがあります。

**対処手順:**
1. zipファイルを右クリック → **[プロパティ]** を開く
2. 下部の **[許可する]** にチェックを入れる(Mark of the Web の解除)
3. **[OK]** をクリック
4. その後、zipを右クリック → [すべて展開] で展開

## 5. 保守担当向けメモ

- Ghostscript(10.03.1 Windows 32bit・AGPL)は `dist/Ghostscript/` に **常置**でコミットしてある
  (`gswin32c.exe` + `gsdll32.dll` + `LICENSE.txt` + `README.txt`)。GitHubの
  「Code → Download ZIP」で取得したものをそのまま解凍すれば、`dist/` 内の `.xlsm` の隣に
  Ghostscriptが並ぶ状態になる(2026-07-31 R9)。`dist/Ghostscript/` はビルドスクリプトが
  一切触らないフォルダなので、ビルドを何度実行しても消えたり上書きされたりしない。
- `ResolveGsExe`(`src/opt/optVision.bas`)の解決順は次の4段階:
  1. `config` `ghostscript_path`(明示フルパス)
  2. 同梱(`ThisWorkbook.Path & "\Ghostscript\gswin32c.exe"`)
  3. `config` `ghostscript_search_dirs`(セミコロン区切り。IT部門が社内の標準配置先を
     焼き込んでおく用途。各フォルダの直下と `bin\` 直下の両方を探す)
  4. どれでも見つからない場合だけ、1回きりの案内カード→フォルダ選択→
     見つかれば `ghostscript_path` へ自動保存して続行
  候補パスの組み立て(優先順位・空要素スキップ・末尾`\`の正規化)は
  `src/opt/optOcrCore.bas` の `GsCandidatePaths` / `GsCandidatesForFolder`(純ロジック・
  境界値テストは `src/test/modTestsPure5.bas`)に切り出してある。
- 変換は **非同期で起動し、完了フラグファイルの出現を監視**しています。壊れたPDFでExcelが永久に固まることはありません
  (タイムアウトしたらその資料だけ失敗になります)。一時ファイルは成功・失敗のどちらでも削除します。
- 実装は `src/opt/optVision.bas`(取込本体)と `src/opt/optOcrCore.bas`(コマンド組み立ての純ロジック)にあります。
  取込フロー側の入口は `src/ingest/modShelfVision.bas` です。
- Wordのリフローが文字化けだけを返すPDF(全ページ化け判定)も、自動的にこのOCR経路へ回ります
  (`usage_log` に `extract_garbled_ocr_route` の行が残ります)。
- 大規模配布(社内へまとめて配る等)には `python3 build/build_mybookshelf.py --prod --zip` で
  `dist/MyBookshelf_配布.zip`(`.xlsm` + `Ghostscript/` 一式)をワンコマンドで梱包できる。
  手順の詳細は `docs/30_運用保守ガイド.md` を参照。
