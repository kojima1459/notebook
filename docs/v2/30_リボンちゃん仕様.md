# 社内AIリボン「リボンちゃん」仕様メモ（ver202606 解析）

> このボットが相乗りしている社内アドインの仕様。横展開・別ツール開発の土台になるので残す。
> ※ アドイン本体のソースは社内資産。ここは**外部から呼ぶために必要な範囲**の仕様だけを記録する。

---

## 1. 何ができるアドインか

社内に全社配布されている Excel/Word/PowerPoint 用の AI アドイン。
内部で **Azure OpenAI** に接続し、ユーザー定義関数として AI 機能を提供する。
我々のボットはこのアドインの関数を `Application.Run(...)` で呼ぶだけ。

接続先：`hd-us-e2-openai.openai.azure.com`（Azure OpenAI、East US 2）

---

## 2. 使っている関数

### 2-1. `ChatGPT(...)` — チャット補完
```
ChatGPT(text, [roleSystem], [Temperature], [MaxTokens], [Wait],
        [optModel], [prevU], [prevA], [toolN], [reasoning_effort], [verbosity])
```
| 引数 | 意味 |
|---|---|
| text | 主入力 |
| roleSystem | システムメッセージ（役割設定） |
| Temperature | 乱数性（**GPT-5系は無視**） |
| MaxTokens | 最大トークン |
| Wait | 応答待ち最大秒。モデルにより自動延長（gpt-5.5 は最大1200秒） |
| optModel | モデル名（後述。空なら既定） |
| prevU / prevA | 直前のユーザー/アシスタント発話（`;;;`区切りで複数） |
| toolN | ログ用ラベルのみ（**機能には影響しない**） |
| reasoning_effort | GPT-5系の推論深度（minimal/low/medium/high） |
| verbosity | GPT-5系の応答長（low/medium/high） |

> **重要：このアドインに Web 検索機能はない。** ペイロードに `web_search`/`tools`/`tool_choice` は一切なく、
> `toolN` は単なるログラベル。「toolsでWeb検索を要求できない」という同僚の指摘は正しい。

### 2-2. `GetEmbeddings(text)` — 埋め込み
```
GetEmbeddings(text) As String
  成功 → "0.013,-0.02,..."（カンマ連結の1536次元・L2正規化済み）
  失敗 → 文字列 "error"（HTTP 200以外。例外は投げず "error" を返す）
```
- モデル：`text-embedding-3-small`（Azureデプロイ名 `text-embedding-3-small-g`）
- L2正規化済み → コサイン類似度＝内積。
- 我々は `modEmbeddings` を**唯一の窓口**にして、空入力を送らない・"error"を検知・例外を握りつぶす、という防御を全部ここに集約している。

## 3. 利用可能モデル（＝Azureデプロイメント名）

`ChatGPT` のURLが `/openai/deployments/<名前>/...` の形なので、
**デプロイ名＝モデル名そのまま**で登録されていることが分かる（この一覧はデプロイ一覧として確定）。

```
chat系: gpt-4o, gpt-4o-mini, gpt-4.1(/mini/nano), o1, o3, o3-mini, o3-pro, o4-mini,
        gpt-5(/mini/nano/chat), gpt-5.1(/chat), gpt-5.2(/chat), gpt-5.3-chat,
        gpt-5.4(/mini/nano/pro), gpt-5.5, gpt-5.5-pro
embeddings: text-embedding-3-small-g
```

> **例外：codex系**（`codex-mini`, `gpt-5.1-codex(-mini/-max)`, `gpt-5.2-codex`, `gpt-5.3-codex`）は
> `/openai/v1/responses` エンドポイントを使い、`/deployments/` を含まない。
> このタイプはコード上からデプロイ名が確認できず、実際に叩くまで可否は不明。

このボットの既定モデルは **GPT-5.5**（config の `recommended_model`／`*_model` で指定。コード変更不要で切替可）。

## 4. セキュリティ上の申し送り（情シス向け）

> ⚠️ **APIキーがアドイン内にハードコードされている**（環境変数ではない）。
> - 場所：アドインの `GPT.bas`（`Public apiKey As String`）に32箇所、`Embeddings.bas` に1箇所、同一リテラルで直書き。
> - リスク：.xlam は VBA エディタを開けば誰でも読める。1本のキーで上記全モデルを外部から叩ける。
> - 推奨：①キーをローテーション ②`Environ("...")` 参照に集約 ③配布管理の見直し。
> - **キーの実値はこのリポジトリには記載しない**（git履歴に残すと別の漏洩経路になるため）。実値は別途口頭/チャットで情シスへ。

> 我々のボット側にはキーは一切持たない（リボン相乗りのため）。この懸念はアドイン側の話。
