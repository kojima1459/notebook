## 1. ホーム画面

質問する画面です。タブ「ホーム」を開くと表示されます。

| 部品 | 説明 |
|---|---|
| ❓ 使い方 | 「使い方」タブに切り替える |
| 🩺 診断 | 今の状態を一覧表示する(困ったときはまずこれ)。診断レポートの冒頭に[設定サマリー]として、AIモデル名・自動同期間隔・本棚フォルダなどの現在値が表示される |
| ⚡ すぐ聞く (10〜20秒) / 🔍 しっかり調べる (1〜2分) | 回答の速さ・丁寧さを切り替えるトグル(詳しくは§4) |
| 質問入力欄 | 「質問をここに入力してください(例: 〇〇の手続きに必要な書類は?)」に質問を書く。サイドバーの「質問テンプレチップ」を押すと、「【知りたい改定】: (資料名や年度を記入)」のような穴埋めテンプレートがここに自動入力される。空白部分(ここに記入)を埋めてから送信する |
| 💬 質 問 す る | 質問を実行する |
| 状態表示 | 🔍検索中… → ✍️回答作成中… のように進行状況が出る |
| 回答欄 | AIの回答が表示される。本棚の資料との関連度が低い場合(既定値: 0.3未満)、回答の先頭に「⚠️ 手元の資料との関連が薄い可能性があります」と警告が付く |
| 📖 この回答のもと | 回答の根拠になった資料名とページ番号(出典) |
| 🟢 解決した! / 🟡 ヒントになった / 🔴 だめだった | 回答への感想ボタン。押すとダッシュボードの記録に反映される |
| 💬 続けて質問 | 前回までのやり取りを踏まえた続きの質問ができる(詳しくは§10) |
| 📝 Wordで開く | 回答を指定した文書スタイルに整えてWordで開く(詳しくは§10) |
| 💡 豆知識 | 待ち時間に表示される小さなヒント |

本棚に資料が1件も無いときは、回答欄に「まだ本棚に資料がありません。まず『マイ本棚』タブで資料を1つ追加してみましょう →」という案内が常に出ます。

## 2. マイ本棚画面

資料を追加・整理する画面です。タブ「マイ本棚」を開くと表示されます。

### 上部のボタン

| ボタン | できること |
|---|---|
| ＋ 資料を追加 | ファイル選択ダイアログで資料を1件以上まとめて追加する |
| 🔄 フォルダと同期 | 「本棚フォルダ」の中身と本棚を今すぐ突き合わせる(詳しくは§5) |
| 📦 パックにして渡す | 本棚(または1件)を他の人に渡せる形式で書き出す(詳しくは§6) |
| 📥 パックを取り込む | 誰かが作った「パック」を自分の本棚に取り込む(詳しくは§6) |
| 🗑 選んだ資料を削除 | クリックした行の資料を本棚から削除する |
| 📸 スクショ取込 | コピーした画面(スクリーンショット)をAIが文字起こしして本棚に追加する(詳しくは§9) |

削除するときは、削除したい資料カードの行をクリックしてから 🗑 ボタンを押してください。行を選んでいないと「削除したい資料の行をクリックしてから、もう一度押してください。」と案内が出ます。確認ダイアログ「『(資料名)』を本棚から削除しますか? この操作は取り消せません。」で「はい」を押すと削除されます。

### 本棚フォルダ

「📁 フォルダを選ぶ」でパソコン内のフォルダを1つ指定すると、「ここにファイルを入れておくと、自動で本棚に追加されます(消せば本棚からも消えます)」のとおり、**フォルダに入れれば本棚に入り、フォルダから消せば本棚からも消えます**。詳しくは§5を参照してください。

### 資料カード(状態アイコン)

| アイコン | 意味 |
|---|---|
| ✅ | 取込・変換が完了(質問に使える) |
| ⏳ | 変換中、または一部だけ変換未完了(そのうち完了する/🔄同期で再開) |
| ⚠️ | 取込に失敗した(理由がメモ欄に表示される) |
| 🖼 | 画像として保存されたPDFのため、文字を取り込めなかった |
| 🕒 | 元のファイルが見つからない(フォルダから削除・移動された可能性) |

### 資料の自動整理(AIによる要約・キーワード付け)

資料カードが✅(取込完了)になったあとも、裏側では**AIが少しずつ資料を整理しています**。
これは検索の精度を上げるための下ごしらえで、質問には影響しません(整理が終わっていなくても
質問はいつもどおりできます)。

- **何をしているか**: 各資料のかたまり(チャンク)ごとに要約とキーワードを作り、
  さらに用語の書き方のゆれ(「回収」「リコール」のように、意味は同じでも書き方が
  違う語)を辞書としてまとめます。あとで書き方が違う質問をしても、この辞書のおかげで
  該当資料が見つかりやすくなります。
- **いつ動くか**: 資料を取り込んだ直後に少しだけ、残りは「🔄フォルダと同期」のたびに
  少しずつ追いつきます(一度に全部を処理して長時間待たされることはありません)。
  操作の妨げにはならず、進捗バナーには出ません。
- **やめたい場合**: 管理者向けの設定ですが、config シートの `enrich_mode` を `off` に
  すると要約・キーワード付けをしなくなり、`graph_synonyms` を `off` にすると
  書き方のゆれを吸収する辞書を使わなくなります(詳しくは
  [30_運用保守ガイド.md](30_運用保守ガイド.md) を参照)。

## 3. ダッシュボード画面

自分の利用状況を振り返る画面です。操作ボタンはなく、見るだけです。

- **今月の質問数**: 今月「質問する」を実行した回数
- **🟢 自己解決した回数**: 「🟢解決した!」を押した回数の累計
- **節約した時間**: 自己解決1件を15分換算で見積もった、AI活用で浮いた時間の目安
- **本棚の資料数**: 現在本棚にある資料の件数
- **🏅 バッジ**: 獲得済みは色付きで日付入り、未獲得は🔒アイコン付き・灰色で獲得条件が表示される(一覧は§7)
- **📈 本棚の育ちぐあい**: 現在の資料数を棒(■)で表示(過去の推移ではなく「今の量」を示す簡易表示です)

## 4. 2速モードの使い分け

ホーム画面上部のトグルで切り替えます。

| モード | 目安時間 | 向いている場面 |
|---|---|---|
| ⚡ すぐ聞く | 10〜20秒 | ちょっと確認したい・急いでいる |
| 🔍 しっかり調べる | 1〜2分 | 正確さが重要・下書き+検証の2段階で確認してから回答する |

| 🔬 入念に調べる | 2〜4分 | 資料をまたぐ複雑な質問・そのまま社内へ出す回答をつくるとき |

「🔍しっかり調べる」は下書きを作ったあとにもう一度AIが内容を検証してから返すため、少し時間がかかりますが、より丁寧な回答になります。

### 🔬 入念に調べる でできること

いちばん時間はかかりますが、ふつうに聞くだけでは届かないところまで調べます。

- **複数の論点を含む質問は、自動で論点ごとに調べて1つにまとめます。**
  「AとBの違いと、Cの申請手続きは?」のように複数のことを一度に聞いた場合、
  論点ごとに別々に資料を探してから統合するので、どの論点も「薄い答え」になりません。
  回答は **■見出し** で論点ごとに分かれて表示されます。
- **質問の読み方がいくつもあるときは、番号の選択肢で聞き返します。**
  「解約について教えて」のように幅の広い質問には、いきなり答えを作らず
  「1) 解約手続きの流れ 2) 解約金の計算 3) 解約後の補償」のような選択肢が出ます。
  **「1」** や **「1と3」** のように番号だけを送れば、その読み方で調べ直します
  (複数選ぶと、両方を論点として調べます)。もちろん番号を使わず、
  ご自身の言葉で質問を書き直していただいても構いません。
- **「全部教えて」型の質問には、章をまたいで俯瞰した回答を返します。**
  「この規程を全部教えて」「全体像は?」のように一覧を求める質問では、
  資料の**章ごとの要約**からまず読むべき章を選び、その章の本文をまとめて読んで
  ■見出しつきで整理します(章の要約は資料を取り込むときに作られます。
  章立てのある資料を取り込み直すと効くようになります)。
- **根拠にした箇所の前後もあわせて読みます。**
  表の見出しと数値、条文と但し書きのように、意味のまとまりがページやブロックを
  またぐ資料でも「書いてあるのに見つけられない」が起きにくくなります。
- **「💬 続けて質問」での深掘りは、前回と重複しない深さへ進みます。**
  2回目・3回目の深掘りでは、前回すでに読んだ箇所を後ろに回して新しい箇所を優先し、
  「前回と同じ説明の言い換え」が返りにくくしています。

**複合質問の自動分解・番号選択肢での聞き返し・俯瞰の回答は、🔬入念に調べる だけの機能です。**
⚡すぐ聞く・🔍しっかり調べる では、複数の論点を含む質問も1本のまま検索されます
(論点ごとに薄い答えになりやすい点にご注意ください)。短くても「免責は?保険料は?」
のように？が続く質問・句点で区切られた複数の質問文は、入念モードなら文字数が
短くても自動で分解対象になります。

## 5. 本棚フォルダ同期

「マイ本棚」タブの「📁 フォルダを選ぶ」でフォルダを指定すると、そのフォルダの中身と本棚が同期されます。

- **フォルダに入れれば本棚に入る**: 対応形式のファイルをフォルダに置くと、次の同期で自動的に取り込まれます
- **消せば本棚からも消える**: フォルダからファイルを削除すると、次の同期で本棚からも削除されます
- **更新すれば置き換わる**: 同じファイル名で内容を更新すると、自動的に新しい内容に置き換わります(重複しません)
- サブフォルダの中までは見ません(フォルダ直下のファイルだけが対象です)

同期は次のタイミングで行われます。

1. 手動: 「🔄 フォルダと同期」ボタンを押したとき
   - **スキャンPDF(画像PDF)が含まれていると、取り込む前に確認が出ます**: 読み取りに時間がかかると見込まれる資料は1件ごとに「全N頁のスキャンPDFです。推定約M分かかります。取り込みますか?」と確認します(「いいえ」を選んだ資料は見送りとして記録され、失敗にはなりません)
   - 「はい」を選んだ直後に一度だけ「先に作業用Excelを開いてから開始しますか?」と聞かれます。**この質問はExcelを開いている間に1回だけ**で、2件目以降では出ません(すでに作業用Excelを開いている場合も出ません)
   - 上限見送りなし(すべてのファイルが無事に取り込まれた)の場合: 状態表示行とステータスバーに「✅ 同期が完了しました(○件の変更)」と表示されるだけで、完了時のダイアログは出ません
   - 上限見送りがあった場合(ファイルサイズやAPI呼び出し上限に達した等): 従来どおり「△件をスキップしました」という確認ダイアログが表示されます
2. 自動: ブックを開いたとき、および設定された間隔(config `sync_interval_min`)ごと(バックグラウンドで静かに実行され、ポップアップは出ません)

同期フォルダが見つからない場合(削除・リネームなど)は、対象の資料が🕒(見つからない)表示になります。フォルダが元に戻れば、次回の同期で自動的に復帰します。

## 6. パックの渡し方・受け取り方

「パック」とは、本棚の資料をひとまとめにした受け渡し用ファイル(.xlsx)です。承認なしで同僚と資料を共有できます。

### 渡す(書き出す)

1. 「マイ本棚」タブで「📦 パックにして渡す」を押す
2. 「本棚全体をパックにして書き出しますか?」で選ぶ
   - 「はい」: 本棚全体を書き出す
   - 「いいえ」: クリックしていた行の資料1件だけを書き出す
   - 「キャンセル」: 何もしない
3. 個人情報らしき内容が見つかった場合は件数と例が表示され、続けるかどうか確認されます(止まるわけではなく、内容を見て判断できます)
4. 保存先を選ぶと、`パック_(資料名または本棚全体)_(日付).xlsx` という名前で保存されます
5. 完了すると「パックを書き出しました。○件の資料を「(ファイル名)」として保存しました。」と表示されます

### 受け取る(取り込む)

1. 「マイ本棚」タブで「📥 パックを取り込む」を押す
2. 受け取った .xlsx ファイルを選ぶ
3. 完了すると「○件取込 / ○件は既にありました。」と表示されます(自分の本棚に無い内容だけが追加されます。重複は自動でスキップされます)

パックの作成者名は、初回起動時に入力した名前が使われます(「📖 この回答のもと」欄では `ファイル名 p.ページ（パック: 作成者名）` のように、パック由来の資料だけカッコ書きで作成者名が付きます。なお回答本文中でAIが引用元を示す際は `[パック(作成者名):ファイル名]` という角括弧書式が使われます)。

## 8. チャット履歴

質問と回答の履歴が自動で記録される、見える形のシートです。

### チャット履歴シートについて

ホーム画面で質問するたびに、次の情報が自動的に「チャット履歴」シートに記録されます。

| 列 | 内容 | 説明 |
|---|---|---|
| A | 質問 | あなたが質問した内容 |
| B | 回答 | AIが返した回答 |
| C | 日時 | 質問した日時 |
| D | モード | 質問したときのモード(⚡すぐ聞く または 🔍しっかり調べる) |

**最新の質問が一番上に表示されます**(新しい順)。

### 自動削除と容量制限

シートの記録は最新100件まで保持されます。100件を超えると、古い質問から自動的に削除されます。

### 記録の有効・無効

設定ファイル(config)の `chat_log_enabled` を **FALSE** に変更すると、以降の質問を記録しなくなります(既に記録された履歴は削除されません)。既定値は **TRUE**(記録している)です。

### 検索機能

Ctrl+F キーを押して「チャット履歴」シートで検索すると、過去の質問や回答から必要な内容をすばやく見つけられます。

## 9. よくある質問

### 「資料が見つからない」と言われる

質問への回答欄に「本棚の中に手がかりが見つかりませんでした。資料が本棚に入っているか確認するか、資料を追加してから試してください。」と表示された場合、次を確認してください。

- 「マイ本棚」タブでその資料が✅(完了)になっているか(⏳のままだと検索対象になりません)
- 質問の言葉が資料の内容とかけ離れていないか(具体的な単語で聞き直してみる)
- そもそもまだ「マイ本棚」タブに資料を追加していないか

### 回答が遅い

- 「🔍しっかり調べる」モードは下書き→検証の2段階のため、「⚡すぐ聞く」より時間がかかる仕様です。急いでいるときは⚡を使ってください
- 「本日のAI利用上限に達した可能性があります。今日はここまでにして、明日「🔄同期」を押せば続きから再開できます。」と表示された場合は、その日はいったん終了し、翌日改めてお試しください

### 画像PDFが取り込めない

スキャンした紙など「画像として保存されたPDF」は、画像解析機能(既定で有効)がAIで文字を読み取って取り込みます。それでも読み取れなかった場合は資料カードが🖼になります。その場合は、読み取りたいページを画面コピーして「📸 スクショ取込」で1ページずつ取り込むと成功しやすくなります。

### 資料を追加しようとするとエラーになる

| メッセージの要点 | 原因と対処 |
|---|---|
| 対応していない種類のファイルです | 対応形式(txt/md/csv/pdf/docx/doc/xlsx等)以外を選んでいます。画像(png/jpg)は画像解析機能が有効なら取り込めます |
| ファイルを開けませんでした(他のアプリで開いている、または権限がない可能性があります) | そのファイルを開いている他のアプリ(Word/Excel等)を閉じてから、もう一度お試しください |
| 本棚に入れられる資料の上限を超えています | 使っていない資料を「🗑 選んだ資料を削除」で減らしてから、もう一度追加してください |
| 同じ名前の資料が、別の場所からすでに登録されています | 同名の別ファイルを別フォルダから追加しようとしています。ファイル名を変えるか、先に元の資料を削除してから追加し直してください |

### 同期でエラーが出る

「同期するフォルダが見つかりませんでした。「📁フォルダを選ぶ」からフォルダを選び直してください。」と表示された場合、本棚フォルダが削除・移動・リネームされていないか確認してください。フォルダが復活すれば、次回の同期で自動的に元に戻ります。

### パックが取り込めない

「パックの形式が正しくないか、バージョンが合っていません。相手にパックの再書き出しを依頼してください。」または「パックのベクトルの次元数が一致しませんでした。AIリボンのバージョンが違う可能性があります。管理者へ連絡してください。」と表示された場合は、パック作成者に最新版での再書き出しを依頼するか、管理者に連絡してください。

### エラーが出た時の詳しい情報を送る

何か操作をしてエラーダイアログが表示されたときは、ダイアログの末尾に「🩺診断→📋 直近のエラーをコピー で詳しい情報を担当者に送れます」という案内が出ています。

1. 「🩺 診断」ボタンをタップして診断画面を開く
2. 「📋 直近のエラーをコピー」ボタンを押す
3. エラー詳細(エラーコード・発生箇所・HTTP通信のステータス・生エラー番号等)が整形テキストでクリップボードにコピーされます
4. メールやチャットなどで管理者に貼り付けて送れば、より詳しいサポートが受けられます

### それでも解決しない

画面右上の **「🩺 診断」** を押し、表示された画面をスクリーンショットして管理者に送ってください。診断結果には ✅/⚠️ でどこに問題があるかが一覧表示されます。

## 10. 便利な機能

### 💬 続けて質問(深掘り)

回答を読んで「もう少し詳しく知りたい」と思ったら、**「💬 続けて質問」** ボタンを押してください。前回までのやり取りを覚えたまま、続きの質問ができます。

- 回答の末尾には **「🔎 深掘り候補」** として、次に聞くとよさそうな質問の例が表示されます。気になるものがあれば、そのまま「続けて質問」に打ち込むだけでOKです
- 「さっきの回答を、新入社員向けにもっとやさしく言い直して」のような聞き方もできます
- 会話として覚えているのは直近3往復までです(それより前の話題は、新しい質問として聞き直してください)

### 📝 回答をWordで開く

回答が表示された状態で **「📝 Wordで開く」** ボタンを押すと、「どんな文書に仕上げますか?」と聞かれます。

- 例えば **「お客様向けの回答文書風に」** と入力すると、AIが回答をその形に整えてからWordが開きます。あとは宛名などを直すだけで、そのまま使える文書になります
- **「社内回覧用に3行で要約」** など、用途は自由に指定できます
- 何も入力せずOKを押すと、回答がそのままWordに転記されます(コピペの手間の省略)

### 📸 スクショ取込

紙のマニュアルの1ページ、システムの画面、Teamsに貼られた図…「この画面の内容をAIに覚えさせたい」と思ったら:

1. 取り込みたい画面をコピーする(`PrintScreen` キー、または `Win+Shift+S` で範囲を選んでコピー)
2. 「マイ本棚」画面の **「📸 スクショ取込」** ボタンを押す
3. 資料名を入力する(例: 「経費精算マニュアル 12ページ」)

これだけで、AIが画像から文字を読み取り、本棚の1冊として登録されます。以後は普通の資料と同じように質問に使われます。分厚いマニュアルの「必要なページだけ」を取り込みたいときに特に便利です。

### 🗔 取込中に別の仕事をする

資料の取込や「🔍 しっかり調べる」「🔬 入念に調べる」での質問は、AIからの応答を待つあいだこのExcel自体が「応答なし」の状態になります(公式仕様。他の操作は受け付けません)。この間に他の仕事をしたいときは:

1. 取込中に出る進捗バナー内の **「🗔作業用Excel」** ボタン、またはヘルプ「❓」→「🗔 作業用Excelを開く」を押す
2. 数秒で別の(空の)Excelウィンドウが開くので、そちらで「ファイル」→「開く」から必要なブックを開いて作業する

この方法で開いたExcelは**別のプロセス**として動くため、取込中のこのブックが「応答なし」でも影響を受けません。

**質問(Q&A)の待ち時間についての大事な注意**: 上の「🗔作業用Excel」ボタンが出るのは**資料の取込中**だけです。質問を送ったあとの待ち時間は、ヘルプ「❓」も進捗バナーのボタンも押せません(このExcelがAIの応答を待って完全に止まっているため、クリック自体が届きません)。「🔍 しっかり調べる」「🔬 入念に調べる」は数分かかることがあるので、**質問を送る前に「🗔作業用Excel」で作業用のExcelを開いておいてください**。先に開いておけば、質問の待ち時間もそちらで仕事を続けられます。

**非推奨**: 取込中にエクスプローラーで別のExcelファイルをダブルクリックして開こうとする方法は、環境によって「コマンドを送信できませんでした」のエラーになることがあります(応答なしになっている同じExcelプロセスへ新しいファイルを渡そうとして阻まれるため)。上記の「🗔作業用Excel」ボタン経由(別プロセスで開く)をお使いください。
