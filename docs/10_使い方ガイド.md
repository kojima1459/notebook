## 1. 初回セットアップ

このアプリを初めて開いたときだけ、名前の入力に続けて部門・共有フォルダの確認が続きます
(「その他」を選ぶと部門名の入力が加わり、環境によっては共有パスの直接入力の案内が
出ます)。

1. 「部門を設定しますか?」(はい/いいえ)
2. (「はい」の場合)部門を選ぶ番号入力(1=商品部 / 2=リスコン部 / 0=その他)
3. 「共有フォルダを設定しますか?」(はい/いいえ)
4. (「はい」の場合)共有フォルダを選ぶダイアログ

**どの確認も「いいえ」やキャンセルでスキップできます。** 一度この案内を最後まで見た(またはスキップした)あとは、次回以降このブックを開いても再表示されません。部門を設定すると部門の公式ナレッジが、共有フォルダを設定すると「みんなの節約」や部門資料が使えるようになります。

**あとから設定・変更したいとき**は、それぞれ次から辿れます。

| 設定項目 | 再設定できる場所 |
|---|---|
| 部門 | Hubのプロフィールカード |
| 共有フォルダ | ヘルプ「❓」の「⚙ 共有フォルダ設定」 |

## 2. ホーム画面

質問する画面です。タブ「ホーム」を開くと表示されます。

| 部品 | 説明 |
|---|---|
| ❓ 使い方 | 「使い方」タブに切り替える |
| ❓ ガイド →「🩺 診断を開く」 | 今の状態を一覧表示する(困ったときはまずこれ)。診断レポートの冒頭に[設定サマリー]として、AIモデル名・自動同期間隔・本棚フォルダなどの現在値が表示される |
| ⚡ すぐ聞く (10〜20秒) / 🔍 しっかり調べる (1〜2分) | 回答の速さ・丁寧さを切り替えるトグル(詳しくは§5) |
| 質問入力欄 | 「質問をここに入力してください(例: 〇〇の手続きに必要な書類は?)」に質問を書く |
| 💬 質 問 す る | 質問を実行する |
| 状態表示 | 🔍検索中… → ✍️回答作成中… のように進行状況が出る |
| 回答欄 | AIの回答が表示される。本棚の資料との関連度が低い場合(既定値: 0.3未満)、回答の先頭に「⚠️ 手元の資料との関連が薄い可能性があります」と警告が付く |
| 📖 この回答のもと | 回答の根拠になった資料名とページ番号(出典) |
| ✅ 解決した / 🤔 微妙 / ❌ 違う | 回答への感想ボタン。押すとダッシュボードの記録に反映される |
| 💬 続けて質問 | 前回までのやり取りを踏まえた続きの質問ができる(詳しくは§12) |
| 📝 Wordで開く | 回答を指定した文書スタイルに整えてWordで開く(詳しくは§12) |
| 💡 豆知識 | 待ち時間に表示される小さなヒント |

本棚に資料が1件も無いときは、回答欄に「まだ本棚に資料がありません。まず『マイ本棚』タブで資料を1つ追加してみましょう →」という案内が常に出ます。

## 3. マイ本棚画面

資料を追加・整理する画面です。タブ「マイ本棚」を開くと表示されます。

### 上部のボタン

| ボタン | できること |
|---|---|
| ＋ 資料を追加 | ファイル選択ダイアログで資料を1件以上まとめて追加する |
| ⚡ 仕上げ | 旧形式の資料を**再取込みせずに**俯瞰・条文参照・言い換え検索に対応させる(下記参照) |
| 📖 本文 | いま選んでいる1件の、読み取った文章を全部表示します(一覧表モードのみ・行をクリックしてから押す) |
| 🔄 フォルダと同期 | 「本棚フォルダ」の中身と本棚を今すぐ突き合わせる(詳しくは§6) |
| 📦 パック出力 | 本棚(または1件)を他の人に渡せる形式で書き出す(詳しくは§7) |
| 📥 パック取込 | 誰かが作った「パック」を自分の本棚に取り込む(詳しくは§7) |
| 🗑 選んだ資料を削除 | クリックした行の資料を本棚から削除する |
| 📸 スクショ取込 | コピーした画面(スクリーンショット)をAIが文字起こしして本棚に追加する(詳しくは§12) |

削除するときは、削除したい資料カードの行をクリックしてから 🗑 ボタンを押してください。行を選んでいないと「削除したい資料の行をクリックしてから、もう一度押してください。」と案内が出ます。確認ダイアログ「『(資料名)』を本棚から削除しますか? この操作は取り消せません。」で「はい」を押すと削除されます。

### ⚡ 仕上げ(旧形式の資料の有効化・R20-3)

「⚡ 仕上げ」ボタンは、資料を**再取込みせずに**次の3つの機能を後から有効にします。

- **俯瞰**: 「〜を全部教えて」「全体像は?」に、章をまたいだ回答が返るようになる(§5)
- **条文参照**: 「第5条の免責は?」で、第5条が参照している別の条・別表もあわせて読む
- **言い換え検索**: 資料と質問で書き方が違っても(例:「リコール」⇔「回収」)見つかるようになる

R19以降に取り込んだ資料はそのまま対象です(何もしなくても有効)。それより前に
取り込んだ資料だけ⚡仕上げが必要です。押すと対象の冊数が確認され、「実行しますか?」
で「はい」を選ぶとAIが章の数だけ動きます(目安: 1冊あたり数十秒〜数分)。進捗
バナーに出る「章の要約中… 3/20章」は、その資料の何番目の章を要約しているかの
表示です。ファイルの再取込みは一切発生しません。旧形式の資料が1件も無ければ、
押すと「すべての資料は仕上げ済みです」と表示されます。かなり古い取込方式の
資料(breadcrumb形式でない資料)だけは⚡仕上げでは直せず、その場合は再取込が
必要になります。

### 本棚フォルダ

「📁 フォルダを選ぶ」でパソコン内のフォルダを1つ指定すると、「ここにファイルを入れておくと、自動で本棚に追加されます(消せば本棚からも消えます)」のとおり、**フォルダに入れれば本棚に入り、フォルダから消せば本棚からも消えます**。詳しくは§6を参照してください。

### 資料カード(状態アイコン)

| アイコン | 意味 |
|---|---|
| ✅ | 取込・変換が完了(質問に使える) |
| ⏳ | 変換中、または一部だけ変換未完了(そのうち完了する/🔄同期で再開) |
| ⚠️ | 取込に失敗した(理由がメモ欄に表示される) |
| 🖼 | 画像として保存されたPDFのため、文字を取り込めなかった |
| 🕒 | 元のファイルが見つからない(フォルダから削除・移動された可能性) |

### 資料の自動整理(AIによる要約・キーワード付け)

資料カードが✅(取込完了)になったあとも、裏側では**AIが少しずつ資料を整理しています**。
これは検索の精度を上げるための下ごしらえで、質問には影響しません(整理が終わっていなくても
質問はいつもどおりできます)。

- **何をしているか**: 各資料のかたまり(チャンク)ごとに要約とキーワードを作り、
  さらに用語の書き方のゆれ(「回収」「リコール」のように、意味は同じでも書き方が
  違う語)を辞書としてまとめます。あとで書き方が違う質問をしても、この辞書のおかげで
  該当資料が見つかりやすくなります。
- **いつ動くか**: 資料を取り込んだ直後に少しだけ、残りは「🔄フォルダと同期」のたびに
  少しずつ追いつきます(一度に全部を処理して長時間待たされることはありません)。
- **画面での見え方**: 手動の取り込み中は進捗バナーに「AI整理中…」「章の要約中… 3/20章」と
  出ます(このあいだも **■中断** で止められ、次回は続きから再開されます)。
  自動同期(バックグラウンド)で追いつく分はバナーを出しません。
- **やめたい場合**: 管理者向けの設定です。変えたいときはこのツールの管理担当に
  相談してください。

## 4. ダッシュボード画面

自分の利用状況を振り返る画面です。操作ボタンはなく、見るだけです。上段にKPIカードが4枚並び、その下に経験値(EXP)バー、さらに下にバッジ棚が続きます。

| KPIカード | 表示内容 |
|---|---|
| 節約した時間 | 「✅ 解決した」の累計を15分換算した、AI活用で浮いた時間の目安。前月より増えていれば増分が色付きで添えられます |
| 登録ナレッジ数 | 自分が本棚に登録した資料の件数 |
| 資料の分量 | 本棚が使っている検索用データの量(上限に対する割合を一言で表示) |
| レベル | 現在の「Lv.」。累計EXPと、次のレベルまでに必要な残りEXPが添えられます |

**レベル/EXPとは**: 質問する・「✅ 解決した」を押す・資料を登録する・パックを渡すなど、日々の利用に応じてEXP(経験値)が少しずつ貯まり、一定量ごとにレベルが1つ上がる、利用状況を振り返るための目安表示です。レベルやEXPの値が何かの権限や機能制限に影響することはありません。

**🏅 バッジ**: 経験値バーの下に並びます。獲得済みは色付きで日付入り、未獲得は🔒アイコン付き・灰色で獲得条件が表示されます(一覧は§9)。

## 5. 回答モード(3種類)の使い分け

ホーム画面上部のトグルで切り替えます。

| モード | 目安時間 | 向いている場面 |
|---|---|---|
| ⚡ すぐ聞く | 10〜20秒 | ちょっと確認したい・急いでいる |
| 🔍 しっかり調べる | 1〜2分 | 正確さが重要・下書き+検証の2段階で確認してから回答する |
| 🔬 入念に調べる | 2〜4分 | 資料をまたぐ複雑な質問・そのまま社内へ出す回答をつくるとき |

「🔍しっかり調べる」は下書きを作ったあとにもう一度AIが内容を検証してから返すため、少し時間がかかりますが、より丁寧な回答になります。

### 🔬 入念に調べる でできること

いちばん時間はかかりますが、ふつうに聞くだけでは届かないところまで調べます。

- **複数の論点を含む質問は、自動で論点ごとに調べて1つにまとめます。**
  「AとBの違いと、Cの申請手続きは?」のように複数のことを一度に聞いた場合、
  論点ごとに別々に資料を探してから統合するので、どの論点も「薄い答え」になりません。
  回答は **■見出し** で論点ごとに分かれて表示されます。
- **質問の読み方がいくつもあるときは、番号の選択肢で聞き返します。**
  「解約について教えて」のように幅の広い質問には、いきなり答えを作らず
  「1) 解約手続きの流れ 2) 解約金の計算 3) 解約後の補償」のような選択肢が出ます。
  **「1」** や **「1と3」** のように番号だけを送れば、その読み方で調べ直します
  (複数選ぶと、両方を論点として調べます)。もちろん番号を使わず、
  ご自身の言葉で質問を書き直していただいても構いません。
- **「全部教えて」型の質問には、章をまたいで俯瞰した回答を返します。**
  「この規程を全部教えて」「全体像は?」「どんな種類がありますか」「概要を知りたい」
  「補償の一覧」のように一覧・全体を求める質問では、資料の**章ごとの要約**から
  まず読むべき章を選び、その章の本文をまとめて読んで■見出しつきで整理します
  (章の要約は資料を取り込むとき、またはマイ本棚の「⚡仕上げ」で作られます。
  R19以降に取り込んだ資料はそのまま対象で、それより前の資料は⚡仕上げ
  (再取込不要)で有効化できます)。**「全体像は?」のような短い質問でも働きます**
  (短いからという理由で聞き返されることはありません)。
  俯瞰で答えたときは、回答のすぐ下のバッジが
  **🔭 章の要約に基づく回答(俯瞰)** に変わります。章の要約から選んで答えた、
  という出自がそのまま出る表示で、このとき「関連が薄いかもしれません」の
  注意書きは付きません。
- **根拠にした箇所の前後もあわせて読みます。**
  表の見出しと数値、条文と但し書きのように、意味のまとまりがページやブロックを
  またぐ資料でも「書いてあるのに見つけられない」が起きにくくなります。
- **「💬 続けて質問」での深掘りは、前回と重複しない深さへ進みます。**
  2回目・3回目の深掘りでは、前回すでに読んだ箇所を後ろに回して新しい箇所を優先し、
  「前回と同じ説明の言い換え」が返りにくくしています。

**「免責は?」のように短く、しかも複数の資料に同じくらい当たる質問は、「ご質問は複数の資料に該当します。どの資料についてですか?」と番号で聞き返します。**
無理に1つの資料へ寄せた答えを作るより、どの資料かを1文字で選んでもらう方が確実だからです。**「💬 続けて質問」での深掘りでも同じように聞き返します**(「計算方法」のような短い深掘りは、前の回答とは別の資料にも当たるためです)。質問文に資料名(「就業規則の免責は?」など)が入っているときは、もう資料が決まっているので聞き返しません。この聞き返しが多すぎると感じる場合は、config シートの `ambiguous_dispersion_gap_x100` を小さく(`0` で機能OFF)してください。

**複合質問の自動分解・番号選択肢での聞き返し・俯瞰の回答は、🔬入念に調べる だけの機能です。**
⚡すぐ聞く・🔍しっかり調べる では、複数の論点を含む質問も1本のまま検索されます
(論点ごとに薄い答えになりやすい点にご注意ください)。短くても「免責は?保険料は?」
のように？が続く質問・句点で区切られた複数の質問文は、入念モードなら文字数が
短くても自動で分解対象になります。

### 3つの聞き方は「一般アシスタント」でも効きます

チャット画面には **🟢 社内ナレッジ検索**(本棚の資料から出典付きで答える)と **🌐 一般アシスタント**(本棚を使わず、AIの一般知識だけで答える)の2つのモードがあり、上の3段トグルは**どちらでも**効きます(以前は社内ナレッジ検索にしか効きませんでした)。

| 聞き方 | 🟢 社内ナレッジ検索 | 🌐 一般アシスタント |
|---|---|---|
| ⚡ すぐ聞く | 1回検索して即答 | 1回で即答(簡潔) |
| 🔍 しっかり | 本棚全体を探す。「続けて質問」のときだけ直前の資料へ絞り、足りなければ広げ直す | 前提と論点を整理してから、判断基準・具体例・注意点まで踏み込む |
| 🔬 入念に | 本棚全体を広く探し、関係する章の本文をまとめて1回で読んで答える(1回読み) | 下書きを別の視点で査読させ、指摘があれば書き直す(最大2周) |

回答のいちばん下(フッター)に、モード名・使った聞き方・実際の回数が出ます(一般アシスタントの例: 「🌐 一般アシスタント・🔬 入念に調べる ・ 128.4秒 ・ 社内資料は未使用 ・ 検証2回」)。「3つとも同じでは?」と感じたときはそこを見てください。

### 🔬 入念に調べる の新しい動き(1回読み)

「🔬 入念に調べる」は、🟢 社内ナレッジ検索で**1つの論点の質問**をしたとき、関係する章の本文をまとめて**1回で読んで答える方式(1回読み)**になりました(複数の論点に分かれる質問・「全部教えて」型・🌐 一般アシスタントは従来どおり)。以前は「要点整理→下書き→自己点検→検証」の4段階で AI と何度も往復していましたが、往復が減るぶん待ち時間が短くなる見込みです(実機で確認中。回答フッターの「(N段)」も減ります)。

実行中は画面に「🔎 入念(1回読み): N章・M箇所を読んで回答を作成中… ※応答なし表示でも処理中」と出ます。読み込み中は Excel が「応答なし」に見えることがありますが、内部では処理が続いていますので、そのままお待ちください。

以前の動きに戻したいとき(著しく遅い・精度が気になる)は、config シートの `thorough_onepass` を `off` に書き換えて保存し、ブックを開き直してください。それだけで従来の4段階に戻ります。遅さだけが気になる場合は `off` にせず、`onepass_max_chars`(既定 450000。約30万トークン分)を `300000` や `150000` に下げて試してください。

### モードを切り替えたときの「直前の1往復」の引き継ぎ

社内ナレッジ検索と一般アシスタントは、覚えている会話が別々です。切り替えたときは、**直前の1往復(質問と回答)だけ**が切替先へ渡されます。ただし**向きによって効き方が違います**。

| 切り替えの向き | 何が起きるか | 続きとして聞くには |
|---|---|---|
| 🟢 社内ナレッジ検索 → 🌐 一般アシスタント | 直前の1往復がそのまま引き継がれます(「文脈を引き継ぎました(直前の1往復)。新しく始めるなら 🗑 クリア」と表示) | そのまま質問すれば続きになります |
| 🌐 一般アシスタント → 🟢 社内ナレッジ検索 | 直前の1往復は**保存されるだけ**です(「直前の1往復を保存しました。続きとして聞くには 🔍 深掘り(続けて質問)を押してください」と表示) | 切り替えたあとに **🔍 深掘り(続けて質問)** を押してから質問してください。押さずにそのまま聞くと、単発の質問として扱われます |

- 「約款の免責事由は?」と社内ナレッジ検索で聞いた直後に一般アシスタントへ切り替えて、「この条文の趣旨を実務の観点で壁打ちしたい」と続けられます(この向きはそのまま続けられます)
- 引き継ぎたくないときは、切り替える前に **🗑 クリア** を押してください(両方のモードの記憶がその場で消えます)
- 引き継ぐのは直前の1往復だけです(それより前の話題は新しい質問として聞き直してください)

## 6. 本棚フォルダ同期

「📚 ナレッジと本棚」画面の「📁 フォルダを選ぶ」でフォルダを指定すると、そのフォルダの中身と本棚が同期されます。

- **フォルダに入れれば本棚に入る**: 対応形式のファイルをフォルダに置くと、次の同期で自動的に取り込まれます
- **消せば本棚からも消える**: フォルダからファイルを削除すると、次の同期で本棚からも削除されます
- **更新すれば置き換わる**: 同じファイル名で内容を更新すると、自動的に新しい内容に置き換わります(重複しません)
- サブフォルダの中までは見ません(フォルダ直下のファイルだけが対象です)

同期は次のタイミングで行われます。

1. 手動: 「🔄 フォルダと同期」ボタンを押したとき
   - **スキャンPDF(画像PDF)が含まれていると、取り込む前に確認が出ます**: 読み取りに時間がかかると見込まれる資料は1件ごとに「全N頁のスキャンPDFです。推定約M分かかります。取り込みますか?」と確認します(「いいえ」を選んだ資料は見送りとして記録され、失敗にはなりません)
   - **文字がそのまま入っているPDF(スキャンでないPDF)でも、大きな資料は取り込みが終わったあとに数分かかることがあります**: 読み取りのあとに検索用の準備と**章の要約**(章の数だけAIを呼びます)が続くためです。進捗バナーに「章の要約中… 3/20章」と残り時間が出ます。急ぐときは **■中断** で止められ、そこまでの章は保存されます(この待ちが不要なら、管理者向け設定 `graph_outline` を `off` にできます)
   - 「はい」を選んだ直後に一度だけ「先に作業用Excelを開いてから開始しますか?」と聞かれます。**この質問はExcelを開いている間に1回だけ**で、2件目以降では出ません(すでに作業用Excelを開いている場合も出ません)
   - 上限見送りなし(すべてのファイルが無事に取り込まれた)の場合: 状態表示行とステータスバーに「✅ 同期が完了しました(○件の変更)」と表示されるだけで、完了時のダイアログは出ません
   - 上限見送りがあった場合(ファイルサイズやAPI呼び出し上限に達した等): 従来どおり「△件をスキップしました」という確認ダイアログが表示されます
2. 自動: ブックを開いたとき、および設定された間隔(config `sync_interval_min`)ごと(バックグラウンドで静かに実行され、ポップアップは出ません)
   - **自動同期では、章の多い資料(13章以上)の「章の要約」は作りません**: 誰も見ていないところで数分〜十数分Excelが固まるのを避けるためです。その資料を手動で取り込むか「🔄 フォルダと同期」を押すと、そのときに全部作られます

同期フォルダが見つからない場合(削除・リネームなど)は、対象の資料が🕒(見つからない)表示になります。フォルダが元に戻れば、次回の同期で自動的に復帰します。

## 7. パックの渡し方・受け取り方

「パック」とは、本棚の資料をひとまとめにした受け渡し用ファイル(.xlsx)です。承認なしで同僚と資料を共有できます。

### 渡す(書き出す)

1. 「📚 ナレッジと本棚」画面で「📦 パック出力」を押す
2. 「本棚全体をパックにして書き出しますか?」で選ぶ
   - 「はい」: 本棚全体を書き出す
   - 「いいえ」: クリックしていた行の資料1件だけを書き出す
   - 「キャンセル」: 何もしない
3. 個人情報チェックを有効にしている場合(config `pii_scan_enabled`。既定はオフ)、個人情報らしき内容が見つかると件数と例が表示され、書き出しは中止されます(続けるかどうかを選ぶ操作はありません)
4. 保存先を選ぶと、`パック_(資料名または本棚全体)_(日付).xlsx` という名前で保存されます
5. 完了すると「パックを書き出しました。○件の資料を「(ファイル名)」として保存しました。」と表示されます

### 受け取る(取り込む)

1. 「📚 ナレッジと本棚」画面で「📥 パック取込」を押す
2. 受け取った .xlsx ファイルを選ぶ
3. 完了すると「○件取込 / ○件は既にありました。」と表示されます(自分の本棚に無い内容だけが追加されます。重複は自動でスキップされます)

パックの作成者名は、初回起動時に入力した名前が使われます(「📖 この回答のもと」欄では `ファイル名 p.ページ（パック: 作成者名）` のように、パック由来の資料だけカッコ書きで作成者名が付きます。なお回答本文中でAIが引用元を示す際は `[パック(作成者名):ファイル名]` という角括弧書式が使われます)。自分で入れた資料は `[本棚:ファイル名 p.ページ番号]`、**Excel の資料は `[本棚:ファイル名 シート番号]`** で、根拠の文には `(B3 付近)` のようにセル番地が添えられます(取り込んだ本文では、値の直前に `[B3]` のようにそのセル自身の番地が付く仕組み。**R43 より前に取り込んだ Excel 資料は、いちど削除してもう一度取り込むと新しい番地になります**)。
R42 より前に取り込んだ複数ページの PDF は、出典ページが 1 に寄っていることがあります。
マイ本棚で削除→もう一度取り込むと直ります。

## 8. 引き継ぎファイル

**パックとは別の機能です(R20-5)。** 「引き継ぎファイル」は、**自分の**本棚・実績(バッジ・EXP)・設定を丸ごと1つの
ファイルに保存する、個人用のバックアップです。新しいパソコンへ移るときや、
新しいバージョンのMyBookshelfへ更新するとき(更新すると本棚も記録もいったん
消えます)に使います。

| | パック | 引き継ぎファイル |
|---|---|---|
| 目的 | 他の人に資料を配る/受け取る | 自分の環境を丸ごと移す |
| 中身 | 資料(本文・出典)のみ | 本棚+実績+設定 一式 |
| 誰が使う | 同僚どうしの共有 | 自分だけ |

**いつ使うか**: パソコンの入れ替え・MyBookshelfのバージョンアップの直前。

**作る/読み込む**: ホーム画面右上「❓」ヘルプカードの「📤 引き継ぎファイルを作る」
「📥 引き継ぎファイルを読む」から。どちらもボタンを押すとまず【引き継ぎファイル
とは】の説明が表示され、「はい」で実行されます(パックと混同して他の人へ
渡してしまわないための確認です)。

**機微情報の注意**: 引き継ぎファイルには本棚の資料本文がそのまま含まれます。
社外の人やクラウドの個人アカウントへは共有せず、自分の管理下に置いてください
(社内の資料共有には「パック」を使ってください)。

## 10. チャット履歴

質問と回答の履歴が自動で記録される、見える形のシートです。

### チャット履歴シートについて

ホーム画面で質問するたびに、次の情報が自動的に「チャット履歴」シートに記録されます。

| 列 | 内容 | 説明 |
|---|---|---|
| A | 質問 | あなたが質問した内容 |
| B | 回答 | AIが返した回答 |
| C | 日時 | 質問した日時 |
| D | モード | 質問したときのモード(⚡すぐ聞く または 🔍しっかり調べる) |

**最新の質問が一番上に表示されます**(新しい順)。

### 自動削除と容量制限

シートの記録は最新100件まで保持されます。100件を超えると、古い質問から自動的に削除されます。

### 記録の有効・無効

設定ファイル(config)の `chat_log_enabled` を **FALSE** に変更すると、以降の質問を記録しなくなります(既に記録された履歴は削除されません)。既定値は **TRUE**(記録している)です。

### 検索機能

Ctrl+F キーを押して「チャット履歴」シートで検索すると、過去の質問や回答から必要な内容をすばやく見つけられます。

## 11. よくある質問

### 「資料が見つからない」と言われる

質問への回答欄に「本棚の中に手がかりが見つかりませんでした。資料が本棚に入っているか確認するか、資料を追加してから試してください。」と表示された場合、次を確認してください。

- 「📚 ナレッジと本棚」画面でその資料が✅(完了)になっているか(⏳のままだと検索対象になりません)
- 質問の言葉が資料の内容とかけ離れていないか(具体的な単語で聞き直してみる)
- そもそもまだ「📚 ナレッジと本棚」画面に資料を追加していないか

### 回答が遅い

- 「🔍しっかり調べる」モードは下書き→検証の2段階のため、「⚡すぐ聞く」より時間がかかる仕様です。急いでいるときは⚡を使ってください
- 「本日のAI利用上限に達した可能性があります。今日はここまでにして、明日「🔄同期」を押せば続きから再開できます。」と表示された場合は、その日はいったん終了し、翌日改めてお試しください

### 画像PDFが取り込めない

スキャンした紙など「画像として保存されたPDF」は、画像解析機能(既定で有効)がAIで文字を読み取って取り込みます。それでも読み取れなかった場合は資料カードが🖼になります。その場合は、読み取りたいページを画面コピーして「📸 スクショ取込」で1ページずつ取り込むと成功しやすくなります。

### 資料を追加しようとするとエラーになる

| メッセージの要点 | 原因と対処 |
|---|---|
| 対応していない種類のファイルです | 対応形式(txt/md/csv/pdf/docx/doc/xlsx等)以外を選んでいます。画像(png/jpg/jpeg)は 📁 追加からも選べます(読み取りは 📸 と同じ。画像解析が使える環境だけ) |
| ファイルを開けませんでした(他のアプリで開いている、または権限がない可能性があります) | そのファイルを開いている他のアプリ(Word/Excel等)を閉じてから、もう一度お試しください |
| 本棚に入れられる資料の上限を超えています | 使っていない資料を「🗑 選んだ資料を削除」で減らしてから、もう一度追加してください |
| 同じ名前の資料が、別の場所からすでに登録されています | 同名の別ファイルを別フォルダから追加しようとしています。ファイル名を変えるか、先に元の資料を削除してから追加し直してください |

### 同期でエラーが出る

「同期するフォルダが見つかりませんでした。「📁フォルダを選ぶ」からフォルダを選び直してください。」と表示された場合、本棚フォルダが削除・移動・リネームされていないか確認してください。フォルダが復活すれば、次回の同期で自動的に元に戻ります。

### パックが取り込めない

「パックの形式が正しくないか、バージョンが合っていません。相手にパックの再書き出しを依頼してください。」または「パックのベクトルの次元数が一致しませんでした。AIリボンのバージョンが違う可能性があります。管理者へ連絡してください。」と表示された場合は、パック作成者に最新版での再書き出しを依頼するか、管理者に連絡してください。

### エラーが出た時の詳しい情報を送る

何か操作をしてエラーダイアログが表示されたときは、ダイアログの末尾に「「❓ ガイド」→「🩺 診断を開く」→📋 直近のエラーをコピー で詳しい情報を担当者に送れます」という案内が出ています。

1. 「❓ ガイド」→「🩺 診断を開く」をタップして診断画面を開く
2. 「📋 直近のエラーをコピー」ボタンを押す
3. エラー詳細(エラーコード・発生箇所・HTTP通信のステータス・生エラー番号等)が整形テキストでクリップボードにコピーされます
4. メールやチャットなどで管理者に貼り付けて送れば、より詳しいサポートが受けられます

### それでも解決しない

画面右上の **「❓ ガイド →「🩺 診断を開く」」** を押し、表示された画面をスクリーンショットして管理者に送ってください。診断結果には ✅/⚠️ でどこに問題があるかが一覧表示されます。

## 12. 便利な機能

### 💬 続けて質問(深掘り)

回答を読んで「もう少し詳しく知りたい」と思ったら、**「💬 続けて質問」** ボタンを押してください。前回までのやり取りを覚えたまま、続きの質問ができます。

- 回答の末尾には **「🔎 深掘り候補」** として、次に聞くとよさそうな質問の例が表示されます。気になるものがあれば、そのまま「続けて質問」に打ち込むだけでOKです
- 「さっきの回答を、新入社員向けにもっとやさしく言い直して」のような聞き方もできます
- 会話として覚えているのは直近3往復までです(それより前の話題は、新しい質問として聞き直してください)

### 💾 この会話を本棚に保存(考察メモ)

回答の下のボタン列にある **「💾 保存」** を押すと、いま表示されている**質問と回答の1往復**を本棚の1冊として残せます。押すと題名を聞かれます(既定は質問の先頭24字。そのままOKでも構いません)。**題名は40字までです**(それより長い題名は先頭40字で切って保存されます)。`\ / : * ? " < > |` とタブ・改行は `_` に置き換わります。

- 保存したメモは **「💭考察メモ_(題名)」** という名前で本棚に並びます。以後は普通の資料と同じように検索で使われ、出典としても表示されます
- **💭が付いているものは、AIとの対話から生まれた考察であって一次資料ではありません**(本文の先頭にもその断り書きが入ります)。数字や条文を確かめるときは、必ず元の資料(💭の付かない資料)に当たってください
- 社内ナレッジ検索の回答でも、一般アシスタントの回答でも保存できます
- 同じ題名で保存し直すときは「上書きして更新しますか?」と確認が出ます(前のメモが黙って消えることはありません)
- いらなくなったメモは、マイ本棚の一覧から普通の資料と同じように削除できます

「調べた結果が、次に同じことを調べる人の資料になる」ための機能です。良い答えが出たときほど、その場で保存しておくと後から効いてきます。

### 📝 回答をWordで開く

回答が表示された状態で **「📝 Wordで開く」** ボタンを押すと、「どんな文書に仕上げますか?」と聞かれます。

- 例えば **「お客様向けの回答文書風に」** と入力すると、AIが回答をその形に整えてからWordが開きます。あとは宛名などを直すだけで、そのまま使える文書になります
- **「社内回覧用に3行で要約」** など、用途は自由に指定できます
- 何も入力せずOKを押すと、回答がそのままWordに転記されます(コピペの手間の省略)

### 📸 スクショ取込

紙のマニュアルの1ページ、システムの画面、Teamsに貼られた図…「この画面の内容をAIに覚えさせたい」と思ったら:

1. 取り込みたい画面をコピーする(`PrintScreen` キー、または `Win+Shift+S` で範囲を選んでコピー)
2. 「マイ本棚」画面の **「📸 スクショ取込」** ボタンを押す
3. 資料名を入力する(例: 「経費精算マニュアル 12ページ」)

これだけで、AIが画像から文字を読み取り、本棚の1冊として登録されます。以後は普通の資料と同じように質問に使われます。分厚いマニュアルの「必要なページだけ」を取り込みたいときに特に便利です。

取り込みが終わると、読み取った文章がそのまま「📖 本文」画面で開きます(config `screenshot_show_text` を FALSE にすると開かなくなります)。内容が違うときは、その資料を 🗑 で消してから ➕登録 で正しい文章を登録し直してください(直接直す機能はありません)。

### 🗔 取込中に別の仕事をする

資料の取込や「🔍 しっかり調べる」「🔬 入念に調べる」での質問は、AIからの応答を待つあいだこのExcel自体が「応答なし」の状態になります(公式仕様。他の操作は受け付けません)。この間に他の仕事をしたいときは:

1. 取込中に出る進捗バナー内の **「🗔作業用Excel」** ボタン、またはヘルプ「❓」→「🗔 作業用Excelを開く」を押す
2. 数秒で別の(空の)Excelウィンドウが開くので、そちらの「ファイル」→「開く」で**仕事のファイルだけ**を開いて作業する。**MyBookshelf本体(MyBookshelf.xlsm)は、この作業用Excelの中では開かないでください**

この方法で開いたExcelは**別のプロセス**として動くため、取込中のこのブックが「応答なし」でも影響を受けません。

**仕事が終わったら作業用Excelは閉じてください。** 開いたまま残しておくと、次にMyBookshelf本体を開くときに**その作業用Excelの中へ吸い込まれ**、以後は本体と同じ1つのプロセスで動くことになります。そうなると、本体が取込を始めた瞬間に作業用Excelも一緒に固まります(下の「起動は必ずランチャーから」を参照)。

### 🚀 起動は必ずランチャーから

配布された zip を展開すると、**「MyBookshelfを起動.bat」** というファイルが入っています。**MyBookshelf本体は、必ずこのランチャーから起動してください**(他のExcelで仕事中でも安全に開けます)。

- ランチャーは Excel を**必ず別のプロセス**で起動します(`excel.exe /x`。Microsoft公式の「新しいインスタンスを起動する」スイッチです)。
- **MyBookshelf.xlsm を直接ダブルクリックするのは避けてください。** Excelは既定で、開いているExcelが1つでもあると新しいファイルを**そのExcelの中へ取り込みます**。その結果、生き残っていた作業用Excelに本体が吸い込まれ、本体が取込を始めると**その作業用Excelも、本体の「■中断」ボタンも、まとめて反応しなくなります**(強制終了しか手が無くなります)。
- どうしてもダブルクリックで開くときは、**他のExcelをすべて閉じてから**にしてください。
- 起動時に「他のExcelブックと同じプロセスで開かれています」という警告が出たら、それはこの状態です。**いったん閉じて、ランチャーから開き直してください。**
- 初回だけ「WindowsによってPCが保護されました」等の警告が出ることがあります。その場合は bat ファイルを右クリック →「プロパティ」→ 下の方の「許可する」にチェック →「OK」を押してから開いてください。

**質問(Q&A)の待ち時間についての大事な注意**: 上の「🗔作業用Excel」ボタンが出るのは**資料の取込中**だけです。質問を送ったあとの待ち時間は、ヘルプ「❓」も進捗バナーのボタンも押せません(このExcelがAIの応答を待って完全に止まっているため、クリック自体が届きません)。「🔍 しっかり調べる」「🔬 入念に調べる」は数分かかることがあるので、**質問を送る前に「🗔作業用Excel」で作業用のExcelを開いておいてください**。先に開いておけば、質問の待ち時間もそちらで仕事を続けられます。

**非推奨**: 取込中にエクスプローラーで別のExcelファイルをダブルクリックして開こうとする方法は、環境によって「コマンドを送信できませんでした」のエラーになることがあります(応答なしになっている同じExcelプロセスへ新しいファイルを渡そうとして阻まれるため)。上記の「🗔作業用Excel」ボタン経由(別プロセスで開く)をお使いください。

**ダブルクリック起動のもう1つのリスク(こちらの方が厄介です)**: MyBookshelf本体をエクスプローラーからダブルクリックして開くと、**開いたまま生き残っていた作業用Excelに吸い込まれ**、本体と作業用Excelが同じ1つのプロセスで動き始めます。このときは何のエラーも出ません。異常が現れるのは後になってからで、**本体が取込を始めた瞬間に、その作業用Excelも一緒に固まります**(本体の「■中断」ボタンも押せません)。だからこそ、本体の起動は上の「🚀 起動は必ずランチャーから」のとおりランチャー経由に統一し、作業用Excelは仕事が終わったら閉じてください。
