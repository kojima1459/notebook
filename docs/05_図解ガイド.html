1. 30秒でわかるこれは何をする道具か

資料（PDF・Word・Excel・テキスト・画面のスクリーンショット）を「本棚」に入れると、AIがその資料だけを根拠にして質問に答えます。答えには必ず資料名とページが付き、その場で原文を確かめられます。

できること
資料の中身についての質問に、根拠のページ付きで答える。要点まとめ、条文の確認、「全部教えて」型の俯瞰。
できないこと
本棚に無いことは答えません（「社内ナレッジ検索」のとき）。一般知識で答えてほしいときは「🌐 一般アシスタント」に切り替えます。
入れてはいけないもの
契約者名・電話番号などの個人情報を含む資料。個人情報の自動チェックはこの版では動いていません（既定オフ）。

2. 最初の1回だけ開けるようになるまで（5分）

この章のゴール: OneDrive のフォルダに展開した bat を押して、画面が組み上がるところまで。
  1. zip を「OneDrive のフォルダ」に展開するzip を右クリック →「すべて展開」。展開先は OneDrive の中のフォルダにしてください（会社PCの D: やデスクトップは、日をまたぐと消えます）。zip の中から直接開くと、取り込んだ資料が次回残りません。
  2. 「MyBookshelfを起動.bat」をダブルクリックExcel 本体（MyBookshelf.xlsm）は直接ダブルクリックしないでください。bat が D: へ複製して、他の Excel と別のプロセスで開きます。初回だけ「WindowsによってPCが保護されました」と出たら、bat を右クリック →「プロパティ」→「許可する」にチェック → OK。
  3. 黄色い帯の「コンテンツの有効化」を押すExcel の上に「セキュリティの警告」の帯が出たら、その中のボタンを押します。数秒待つと画面が自動で組み上がります。押さないと案内画面のままです。
  4. 名前を入れる（初回のみ）「はじめまして。あなたのお名前（またはニックネーム）を教えてください」と出ます。好きな名前で OK。あとから config シートで変えられます。
  5. 続く案内は「いいえ」で全部飛ばして構いません「部門を設定しますか?」「共有フォルダを設定しますか?」が続けて出ます（最大4回）。テスト中はすべて「いいえ」で先へ進めます。あとから Hub と ヘルプ「❓」で同じ設定に辿り着けます（→ 第6章）。

bat が裏でやっていること（知らなくても使えます）

やってはいけない2つ
・黒い窓を×で閉じない（閉じると OneDrive への書き戻しが止まります）。
・開いたまま PC をシャットダウンしない（直前10分の作業が消えることがあります）。Excel を閉じて、黒い窓が自動で消えてからシャットダウンしてください。
版上げのとき（新しい zip を受け取ったら）
新しい zip を展開する前に、古い MyBookshelf.xlsm を削除せず、名前を MyBookshelf_旧版.xlsm に変えて同じフォルダに残してください。
新しい版を開いた初回に「前の版の本棚を引き継ぎますか?」と聞かれるので、「はい」を選ぶと本棚・実績・設定が自動で引き継がれます。

3. 画面の地図画面は5つ。全部 Hub から行き、「← Hub」で戻る

画面が崩れた・ボタンが消えたときは Hub 右上の 🔄 で描き直せます。マイ本棚の上にある3つのピル（🃏 ギャラリー / 📋 マイ本棚 / 🎁 みんなの解決事例）は画面の中の表示切替で、「📋 マイ本棚」は画面名と同じ文字ですが一覧表示に切り替えるボタンです。

4. 毎日の使い方資料を1つ入れて、質問して、答えを確かめる

この章のゴール: 自分の資料について質問し、出典のページを開いて確かめる。

チャット画面のスイッチ（2つだけ覚える）

スイッチどう使い分けるか

終わるとき

右上の 🚪（Hub では 🚪 終了）を押すと「保存してこのファイルを閉じますか?」と聞かれます。[はい] 保存して閉じる を選んでください。[いいえ] は保存せずに閉じる（今回取り込んだ資料は消えます）です。自動保存はしません（取込の途中経過だけは自動で保存されます）。

モードを切り替えたときに会話は引き継がれる？（向きで違います）

🏢 社内ナレッジ検索 → 🌐 一般アシスタント: 直前の会話がそのまま引き継がれます。画面に「直前の会話を引き継ぎました。新しく始めるなら 🗑 クリア」と出ます。調べた数字をそのまま計算させる、といった使い方ができます。

🌐 一般アシスタント → 🏢 社内ナレッジ検索: 直前の会話は保存されるだけです。「直前の会話を保存しました。続きとして聞くには 🔍 深掘り(続けて質問)を押してください」と出ます。🔍 深掘りを押してから質問すると続きになり、押さずに聞くと単発の質問として扱われます。

質問の待ち時間に別の仕事をしたい（作業用Excel）

取込中や 🔍/🔬 の質問中は、この Excel は「応答なし」に見えます（仕様です）。別の仕事は、質問を送る前に ヘルプ「❓」→「🗔 作業用Excelを開く」（取込中は進捗バナーの「🗔作業用Excel」）で開いた別の Excel でしてください。仕事のファイルはそちらで開き、MyBookshelf 本体はそこでは開かないでください。終わったら作業用 Excel は閉じます（残しておくと、次回本体を直接ダブルクリックしたときにそちらへ吸い込まれ、取込中に一緒に固まります。bat から起動していればこの巻き添えは起きません）。

入れる

ボタンいつ使う補足

消す

  1. ピルで「📋 マイ本棚」（一覧表示）に切り替える🃏 ギャラリー表示には削除ボタンが出ません（押し間違い防止）。
  2. 消したい資料の行をクリックする行を選ばずに押すと「削除したい資料の行をクリックしてから、もう一度押してください。」と出ます。
  3. ツールバー右端の 🗑 1件 を押し、「はい」この操作は取り消せません。

ほかの消し方: 🗑 部門ぶん一括＝選んだ部門から受け取った正典だけをまとめて消す（自分の資料とパックは残る）／ 🃏 ギャラリーでカードをクリック → [はい] で1件削除、[いいえ] で「⚠ ノイズ報告」（その資料を自分の検索から外す）。本棚をまるごと空にするボタンはありません。

量と速さの目安（大きい資料を入れる前に）
  • 文字の入っていない画像PDF（スキャン）は1ページごとにAIが読みます。20ページで約9分（実機実測）。5分以上かかる見込みのときは取り込む前に確認が出ます。
  • 1ファイルの読み取りは 300ページまで（超えた分は打ち切り）。
  • 本棚の上限はチャンク数 20,500件（資料150〜200冊相当）。8割を超えると Hub に警告が出ます。
  • 文字入りPDFでも、取込のあとに「章の要約」（章の数だけAIを呼ぶ）が続きます。急ぐときは ■中断 で止められ、そこまでは保存されます。
  • 同じ名前のファイルを別の場所から追加するとエラー（E0504）。ファイル名に年度や版を入れて区別してください。

7. 答えを確かめる・直す出典を開く／スクショの読み取りを確かめる／❌違う の効き方

出典を確かめる（毎回やってほしいこと）

  1. 答えのすぐ下の信頼度バッジを見る🟢「本棚の資料と強く一致(N件)」／🟡「部分的に一致 ― 下の出典で原文をご確認ください」／🔴「本棚に十分な根拠なし ― 内容をうのみにしないでください」の3段階です。🔴 のときは答えを使わないでください。
  2. 「🔎 出典(クリックで原文を確認):」の資料名ボタン（📄 資料名 p.ページ）を押すその資料の該当箇所の抜粋（先頭600字まで）がポップアップで出ます。出典ボタンは最大4件、同じ資料は1つにまとまります。
  3. 「📂 原文を開く」で元のファイルを開く数字・条文はここで必ず元の資料に当たってください。
  4. 答えの頭に「⚠️ 手元の資料との関連が薄い可能性があります」が付いていたら疑う本棚との一致が弱かった印です（既定: スコア 0.3 未満）。質問の言葉を資料と同じ表記に寄せて聞き直すのが近道です。

スクショ（画像）の読み取り結果を確かめるには

📸 スクショ取込の直後、AIが読み取った文章をその場で全文表示する画面（📖 本文）が自動で開きます。あとから見返したいときも、📋 マイ本棚（一覧表示）で資料の行をクリックしてから 📖 本文 を押せば、いつでも同じ画面が開きます。

📖 本文（この版で追加）
資料名・取込日時・チャンク数と、読み取った文章の全文がページ番号（【p.1】など）つきで表示されます。左上の「← 戻る」で元の画面に戻ります。
使い分け
画像だけでなく PDF/Word などすべての資料で使えます。抜粋（150/300/600字）だけでは足りないとき、全文をその場で確かめられます。
読み取った文章を直接書き直して保存し直す機能はありません（表示のみ）。内容が違うときは、その資料を 🗑 で消し、正しい文章を ➕ 登録 で登録し直してください（上書きではなく別の資料として入ります）。

❌ 違う → 正しい内容を教える、はどこまで効くか

効かせるコツ: 質問を打ち直すときは、最初に聞いたときと同じ言い回しで。是正メモは「そのとき打った質問文」にひも付いています。言い回しが大きく変わると別の質問として扱われます。

10. 用語画面に出る言葉だけ

本棚 / マイ本棚
あなたが入れた資料の置き場。AIはここだけを根拠に答えます。
ベクトル化 / 変換
資料をAIが検索できる形に直すこと。カードが ⏳ → ✅ になるまでの処理です。
チャンク
資料を検索しやすい大きさ（数百字）に切った1切れ。本棚の上限は「チャンク数」で数えます。
出典 / 📖 この回答のもと
答えの根拠にした資料名とページ。ボタンを押すと抜粋が出て、原文を開けます。
仕上げ（⚡）
古い形式で取り込んだ資料に、章の目次と要約を後付けする処理。再取込は不要。全部済んでいれば「仕上げ済みです」と出るだけです。
パック
本棚の資料をひとまとめにした受け渡し用ファイル（.xlsx）。同僚に渡す用。
引き継ぎファイル
本棚＋実績＋設定を丸ごと1つにした、自分用のバックアップ。
正典 / 部門チャンネル

部門の受け渡し場所（ファイルサーバ上のフォルダ）。感謝状・正典・みんなの節約はこれを設定してから動きます。
Hub
最初に出る拠点画面。どの画面からも「← Hub」で戻れます。
是正メモ（旧称: 修正ナレッジ）
❌違う のあとに書いた「正しい内容」が、元の質問文とセットで本棚に入ったもの。同じ質問をすると、答えのいちばん最初の根拠として必ず使われます。
考察メモ（💭）
💾 保存で残した質問と回答の1往復。一次資料ではないので、根拠は原典で確認します。
