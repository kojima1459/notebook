# 【配布者用】営業担当者にChatbot.xlsmを配るガイド

このガイドは、`01_admin-setup-guide.md` で動作確認が済んだあと、**営業担当者に配るパッケージを作って渡す手順** を説明します。

所要時間：**約20分**（一度作れば全員に同じものを使い回せる）

---

## 配布パッケージの中身（5点セット）

USBメモリ・社内共有フォルダ・SharePointのどれで渡してもOK。中身は以下の5点：

| ファイル/フォルダ | コピー元 | サイズ目安 |
|---|---|---|
| `Chatbot.xlsm` | `notebook-claude-prototype-gemini-demo\dist\` | 53KB |
| `config.ini` | `C:\Users\あなた\AppData\Local\InternalNotebookLM\` | 1KB（APIキー入り） |
| `disclaimer.txt` | 同上 | 1KB |
| `index\` フォルダ丸ごと | 同上 | 約21MB |
| `README.txt`（後述） | このページの後半に内容あり | 2KB |

合計：**約21MB**。USBメモリ・社内共有・SharePoint・OneDrive、どれでも余裕で送れます。

> ⚠️ **`Admin_KnowledgeBuilder.xlsm` は配らない**。これは管理者（あなた）専用。

> ⚠️ **`config.ini` には Gemini APIキー が入っている**。配布先＝そのキーで API を叩ける = キーが漏れたら誰でも使える状態になることを認識した上で配ること。本格運用時は中継サーバー方式に切り替える（実装プランあり）。

---

## ステップ 1：配布フォルダを作る

1. デスクトップ（または D ドライブ）に **新しいフォルダ** を作る。名前は何でもOK、例：`Chatbot配布用_20260620`。

2. このフォルダの中に以下をコピー（先に `01_admin-setup-guide.md` のステップ6まで完了している前提）：

   **コピー元 → コピー先**：

   | コピー元 | 配布フォルダ内のどこに置くか |
   |---|---|
   | `notebook-claude-prototype-gemini-demo\dist\Chatbot.xlsm` | 直下 |
   | `C:\Users\あなた\AppData\Local\InternalNotebookLM\config.ini` | 直下 |
   | `C:\Users\あなた\AppData\Local\InternalNotebookLM\disclaimer.txt` | 直下 |
   | `C:\Users\あなた\AppData\Local\InternalNotebookLM\index\` フォルダ丸ごと | 直下に `index\` |

   `%LOCALAPPDATA%` フォルダの開き方が分からない場合は、**Windowsキー + R** → `%LOCALAPPDATA%\InternalNotebookLM` を貼り付け → Enter で開けます。

3. 完成形：

   ```
   Chatbot配布用_20260620\
     ├ Chatbot.xlsm
     ├ config.ini             ← APIキー入り（重要）
     ├ disclaimer.txt
     ├ README.txt             ← 次のステップで作る
     └ index\
         ├ manifest.json
         ├ embeddings.bin
         └ chunks.json
   ```

---

## ステップ 2：README.txt を作る（受け取った人がやることを書く）

配布フォルダの中で **右クリック → 新規作成 → テキスト ドキュメント** → `README.txt` という名前にする。
ダブルクリックで開いて、以下の内容をそのまま貼り付けて保存：

```
====================================================================
社内ナレッジ Q&A ボット (デモ版) - セットアップ手順
====================================================================

このフォルダの中身を以下の手順で1回だけ設定すれば、
あとは Chatbot.xlsm をダブルクリックで使えるようになります。

所要時間: 5〜10分

【ステップ1】 設定フォルダを開く（または作る）
----------------------------------------------------------
1. キーボードの「Windowsキー + R」を同時に押す
2. 開いた小窓に以下をコピペ → OK
       %LOCALAPPDATA%
3. エクスプローラーが開くので、その中に
   「InternalNotebookLM」 という名前のフォルダを新規作成する
   （既にあればそれを使う）

【ステップ2】 設定ファイルとデータをコピーする
----------------------------------------------------------
このフォルダの中の以下を、ステップ1で作った
「InternalNotebookLM」フォルダにコピーする：

  ・ config.ini       （1個のファイル）
  ・ disclaimer.txt   （1個のファイル）
  ・ index            （フォルダ丸ごと）

【ステップ3】 Chatbot.xlsm を開く
----------------------------------------------------------
1. このフォルダの「Chatbot.xlsm」をダブルクリック
2. 上に黄色いバーで「セキュリティの警告」が出たら
   「コンテンツの有効化」をクリック
3. 初回のみ「部署名」「役割」を聞かれるので入力

【ステップ4】 使い方
----------------------------------------------------------
・ 黄色い質問入力欄に質問を書いて「> 送信」ボタンを押す
・ 30〜60秒で AI 回答と出典が表示される
・ 回答は参考情報。最終判断は必ずアンダーライターへ確認

【注意】
----------------------------------------------------------
・ 質問に契約番号・氏名・電話番号などの個人情報を含めない
・ このフォルダの中身を他人に再配布しない（API キーが入っている）

【困ったときは】
----------------------------------------------------------
[配布した人=あなた]の連絡先を書いておくこと
例: 引受第1部 ○○ (内線XXXX) まで連絡してください
====================================================================
```

最後の連絡先欄は **必ずあなたの内線または連絡先に置き換えて** ください。

## ステップ 3：配り方を選ぶ

### 案A：USBメモリで配る（5〜10人の少人数ならこれが一番楽）

1. USBメモリに `Chatbot配布用_20260620` フォルダを丸ごとコピー。
2. 営業担当者に手渡し → 「USBの中身を自分のデスクトップにコピーして、README.txt を読んでね」と伝えるだけ。

### 案B：社内共有フォルダ・OneDrive・SharePointに置く（10人以上）

1. 共有フォルダに `Chatbot配布用_20260620` フォルダを丸ごとアップロード。
2. 営業担当者にリンクを送る → 「中身をデスクトップにコピーして、README.txt を読んでね」と伝える。

> ⚠️ **「共有フォルダから直接 Chatbot.xlsm を開く」のは避ける**。マクロが信頼できない場所として警告を出したり、index ファイルが読めなかったりする。**必ず各自のPCにコピーしてもらう**。

### 案C：本格運用（情シス経由でグループポリシー配布）

将来的に全社展開する場合は、情シスに以下を依頼：
- `%LOCALAPPDATA%\InternalNotebookLM\` を **信頼できる場所** に追加
- VBAプロジェクトに **デジタル署名** を付与
- **GPO（グループポリシー）** で `Chatbot.xlsm` と `index\` を全PCに配布
- APIキーは **中継サーバー（Azure Functions）経由** に切り替え（クライアント側にキーを置かない）

これは `docs/architecture.md` の Mode A 設計に沿って実装します。

## ステップ 4：配り終わったあとにやること

### コスト管理
- Google AI Studio で Gemini API の **月次予算アラート** を設定（推奨：月X円）
- レート制限：1ユーザー1日100回、1時間30回 を `config.ini` の `[rate_limit]` セクションで調整可

### キーの定期ローテーション
- 3ヶ月に1回くらいで Gemini API キーを差し替える
- 新キー発行 → 配布フォルダの `config.ini` を差し替え → 旧キー削除 → 全員に再配布

### 利用状況の確認
- 営業担当者の使用ログは `%LOCALAPPDATA%\InternalNotebookLM\usage_buffer.csv` に各自溜まる
- SharePoint 集約版が必要なら `config.ini` の `[logging] remote_url` を設定

### ナレッジを追加・削除したい
- 追加/削除したいPDFと **「これを足して」「これは外して」** をClaude（僕）に伝える
- 新しい `index\` フォルダを受け取って、各営業PCの `%LOCALAPPDATA%\InternalNotebookLM\index\` を上書き
- 配布フォルダの `index\` も上書きしておけば次の新人にも対応可

---

## 配布後 1〜2週間で確認したいこと

| 項目 | 確認方法 |
|---|---|
| 全員のPCで動いてるか | 各人に「1回でも使えた？」と聞く |
| 回答精度に不満がないか | 「答えが間違ってた質問」を集める → ナレッジ追加・チューニング材料に |
| コストが想定内か | Google AI Studio の月次使用量を確認 |
| キーが漏れてないか | `config.ini` を社外（個人メール等）に転送した人がいないか |
