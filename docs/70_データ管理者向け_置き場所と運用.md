# データの置き場所と運用（データ作成・更新担当者むけ）

「同期用のデータはどこに置く？ファイル名の決まりは？」への回答。
**この製品には性質の違う置き場所が3つあります。** まず自分がどれをやるのかを
決めてください。混ぜると事故ります。

| | 何のため | 誰がやる | 置き場所 |
|---|---|---|---|
| **A. 本棚フォルダ** | 自分（または自部署）の資料を自動で取り込む | 各利用者・データ担当 | 任意のフォルダ1つ |
| **B. 部門の公式ナレッジ** | 部門全員へ同じ正典を配る | 部門の発行担当 | 共有サーバーの決まった場所 |
| **C. 初期ナレッジ** | 配布ファイルに最初から入れておく | ビルド担当のみ | リポジトリ（利用者は触らない） |

以下、A と B の具体的な決まりです。

---

## A. 本棚フォルダ（いちばん多い用途）

指定したフォルダにファイルを置くだけで、起動時と同期時に自動で取り込まれます。
消せば本棚からも消えます。

### 置き場所

`config` シートの `shelf_folder` に**フォルダのパスを1つ**書きます。

```
例) \\サーバー名\部門共有\Nexus資料\
例) C:\Users\<自分>\OneDrive\Nexus資料\
```

> `config` シートの開き方: このアプリは通常起動中シートタブを隠しているため、
> 「タブを右クリック→再表示」はできません。①アプリの「🚪保存して閉じる」で
> いったん閉じる →②再度開く際、セキュリティの警告バーで「コンテンツの有効化」を
> 押さずに開く(マクロを無効のまま開く)→③タブが見える状態になるので右クリック
> →「再表示」→ `config` を選ぶ。変更したら上書き保存し、次に開くときは通常どおり
> マクロを有効化してください(VBEに慣れている場合は、`Alt+F11`→`Ctrl+G`で
> `modConfig.SetValue "shelf_folder", "パス"` を実行する方法でも設定できます)。

### 決まりごと

| 項目 | 仕様 |
|---|---|
| **対応形式** | `txt` `md` `csv` `pdf` `docx` `doc` `xlsx` `xls` `xlsm` |
| **ファイル名** | **自由**。ただし下の「同名は禁止」に注意 |
| **サブフォルダ** | **読みません。第1階層だけ**です |
| **上限** | チャンク20,500件（≒資料150〜200冊相当）。ただし下の「量と速さ」も必ず読んでください |

### 量と速さ（正直な話）

**資料が増えるほど1回の質問は遅くなります。** 検索は本棚の全チャンクを見るためです。

| 本棚の規模 | 1回目の質問 | 2回目以降 |
|---|---|---|
| 〜1,000件 | ほぼ待ちなし | ほぼ待ちなし |
| 5,000件前後 | +数秒（準備表示が出ます） | 準備は不要 |
| 20,000件前後 | +十数秒（準備表示が出ます） | 数秒 |

- 上の表は**実装から見積もった値**です。**実機での測定はこれから**行います
  （手順は `docs/45_実機スモークテスト手順.md` の項目13）。数字が違ったら
  実測値でこの表を書き換えます。開発環境では待ち時間を測れないため、
  ここに書ける確かな数字は実機の測定結果だけです。
- 「1回目」が長いのは、ブックを開いてから最初の質問のときに、ベクトルを
  1回だけまとめて読み込むためです（画面に「🔍 検索の準備をしています…」が
  出ます）。以降の質問はその結果を使い回します。資料を追加・削除・
  再ベクトル化すると、次の質問でもう一度だけ準備が入ります。
- なお、この待ち時間は**AIの応答時間とは別**です（AIの応答は本棚の量に
  よりません）。実際の体感 = 準備 + 検索 + AI応答 になります。
- 5,000件を超えると、粗い絞り込み（`binary_rag_auto`・既定ON）が自動で
  働いて検索を短縮します。切りたい場合は `config` の `binary_rag_auto` を
  `FALSE` にしてください（そのぶん遅くなります）。

### ⚠ 注意点（実際に踏む順）

**1. 同じファイル名を2つ作らない（最重要）**

このアプリは資料を**ファイル名で識別**します。
別のフォルダから同じ名前のファイルを入れようとすると、**エラー E0504 で止まります**。

```
NG)  2024年度\料率表.xlsx  と  2025年度\料率表.xlsx
OK)  料率表_2024年度.xlsx  と  料率表_2025年度.xlsx
```

黙って上書きせずエラーで止める仕様です（気づかないうちに古い資料が
消えるより、止まったほうが安全なので）。**年度・版をファイル名に必ず入れてください。**

**2. 同じ名前で中身を差し替えると「置き換え」になる**

同名・同じパスのファイルを更新すると、古い内容は消えて新しい内容に**置き換わります**。
これは正しい動作です。改定版を配るときはこの方法が最短です。

**3. アプリ本体（MyBookshelf.xlsm）と同じフォルダでも大丈夫**

自分自身は自動で除外します（2026-07-28に対応）。
ただし**分けることを強く推奨**します。理由は次項。

> **2026-09-04 R35 F3b: ランチャー(bat)経由で開くと、実行中のアプリ本体は
> `D:\MyBookshelf\` にある(OneDrive上の原本のコピー)。** `shelf_folder` を
> 「アプリ本体と同じフォルダ」にする場合は、**OneDrive側(zipを展開した
> フォルダ)を指定してください**。`D:\MyBookshelf\` を指定すると、
> シャットダウンでフォルダごと消えることがあります。共有サーバー
> (`\\...`)や部門共有をそのまま使う場合は影響ありません。

**4. Officeの一時ファイルは自動で無視します**

誰かが Word や Excel でファイルを開いていると、同じフォルダに
`~$資料名.docx` という一時ファイルができます。これは自動で除外します
（同じく 2026-07-28 に対応）。

**5. SharePoint / Teams の URL は指定できません**

`https://...` の形式は読めません。**エクスプローラーで開ける形のパス**
（`\\サーバー\...` または `C:\...`）にしてください。
OneDrive / SharePoint は**同期してローカルにフォルダとして見える状態**にすれば使えます。

**6. 置いてよい資料・いけない資料**

- 個人情報を含む資料は置かない（**PII検査は既定オフです**。`config` の `pii_scan_enabled` を
  `TRUE` にしたときだけパック書き出し前に走り、見つかれば書き出しを中止します。
  いずれにせよ取込そのものは止まりません）
- 機密区分の高い資料を入れると、**その .xlsm 自体が同じ機密区分**になります

**7. 画像だけのPDF（スキャン）は取り込めません**

文字が埋め込まれていないPDFは中身を読めず、`🖼 画像PDF` の状態になります。
OCR済みのPDFにしてください。

## B. 部門の公式ナレッジ（正典）を配る

部門の全員へ同じ内容を配りたい場合はこちら。**発行担当だけが行います。**

### 置き場所（構造は固定）

`config` の `nexus_share_path` の下に、この形で作られます。

```
<nexus_share_path>\
  └ channels\
      └ 商品部\                ← フォルダ名 = 部門名。そのまま画面に出ます
          ├ pack.xlsx          ← 正典パック本体（アプリが作ります）
          ├ version.txt        ← 版番号（アプリが作ります）
          └ _archive\          ← 過去版（自動退避）
```

### 決まりごと

- **手作業でファイルを置かないでください。** 画面の「正典を発行」から出します
  （版番号付けと過去版の退避が自動で走るため。PII検査は既定オフで、
  `config` の `pii_scan_enabled` を `TRUE` にしたときだけ走ります）
- **フォルダ名＝部門名**。利用者の画面にそのまま表示されます
- 発行には `config` の `publish_key`（管理者パスワード）が必要です
- 書き込み権限は**発行担当だけ**に絞ってください（誤上書き防止）

### ⚠ 正典に入れてよいもの

**確認済みのQ&Aと要点だけ**にしてください。100ページの約款を丸ごと入れると、
1部門でチャンクを数千消費して全体が破綻します。
原文が必要な人は各自の本棚（A）に入れます。

### 事故ったとき

発行画面の「**直前の版に戻す**」で戻せます。利用者は次回起動時に自動で旧版へ戻ります。
承認フローを挟んでいないのは、**担当者ひとりで数十秒で止められるようにするため**です。

## そのまま同僚に送れる短い回答

> **置き場所**: `config` シートの `shelf_folder` に、フォルダのパスを1つ書いてください。
> そのフォルダに資料を置くだけで自動で取り込まれます。消せば本棚からも消えます。
>
> **ファイル名**: 自由です。ただし**同じファイル名を2つ作らないでください**
> （ファイル名で資料を識別しているため、エラーで止まります）。
> 年度や版は必ずファイル名に入れてください。例）`料率表_2025年度.xlsx`
>
> **フォルダ**: **サブフォルダは読みません。第1階層に直接置いてください。**
>
> **アプリと同じ場所でもOK**です（自分自身とOfficeの一時ファイルは自動で除外します）。
> ただし整理のため分けることをおすすめします。
>
> **対応形式**: PDF / Word / Excel / テキスト。
> スキャンしただけの画像PDFは読めないのでOCR済みにしてください。
>
> **注意**: SharePointのURL（https://…）は指定できません。
> エクスプローラーで開けるパス（`\\サーバー\…`）にしてください。
