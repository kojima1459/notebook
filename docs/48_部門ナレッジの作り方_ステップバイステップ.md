# 部門ナレッジ（正典）の作り方 ― 完全手順書

> **この文書だけで最後まで終わります。** 他の文書を見に行く必要はありません。
> **想定している材料**: 「教えてBOX」「教えてNavi」の**過去照会データのCSV**
> **所要時間**: 初回 90分（うち待ち時間30分）／2回目以降 20分

---

## 全体の流れ（この6ステップだけです）

```
STEP 1  共有フォルダを設定する                      （5分・初回のみ）
STEP 2  CSVを開いて、要らない列を消す               （15分）
STEP 3  数式1本で「正典の形」に変える               （10分）
STEP 4  Wordに貼って、txtで保存する                 （5分）
STEP 5  アプリに取り込む                            （15分・待ち時間）
STEP 6  発行する                                    （5分）
```

**⚠️ 先に1つだけ知っておいてください。**

> ## CSVは、そのまま取り込んではいけません。

理由は §付録A に書きましたが、**そのまま入れると「答えの途中でぶつ切りになった記憶」ができて、まともに答えられなくなります。** STEP 3〜4 の変換が、この手順書の心臓部です。

---

# STEP 1　共有フォルダを設定する（初回だけ）

1. `MyBookshelf_発行者用.xlsm` をダブルクリックで開く
2. 黄色い帯で「セキュリティの警告」が出たら **「コンテンツの有効化」**
3. 数秒待つと画面が組み上がります
4. 右上の **❓ヘルプ** → **「⚙ 共有フォルダ設定」**
5. 開発担当から伝えられた**共有フォルダのパス**を貼り付けて **OK**

> 存在しないパスを入れると「そのフォルダが見つかりませんでした」と出て、設定は変わりません。それが正常な動きです。

---

# STEP 2　CSVを開いて、要らない列を消す（15分）

## 2-1. CSVをExcelで開く

過去照会データのCSVをダブルクリックで開きます。だいたいこんな形のはずです。

| A | B | C | D | E | F |
|---|---|---|---|---|---|
| 受付日 | 部署 | 氏名 | 質問内容 | 回答内容 | 回答者 |
| 2026-01-05 | 商品部 | 山田太郎 | 経費精算の締切はいつ… | 毎月5日17時まで… | 佐藤 |
| 2026-01-06 | 商品部 | 鈴木花子 | 出張申請は何日前… | 5営業日前まで… | 田中 |

**列の並びは、あなたのCSVに合わせて読み替えてください。** 大事なのは次の2つだけです。

- [ ] **質問が入っている列は、どれか**（上の例では **D列**）
- [ ] **回答が入っている列は、どれか**（上の例では **E列**）

**この2つの列の記号（アルファベット）を、メモしておいてください。** STEP 3 で使います。

## 2-2. ⚠️ 個人情報が入っている列を、列ごと削除する

> **これは必ずやってください。** 発行すると部門の全員に配られます。**個人情報の自動チェックは、いまオフになっています**（誤検知で正しい資料の発行まで止まる事故があったため）。**最後の砦はあなたの目です。**

消す列の例：

| 消すもの | 理由 |
|---|---|
| **氏名**（照会者・回答者とも） | 「誰が聞いたか」は答えに不要 |
| **社員番号・メールアドレス・電話番号** | 個人情報 |
| **取引先名・契約者名・口座番号** | 社外の個人情報。最も危険 |
| 受付日・受付番号 | 答えに不要（消さなくても害はない） |

**列の消し方**: 列の記号（A、B…）を右クリック → **[削除]**

> **消したあと、質問列と回答列の記号がズレます。** 消したあとの記号をメモし直してください。

## 2-3. 「答えになっていない行」を消す

過去照会データには、そのまま使えない行が必ず混ざっています。

**消す行**

- 回答欄が**空**の行
- 回答が「担当部署へ転送しました」「お電話しました」など、**答えが書かれていない**行
- 「システムが重い」「ログインできない」など、**その時だけの障害対応**
- **同じ質問が何十件もある**もの → **1件だけ残して、あとは消す**

> **迷ったら消してください。** 10件の良い正典は役に立ちますが、100件の玉石混交は「使えないツール」という評価になります。**最初は30〜50件で十分です。**

## 2-4. 残った行を仕上げる

残した行の**回答列**を見て、次の3点を直します。ここが正典の品質そのものです。

| 直すこと | 例 |
|---|---|
| **その場限りの言葉を消す** | 「先ほどお電話した件ですが、」→ 削除 |
| **例外・条件を書き足す** | 「毎月5日まで」→「毎月5日の17時まで。**5日が土日祝なら前営業日に繰り上がります。** 過ぎた分は翌月払いです」 |
| **いつ時点の情報かを書く** | 末尾に「（経理部確認・2026年9月時点）」 |

> **「毎月5日」だけで終わらせないでください。** 土日のとき・過ぎたときが書いていないと、結局その人が誰かに聞きに来ます。**聞かれなくなるまで書く**のが正典です。

# STEP 3　数式1本で「正典の形」に変える（10分）

ここが心臓部です。**やることは、空いている列に数式を1つ入れるだけです。**

## 3-1. 空いている列を1つ用意する

データの右側の、**何も入っていない列**を使います（例では G 列とします）。

## 3-2. 数式を貼る

**G2** のセルに、次の1行をそのまま貼り付けます。

```excel
="# "&D2&"@@"&E2
```

**`D2` と `E2` は、あなたのCSVに合わせて書き換えてください。**

- `D2` … **質問**が入っている列の記号 + 2
- `E2` … **回答**が入っている列の記号 + 2

> 例：質問がB列・回答がC列なら `="# "&B2&"@@"&C2`

## 3-3. 下までコピーする

1. **G2** をクリック
2. セルの**右下の角の小さい四角**をダブルクリック（データの最終行まで一気に埋まります）

結果はこうなります。

| G |
|---|
| `# 経費精算の締切はいつですか？@@毎月5日の17時までです。5日が土日祝なら…` |
| `# 出張申請は何日前までですか？@@出発の5営業日前までです。…` |

> **`# ` と `@@` は、消さないでください。**
> `# `（半角シャープ + 半角スペース）は「ここから新しい話題」という**区切りの目印**、`@@` は次のステップで**改行に置き換える目印**です。理由は §付録A に書きました。
>
> **⚠️ 全角の「＃」ではなく、半角の「#」です。** 全角だと目印として認識されません。

## 3-4. G列をコピーする

1. **G列の記号（G）をクリック**して列全体を選択
2. **Ctrl + C**

# STEP 4　Wordに貼って、txtで保存する（5分）

## 4-1. Wordに「文字だけ」貼り付ける

1. **Word** を新規で開く
2. **Ctrl + V** で貼り付ける
3. 貼り付けた直後、右下に小さな **[貼り付けのオプション]** ボタンが出ます。それをクリック
4. **「テキストのみ保持」**（**A** のアイコン）を選ぶ

> **この手順を飛ばすと、Wordの「表」として貼り付いてしまい、あとの処理が全部おかしくなります。** 必ず「テキストのみ保持」を選んでください。

## 4-2. `@@` を改行に置き換える

1. **Ctrl + H**（置換の画面が開きます）
2. **検索する文字列**: `@@`
3. **置換後の文字列**: `^p`  ← **半角のハット記号 + 半角の p**
4. **[すべて置換]** をクリック

画面がこうなれば成功です。

```
# 経費精算の締切はいつですか？
毎月5日の17時までです。5日が土日祝なら前営業日に繰り上がります。過ぎた分は翌月払いです。（経理部確認・2026年9月時点）
# 出張申請は何日前までですか？
出発の5営業日前までです。航空券の手配が必要な場合は10営業日前を推奨します。（総務部確認・2026年9月時点）
```

**質問の行が `# ` で始まり、その下に答えが1行で続いている。** この形になっていればOKです。

## 4-3. txt で保存する

1. **[ファイル]** → **[名前を付けて保存]**
2. **ファイルの種類**: **「書式なし (*.txt)」** を選ぶ
3. ファイル名: `商品部_正典_2026-09.txt` のように、**部門名と年月**を入れる
4. 保存場所: **どこでも構いません**（Dドライブでも、デスクトップでも、自分のフォルダでも。§付録B）
5. 「ファイルの変換」という画面が出たら、**そのまま [OK]**（文字コードは自動で判別されます）

**これで「配れる中身」が完成です。**

---

# STEP 5　アプリに取り込む（15分・ほとんど待ち時間）

1. `MyBookshelf_発行者用.xlsm` を開く
2. チャット画面の入力欄の左にある **「📁 資料を入れる」** をクリック
3. STEP 4 で保存した `.txt` を選ぶ
4. **待ちます**（件数によって数分〜十数分。進み具合が画面に出ます）

取り込みが終わると、こう出ます。

```
✅ 資料を取り込みました。
これで、この資料の中身について「どのページに書いてあるか」まで付けてお答えできます。
```

## 取り込めたか、その場で確かめる

**発行する前に、必ず自分で1つ質問してください。**

1. チャットの入力欄に、**正典に入れた質問をそのまま**打つ（例:「経費精算の締切はいつですか？」）
2. 送信

**見るところ**

- [ ] 書いたとおりの答えが返ってくる
- [ ] 回答の下に **「出典」のボタン**が出る
- [ ] 出典ボタンを押すと、**あなたが書いた文章**が出る

ここでうまくいかない場合は、**発行せずに** §困ったとき を見てください。

# STEP 6　発行する（5分）

## 6-1. 発行ボタンを押す

1. 画面上部の **「ナレッジ」** タブを開く
2. **「📤 正典を発行」** ボタンをクリック

> **このボタンが出ていない場合**、一般配布版（`MyBookshelf.xlsm`）を開いています。`MyBookshelf_発行者用.xlsm` の方を開き直してください。

## 6-2. 部門名を入れる

こんな画面が出ます。

```
部門の公式ナレッジ(正典)を発行します。

【ボタン1回で完了します】
  今の本棚の内容がそのまま部内へ配られます。
  保存先を選ぶ操作は要りません。

【まちがえても大丈夫です】
  前の版は自動で保存されます。もう一度この画面を開いて
  「いいえ」を選ぶと、直前の版に戻せます。

発行する部門名を入力してください(例: 商品部)。
※ 更新するときも、前と同じ名前を入れてください。
```

部門名（例: `商品部`）を入れて **OK**。

**決まりごと**

- **実在する部門の名前をそのまま**使う
- **「全社共通」は作らない**（管理する部署が決まらず必ず破綻します）
- **更新のときは前と同じ名前**（違う名前を入れると別の部門として新規作成されます）
- `/` `\` `:` `*` `?` `"` `<` `>` `|` は使えません（入れると発行前に止めてくれます）

## 6-3. 発行キーを入れる

```
発行キーを入力してください。
(分からない場合は、このツールの管理担当者に確認してください)
```

開発担当から伝えられた合言葉を入れて **OK**。

> 違うと「発行キーが違います。発行は行いませんでした。」と出て、**何も起きません**（壊れません）。
> **この合言葉を部門の人に教えないでください。**

## 6-4. 確認画面を読む ←【ここが本番です】

```
【商品部】として発行します。

  発行する件数: 240 チャンク(自分で入れた資料のみ)
  配置先: \\ファイルサーバ\共有\NexusAgent\channels\商品部\pack.xlsx

【発行前の確認】
  ・正典には『確認済みQ&A・要点』を入れてください
  ・(個人情報の自動チェックは現在オフです)

【この部門の発行履歴】
  ...

このまま発行しますか?
(「いいえ」= 直前の版に戻す操作に進みます)
```

**必ず確認すること**

- [ ] **部門名は合っているか**
- [ ] **件数が想定どおりか**（50件のQ&Aなら 50〜100 チャンクくらい。**数千と出たら異常**です。§困ったとき へ）
- [ ] 配置先のパスが合っているか

> **件数が本棚の総数より少ないのは正常です。** 発行対象は「自分で入れた資料のみ」で、他部門から受け取った正典は自動で除かれます（他部門のものを自分の名前で再配布しないため）。

**「はい」** を押すと発行されます。数十秒かかります。

## 6-5. 完了

```
発行しました。

  部門: 商品部
  件数: 240 チャンク
  版: 20260901-153042|2026-09-01|山田

部内の全員が、次にファイルを開いたとき Hub に「更新があります」と
出ます。それを押すと受け取れます(自動では入りません)。
内容に誤りが見つかったら、この画面から「いいえ」で戻せます。
```

**自動では届きません。** 部内の全員が、次にファイルを開いたとき Hub の画面に「📡【商品部】に更新があります」というお知らせが出ます。それに気づいた人が自分で **「📡 部門チャンネル」**（または、お知らせそのもの）を押した時点で、その人の本棚に取り込まれます。押すまでは何も変わりません。

# 🆘 間違えて配ってしまったとき（数十秒で止まります）

**開発担当への連絡は要りません。あなた1人で止められます。まず止めてください。**

1. **「📤 正典を発行」をもう一度押す**
2. **同じ部門名**を入れる
3. 発行キーを入れる
4. 確認画面で **「いいえ」** を選ぶ ← ここです
5. 戻す版が表示されるので **OK**

```
戻しました。全員が次に Hub のお知らせを押すと、この版に置き換わります。
```

**メッセージのとおり、置き換わるのはお知らせを押した人からです。** 部内の全員が、次にファイルを開いたとき Hub に「更新があります」というお知らせが出ます。それに気づいた人が **「📡 部門チャンネル」** を押した時点で、その人の本棚が前の版に置き換わります（誤った内容はそこで消えます）。押すまでは各PCとも変わりません。

### ⚠️ 戻せるのは「1つ前」までです

一度巻き戻した直後にもう一度戻そうとすると、警告が出ます。

```
【商品部】は直前に巻き戻しを実行済みです。
ここでもう一度戻すと、取り下げたはずの版が全員へ配られます。
```

**戻すボタンは「行ったり来たり」します。** 2回押すと、取り下げたはずの誤った版が復活します。
さらに直したいときは、**正しい内容で発行し直してください**（戻すのではなく、進んで直す）。

# 🔁 2回目以降の更新（20分）

**初回とまったく同じです。** ただし2つだけ違います。

1. **部門名は前と同じもの**を入れる
2. 新しいtxtを取り込む前に、**古い方を本棚から消す**（「マイ本棚」タブで古いファイルを 🗑）
   - 消さないと、古い内容と新しい内容が**両方**配られます

利用者側では、次にファイルを開いたとき Hub のお知らせに **「【商品部】に更新があります」** と出ます。押すと入れ替わります。

> **更新の頻度は週1回程度で十分です。** 版が変わると全員がダウンロードするので、毎日出すと共有フォルダの負荷になります。急ぎの訂正だけ随時。

## ネタ切れしない育て方

アプリの **「💡 みんなの困りごと」** を開くと、**答えが見つからなかった質問**が溜まっています。
**そこが、そのまま「次に書くべきネタの一覧」です。** 利用者が勝手に集めてくれます。

# 🔧 困ったとき

| 症状 | 原因 | 直し方 |
|---|---|---|
| **件数が数千と出た** | CSVをそのまま取り込んでいる／古い資料が本棚に残っている | 「マイ本棚」で本棚の中身を確認。CSVそのものが入っていたら削除し、STEP 3〜4 をやり直す |
| 書いたはずのことが出てこない | 質問の言い回しが、書いた言い回しと違いすぎる | 回答の文中に**別の言い方も入れる**（「経費精算」＋「立替精算」＋「精算」） |
| **関係ない答えが混ざる** | `# ` が付いていない／全角の「＃」になっている | Wordのファイルを開き、質問行の先頭が**半角の `# ` + 半角スペース**か確認 |
| 答えが途中で切れる | 1件が長すぎる（1,800字超） | その1件を2件に分ける |
| Wordに貼ったら表になった | 「テキストのみ保持」を選び忘れ | STEP 4-1 からやり直す |
| 置換したのに改行されない | 置換後の文字列が `^p` になっていない | 半角のハット `^` と半角の `p`。全角だと効きません |
| 「📤 正典を発行」が出ない | 一般配布版を開いている | `MyBookshelf_発行者用.xlsm` を開く |
| 「発行キーが違います」 | 全角/半角、前後の空白 | 開発担当へ確認 |
| 「共有フォルダが未設定か、接続できません」 | パス未設定／VPN未接続 | ❓ヘルプ →「⚙ 共有フォルダ設定」を確認 |
| 「発行できませんでした」＋権限の案内 | 共有フォルダへの**書き込み**権限がない | IT部門へ依頼 |
| 「いま別の方が発行中です」 | 同時発行の見張り | **数分待ってもう一度**。壊れていません |
| **利用者に違う部門名で通知が出る** | 不具合の可能性 | **開発担当へ報告してください** |

## 開発担当への連絡のしかた

**「不具合か分からない」まま送ってください。判断はこちらでします。**

```
【何をしたか】 例：商品部で2回目の発行をした
【どうなったか】例：発行は成功したが、利用者側に「人事部に更新があります」と出た
【どう思ったか】例：違うものを配ったのではと不安になった
```

エラーが出たら、「ホーム」タブ右上の **「🩺 診断」** を押し、出てきた `diag_report` シートを**そのままスクリーンショット**して送ってください。

# 🚫 やってはいけないこと

| やってはいけないこと | 何が起きるか |
|---|---|
| **CSVをそのまま取り込む** | 答えの途中でぶつ切りになり、まともに答えられなくなる（§付録A） |
| **規程・マニュアルPDFを丸ごと入れる** | 容量を数千個食い、**部門全員のツールが使えなくなる**（§付録C） |
| **発行者用ファイルを部門の人に配る** | 受け取った全員が正典を上書きできてしまう |
| **発行キーを部門の人に教える** | 同上 |
| 「たぶんこうだと思う」を入れる | **間違いが部門全員に配られる。** 人が聞きに来るより悪い |
| 氏名・電話番号・取引先名を残す | 個人情報が部門全員に配られる。**自動チェックはオフです** |
| 「全社共通」チャンネルを作る | 管理する部署が決まらず必ず破綻する |
| 共有フォルダの `pack.xlsx` を手で開いて編集する | 版番号と中身が食い違う。**必ずアプリから発行する** |
| `_archive` フォルダを手で消す | 戻せなくなる |
| 巻き戻しを2回続けて押す | 取り下げたはずの誤った版が復活する |
| **完璧な100件を目指して着手しない** | **いつまでも誰にも届かない。30件で出して、あとから育てる** |

# 付録A　なぜCSVをそのまま入れてはいけないのか

**読まなくても手順は実行できます。** 理由が知りたい方向けです。

このアプリは、取り込んだ文章を**約700文字ずつの「かたまり」に切って**覚えます。質問が来ると、かたまり単位で探して、見つかったかたまりをAIに渡して答えさせます。

**問題は「どこで切るか」です。** アプリは**行の先頭を見て**、話題の変わり目を判断しています。

| 行の形 | 扱い |
|---|---|
| `# 経費精算の締切は？` | **話題の変わり目**（ここで切る） |
| `2026-01-05,商品部,締切は？,5日です` | ただの本文（切る目印にならない） |
| タブ・半角スペース3つ以上・`|` を含む行 | 表の行として扱う |

CSVには `# ` がありません。**目印がゼロなので、アプリは文字数だけを見て700文字ごとに機械的に切ります。** その結果こうなります。

```
【かたまり1】…出張申請は何日前までですか？ 出発の5営業日前まで
【かたまり2】です。航空券の手配が必要な…  ← 質問が付いていない断片
```

**質問と答えが分断された記憶**ができあがり、「出張申請は何日前？」と聞いても、答えの後半だけが出てきたり、隣の全然違うQ&Aが混ざったりします。

`# ` を1つ付けるだけで、**1問1答がまるごと1つのかたまりに収まります。** これが STEP 3 の数式がやっていることの全てです。

**ついでに知っておくと得すること**

- 1つのかたまりの上限は **1,800文字**。1問1答は **400〜700文字**が理想
- 文字コード（Shift-JIS / UTF-8）は**自動で判別される**ので、気にしなくて構いません
- `@@` を使うのは、Excelのセルの中で改行すると、コピーしたときに `"` が勝手に付いて `# ` が先頭でなくなってしまうためです。一度 `@@` で逃がしてから、Wordで改行に戻しています

# 付録B　ファイルの置き場所（Dドライブでも大丈夫です）

置き場所が2種類あって混同しやすいので、分けて書きます。

| | 何を置くか | どこに置くか | Dドライブでいい？ |
|---|---|---|---|
| **A. 材料ファイル** | CSV、STEP 4 で作った `.txt` | **どこでも** | ✅ **問題なし** |
| **B. 共有フォルダ** | 発行された正典（アプリが自動で置く） | **全員が読み書きできるネットワーク上** | ❌ **不可** |

**なぜBはDドライブではだめか**: Dドライブは**そのPCの中だけ**にあります。他の人からは見えないので、そこに正典を置いても誰にも届きません。

**Bのフォルダ構成は、材料をどこに置いても一切変わりません。** アプリが自動で作ります。**手で作る必要はありません。**

```
<共有フォルダ>\                 ← ❓ヘルプ →「⚙ 共有フォルダ設定」で指定する1箇所だけ
    channels\
        商品部\
            pack.xlsx           ← 正典の本体
            version.txt         ← 版番号
            publish_log.txt     ← 誰がいつ何件出したかの記録
            _archive\           ← 過去版（戻すときに使う）
        人事部\
            ...
```

> **全部門の正典を「1つの場所の下」にぶら下げます。** 部門ごとに別の共有フォルダを指定することはできません（各PCは1つの設定値だけを見て、その下の `channels\<部門名>\` を探すため）。
> **権限**: 全員に**読み書き両方**が必要です（読み取り専用では動きません）。

# 付録C　なぜ「原文を丸ごと」入れてはいけないのか

このツールが覚えられる「かたまり」の上限は、**1人あたり20,000個**です。

| | 使う量 |
|---|---|
| Q&A形式の正典 500件 × 6部門 | 3,000〜6,000個 |
| 各自が自分で入れる資料 20冊 | 〜2,800個 |
| **合計** | **6,000〜9,000個**（上限20,000に余裕あり） |

ところが**100ページの規程を丸ごと入れると、それだけで1部門で数千個**。6部門が同じことをすると上限を超え、**部門全員のツールが使えなくなります**。

**正典に入れるのは「資料」ではなく「答え」です。** 原文が必要な人は、その人が自分の本棚に個別に入れます。

「ナレッジ」画面に **「本棚の使用量: 36%」** と出ています。**80%を超えると警告が出ます。** 勝手に消える仕組みはないので、出たら見直してください。
