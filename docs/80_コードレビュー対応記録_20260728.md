## 2. 特に注意して見てほしい修正

### C-1 / H-14(チャンネル配信)— **移行処理が走ります**

修正前のビルドで部門チャンネルへつないだ端末には、消せないまま溜まった `pack:` タグのチャンクが残っています。放置すると「切り替えたのに前の部門の出典で答える」が直らないため、**起動時に一度だけ掃除** します(`modChannel.MigrateOriginNamespace`)。

- 対象: **チャンネルを一度でも同期したことがある端末のみ**
- 動作: `pack:` で始まる origin の行を全削除 → 全チャンネルのローカル版数をクリア → 次の同期で正しいタグで入れ直し
- **副作用**: 手渡しパック(`ImportPackDialog` で取り込んだもの)も同じ `pack:` 名前空間にいるため、一緒に消えます。本棚側に区別する手段が無いための割り切りです。消えた場合は **パックを再取込すれば戻ります**。
- 実行された事実は `usage_log` の `channel_origin_migration` に残ります。

> チャンネルを使っていない端末では何も起きません(フラグも立てず、次にチャンネルが見えたときに改めて判定します)。

### H-4(正典発行)— 発行される件数が変わります

発行は **`origin="self"`(自分で入れた資料)だけ** を書き出すようになりました。他部門を購読した状態で発行しても、他部門の正典は混ざりません。確認ダイアログの件数も「本棚の総数」から「実際に出る件数」に変えたので、**これまでより小さい数字が出ます**(正しい数字です)。

### H-5(感謝EXP)— pack_meta に列が増えます

`author_id` を追加しました。**新しく発行したパックから有効**です。既存の(author_id を持たない)パックは従来どおり表示名で宛先を作るため、過渡期は受け取り側が **両方のハッシュを走査** します(nonce があるので二重加算はしません)。

### M-6(ドメインチェック)— 即ワイプをやめました

不一致1回では消しません。既定で **3回連続** して初めて消します(`config domain_wipe_after_n_boots`、0以下なら決して消さない)。判定も NetBIOS 名だけでなく FQDN と両方を見て、全角カンマ・全角スペースを正規化します。

### M-25(チャットバブル保護)— 選択できなくなります

シート保護を `DrawingObjects:=True` に変えたため、**回答の吹き出しをクリックしても選択できません**。これは意図した変更です(以前は選択して Delete すると回答が消え、Ctrl+Z を無効化しているため復元できませんでした)。マクロ側の描画は `UserInterfaceOnly:=True` により従来どおり動きます。

### M-19(テレメトリ)— 集計側の想定が変わります

送信ファイルが `<uid>_<yyyymm>.txt` から **`<uid>.txt` の上書き** に変わりました。生涯累計のスナップショットを月別に置いていたため、2ヶ月目以降に同じ人の数字が月数ぶん合算され、利用者数・質問総数・節約時間が過大に出ていたためです。旧形式の自分のファイルは移行時に自動で片付けます。**集計スクリプトを別に持っている場合は、この変更に合わせてください。**

## 4. 実機で確かめること(このレビューでは検証できていない範囲)

レビューは macOS 上の静的解析です。以下はコード上は直っていますが、**Windows 実機での確認が必要**です。

1. **H-1 の二重Boot解消** — 2回目以降の起動で MsgBox が2回出ないこと。起動約1秒後に画面がちらつかないこと。
2. **H-1 の予約解除** — ブックを開いて数秒以内に閉じたとき、Excel が勝手に開き直さないこと。
3. **H-2 の画面重畳** — Hub タイルの上に旧「質問する」画面が重ならないこと。既知の「タブが常時表示されない」「位置がずれる」が再現しないこと。
4. **C-1 / H-14 の切替・更新配信** — テスト手順書 STEP5(切替)・STEP6(更新配信)が通ること。特に **A部門 → B部門 → A部門** と戻せること。
5. **移行処理** — 既にチャンネルへつないだ端末で、起動時に掃除が走り、その後の同期で正しく入り直すこと(`usage_log` の `channel_origin_migration`)。
6. **H-11 の COM 変更** — 取込中に Word のウィンドウが開かないこと。取込対象を開いた状態で取り込むと「閉じてから取り込んでください」と出て、**編集中のブックが閉じられない**こと。
7. **M-13 の Acrobat 経路** — Acrobat Pro のある端末で、Word 抽出に失敗した PDF が Acrobat 経由で読めること(従来は必ず失敗していました)。
8. **M-25 のシート保護** — 吹き出しがクリックで選択できないこと。かつ、回答・出典チップ・ボタンの描画が従来どおり出ること。
9. **L-19 の Ctrl+Enter** — テンキーの Enter でも送信できること。
