## R24-1 modVaultGallery の CompressFactor 旧式呼び出し【配布ブロッカー】

確定事実: R21H F3 で `CompressFactor` の引数を (viewH, need) → (viewH, needFixed, needVariable) へ変更した際、呼び出し3箇所のうち modHub(:139)・modDash(:243) は更新されたが **modVaultGallery.bas:337-338 だけ旧式2引数のまま取り残された**。実Excelでは「引数は省略できません」でギャラリー描画がコンパイル不能。LibreOffice Basic は引数数をコンパイル時に照合しないため検査をすり抜けた（LO死角その2）。

### FA-R24-1a 呼び出しのF3準拠化

modVaultGallery.bas:337-338 を F3 の意味論（固定=SYで縮まない要素/可変=SYで縮む要素）に従い分解:

```vb
modViewport2.SetScaleY modViewport2.CompressFactor(modViewport.ViewportHeight(), _
    cardT + rowsNeed * CARD_GAP + PAGER_H, _
    rowsNeed * CARD_H)
```

根拠: ギャラリーの行ピッチは `SY(CARD_H) + CARD_GAP`（cardH のみ SY 適用、CARD_GAP は非適用: :339 `cardH = modViewport2.SY(CARD_H)`）。よって可変= rowsNeed×CARD_H、固定= cardT（ヘッダー等）+ rowsNeed×CARD_GAP + PAGER_H。modHub:139-141 と同型。

### FA-R24-1b vba_lint へ「引数数照合」検査を新設【恒久対策・最重要】

R21H型の「シグネチャ変更の呼び出し側取り残し」をビルド前に機械検出する:
- src/ 全体から Public/Private Sub・Function・Property のシグネチャを収集（必須引数数 = Optional/ParamArray より前の引数数、最大引数数 = 全引数数。ParamArray は上限∞）。
- `modX.Proc(args)` 形式の修飾呼び出し（Function呼び出し・Call文・引数付きSub呼び出し `modX.Proc a, b` を含む）を走査し、実引数の個数が [必須, 最大] の範囲外なら **ERROR**。
- パースの制約（文字列/コメント内の除外、行継続 `_` の連結、入れ子括弧・引数内カンマのバランス計算）を正しく処理すること。**確実に数えられない複雑な行はスキップし黙って通す**（偽陽性でビルドを止めるくらいなら検出漏れの方がまし。スキップ件数はWARNで可視化）。
- 名前付き引数 `x:=1` は個数照合の対象外としてよい（現リポジトリでの使用実態を確認し、使用があれば個数だけ数える）。
- ネガティブ確認: FA-R24-1a 適用前のコードで modVaultGallery:337 が ERROR 検出されること。適用後は ERROR 0。
- この検査で**他の取り残しが検出された場合は勝手に直さず司令塔へ報告**（今回の裁定対象は modVaultGallery のみの想定。想定外の検出は裁定が要る）。

## R24-2 ヘッダーボタンの視認性【本修正・白枠は不十分と実機判定】

R23の白枠線0.75ptは実機で「変わっていない」と判定された（26pt円の細枠は視認距離で消える）。裁定: **ボタンの塗りを白系へ反転**する。全テーマの帯は暗色（最明 #0B7D6E）のため、白地ボタンは常時コントラスト5:1以上で成立し、テーマ分岐不要。

### FA-R24-2a Hub 円形ボタン6個（modHub.bas:260-264 付近）

- 塗り: RGB(255,255,255)。枠線: 既存の白枠設定を **PRIMARY_DARK RGB(1,77,68)・0.75pt** へ変更（白地に白枠は無意味のため）。
- 中身は絵文字（自色レンダリング）なので文字色変更不要。ボタン直下のラベルShape（帯上の白文字）は変更しない。

### FA-R24-2b Dash HeaderPill（modDash.bas:401-407）と Chat HeaderButton/HeaderTheme（modUINexusDraw.bas:338-349, 363-371）

- 塗り: RGB(255,255,255)。文字色: RGB(1,77,68)（PRIMARY_DARK）。Bold は現状踏襲。枠線: PRIMARY_DARK 0.75pt（白枠から変更）。
- ダーク系テーマでも帯は暗色なので白地+濃緑文字で成立（文字コントラスト 10:1 超）。

### FA-R24-2c Knowledge の Pill タブ（modKnowledge.bas Pill プロシージャ）

タブは active/inactive の区別が必要（セグメンテッドコントロール型へ）:
- active: 塗り白 + PRIMARY 文字（現状のまま）。枠線なしまたは PRIMARY 0.75pt。
- inactive: **塗りを帯に透過（Fill.Visible=0 または帯色）+ 白文字 + 白枠 0.75pt**（現R23の白枠を活かす）。
- これで「白いタブ=選択中/枠だけ=非選択」の標準文法になる。
