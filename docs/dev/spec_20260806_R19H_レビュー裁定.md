## FA(重大・中)

FA-1【A-H① 吸収列の換算誤差】FitBandToViewport の pt↔ColumnWidth 換算は単純除算
  (アフィン特性を無視)のため基準列が狭いほど過大評価(Hubは必要幅の69%しか吸わない)。
  修正: ColumnWidth 設定後に ws.Columns(pad).Width を読み直し、目標との差分で
  1回再補正(誤差<1ptに収束)。純関数部はテスト追随(狭基準列1.5/広基準列13の両ケース)。
FA-2【A-H② sharedモードの下端切れ】modShared.Show の描画末尾に、実下端(件数行)からの
  境界再適用(ApplyShelfExtent 同型)を追加。狭窓での白い断崖・到達不能を解消。
FA-3【A-H③/B-H② Personal.xlsb誤検知】CohabitCount を「可視の他ブック」だけ数える
  実装へ: ThisWorkbook 除外+名前が personal.xlsb(大小無視)除外+IsAddin=True 除外+
  可視ウィンドウを持たないブック除外。判定純ロジックを分離しテスト固定
  (personal.xlsb のみ同居/可視ブック同居/混在)。
FA-4【A-M④ Hubの帯と操作系の乖離】Nexus と同型に統一: 帯・ピル・ナビ・カード・
  フッターの右端を全て HUB_BAND(吸収列込み=可視幅)基準の ContentRight(-8pt)へ。
  HUB_CONTENT 基準は廃止(帯だけが伸びて操作系が画面2/3で止まる非対称を解消。
  広い窓ではナビ/タイルが可視幅に追随して伸びるのが正)。
FA-5【A-M⑤/A-L⑩ UsedRange救済の誤発動+塗り巻き戻し】(i)ClearChat で伸ばした塗りを
  既定色へ巻き戻す(旧最深行まで)。(ii)Nexus の膨張判定は倍率ではなく絶対値
  (例: 縦12,000pt超)へ変更(長い正常会話で誤発動しない)。テスト追随。

  (無人同期は従来どおり出さない)。modShelfSync 残81字→呼び出しは1行+同量圧縮。
FA-7【A-M⑦/B-M⑤ 存在しないランチャーへの誘導】ガードシート・README・
  CohabitWarnMsg の文言を両対応の1文へ:「同梱の『MyBookshelfを起動.bat』があれば
