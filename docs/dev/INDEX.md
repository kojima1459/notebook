## 3. ラウンドの裁定（`spec_*` / `audit_*`）

- `spec_<日付>_R<番号>_<主題>.md` … そのラウンドの仕様と全裁定
- `audit_<日付>_R<番号>_..._生報告.md` … 監査班の生の所見（採否は spec 側）
- `reference_*.md` … 調査の一次資料
- `review_<日付>_外部レビュー裏どり_R<番号>.md` … 外部（Gemini 等）レビューの再現結果と採否（採ったものは spec/HANDOFF にも書く）

**過去ラウンドの「なぜそう決めたか」は必ずここにある。同じ議論を再演する前に grep する。**

```bash
grep -rl "<キーワード>" docs/dev/spec_*.md docs/dev/audit_*.md
```
