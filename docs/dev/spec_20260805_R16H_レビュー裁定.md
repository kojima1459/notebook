## 仕様の改訂(本裁定で確定。spec_20260805_R16 の読み替え)
- §3C: 精読(NeighborExpand)の適用は thorough(single/parts)のみとし、deep深掘り
  (FinishDeep)への適用は取り下げる。理由: modAsk 凍結下では deep 経路の nHits が
  表示・ログ(件数バッジ/hit_count)と一体で、近傍込み件数が「N件ヒット」の嘘になる
  (A-M4)。deep は速度重視モードであり精読は thorough の役割。
- §3D: 既出チャンク降格は「followupターンの全検索」に適用する(RunDeepScoped +
  RunUnscoped の followup 時)。判定は modFollowup.IsFollowupTurn() を検索側で読む
  (modAsk は変更しない)。
- §4のパーサ「CP932境界」テスト: ParseChoiceNumbers/ParseOptions はUnicodeコード
  ポイント判定でありCP932表現可否と独立のため対象外とする(B-L10の記録)。
