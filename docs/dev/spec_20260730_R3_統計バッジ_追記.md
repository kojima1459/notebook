# R3 追記（実装開始前に必読）

R2(取込コア)の実装が完了し、以下が変わっている。R3実装はこの最新状態を前提にする。

- `modShelf.IngestFile` の署名が
  `IngestFile(path, origin, Optional silent, Optional ByRef outErrCode)` になった。
  R3要件B(EvaluateBadges フック)を入れる際、この新しい形を壊さないこと。
- `modShelf.AddFilesViaDialog` は `AddFilesResult(showMsgBox)` の薄いラッパーに
  なった。stats 加算ブロックの位置は IngestFile 内で変わっていないが、
  必ず最新のファイルを読むこと。
- テストモジュールは `modTestsPure3.bas` が新設され、
  `modTestsPure2.RunAll2 → modTestsPure3.RunAll3` の配線がある。
  R3のテスト追加は modTestsPure3 に追記してよい(容量に注意)。
  新規モジュールを作る場合は tools/run_lo_tests.py の PURE_ALLOWLIST と
  tools/vba_lint.py の CONTRACT への登録も必要(modTestsPure3 の例に倣う)。
