## 1. 裁定済みの修正計画(上限回復後に波で実施)

### R12-1【最優先・小粒の重大件】
1. **modGuard.bas:183 の knowledge_expire_days フォールバックを 30→0**
   (High。configセルが空/文字列化した瞬間に30日消去タイマーが起動する
   逆向き既定。1行+読めなかった事実の usage_log。modBoot:391 のコメントも)。
2. **modApp.OnSaveAndExit: ThisWorkbook.Close の直前に modBoot.Auto_Close
   を明示呼び出し**(Critical。本番ビルドのThisWorkbookはインストーラ占有で
   BeforeCloseが無く、VBAからのCloseはAuto_Closeを実行しない→終了ボタン
   経由だと OnKey残存(Excel全体でCtrl+Z死亡)/リボン非表示残存/テレメトリ
   未送信。Auto_Closeは冪等)。
3. **streak(連続利用日数)が実機で恒久1**(Med・無条件発現): modStats.
   TouchToday の比較前に IsDate 正規化(ShortDateと同型)。書き側の
   NumberFormat="@"化は移行考慮が要るため比較側で吸収。
4. **和暦カレンダー設定への防御**: guard_last_reach 等の日付書込を
   Format$("yyyy-mm-dd")から Year()/Month()/Day() 数値合成へ(和暦設定で
   元号年が書かれ失効判定が誤作動/無言無効化する芽)。同型の日付文字列
   書込を grep で全数確認し同時に統一。
5. modEmbed.SleepMs に Timer日跨ぎガード1行(同型9箇所で唯一の欠落)。
6. modPrompts.bas:361 BuildSourceBlock の生Left$→modUtil.SafeLeft
   (R11-I適用漏れ。サロゲート境界)。
7. ValidateMigFile に mig_format_version 上限チェック1行(前方互換)。
8. shelf_max_chunks フォールバック不一致(20500/20000/10000)を定数1箇所へ。
