# 要件定義 R9: Ghostscriptの配布・自動検出（起草: Fable司令塔）

利用者フィードバック(2026-07-31): 「Ghostscriptフォルダを手で置く運用は無理。
脳死で簡単に。別DL・手動配置をなくして1つにまとめてほしい」。

## ゴール(利用者要件)

**利用者は Ghostscript を一切「別途ダウンロード」も「手動配置」もしない。**
IT知識の無い社員でも、DLして開けば画像PDFのOCRが使える状態にする。

## 司令塔の裁定(既定=安全策・埋め込みは任意ON)

「デメリットゼロ」ではない。埋め込み(embed-and-drop)には2つの実在コスト:
- (a) 自己インストーラは毎起動でブックを保存し直すため、22MB内蔵で
  **毎起動の保存が30MB級**になり起動が常時遅くなる(一度きりのDLではない)。
- (b) マクロが22MBのネイティブexe/dllをディスクへ書き出して実行するのは
  マルウェアのドロッパの典型挙動で、**Word COMを既にEDRに止められている
  本環境では隔離リスクが高い**(最悪アプリごと隔離=フォルダ配置より悪化)。

よって、利用者要件(別DL・手動配置ゼロ)を**リスクゼロで**満たす方式を既定にする。

### A. 既定: 配布zip一体化 + 自動検出（EDR安全・公式ツールと同方式）

1. 配布物を「アプリ .xlsm + Ghostscript フォルダ」を含む**1つのzip**にする。
   利用者は1個DL→解凍だけ。手動フォルダ配置は発生しない。
   (会社公式 Excel帳票OCR/画像RAG と同一方式=本環境で動作実績あり)
2. Ghostscript実行ファイルの**自動検出**を強化する。解決順:
   1. config `ghostscript_path`(明示フルパス。R6で追加済み)
   2. `ThisWorkbook.Path & "\Ghostscript\gswin32c.exe"`(同梱zipの隣。R6済)
   3. config `ghostscript_search_dirs`(セミコロン区切りの追加探索先。
      **IT が標準配置先を配布ビルドのconfigに1回焼き込む**ための口。
      これで多くの端末=公式OCRツール導入済み端末が無操作で当たる)
   4. `%LOCALAPPDATA%\NexusAgent\gs\gswin32c.exe`(Bの展開先)
   検出結果はセッションキャッシュ(毎回ディスクを舐めない)。
3. 見つからない時は**エラーではなく1回きりの親切な案内カード**を出す:
   「画像PDFの読み取りには追加部品(Ghostscript)が要ります。配布zipに
   同梱の Ghostscript フォルダをこのファイルの隣に置くか、[フォルダを選ぶ]
   で場所を指定してください」+ フォルダ選択ボタン(選んだら
   ghostscript_path に保存=次回から無操作)。怖い赤エラーにしない。

### B. 任意: 埋め込み展開（config `gs_embed_extract`、既定 FALSE）

- Ghostscript(gswin32c.exe + gsdll32.dll)を veryHidden シートへ base64 で
  分割格納し、初回OCR時に `%LOCALAPPDATA%\NexusAgent\gs\` へ**一度だけ**
  展開(サイズ照合で再展開しない)。以後 A-2-4 の自動検出で当たる。
- 既定 FALSE。EDR が問題ないと確認できた部署だけ config で TRUE にすると
  真の「1ファイル配布」になる。
- 実装は用意するが**既定では焼き込まない**(本体を軽く保つ)。ビルドに
  `--embed-gs <gsフォルダ>` を付けた時だけ base64 シートを生成する。
- 展開は「マクロがPEを書く」挙動なので、有効化前に実機1台でEDR隔離が
  起きないことの確認を運用手順に明記。

## ビルド/配布(build)

- 既定ビルドは A（本体は Ghostscript を含まない・軽い）。
- 配布zipの作成手順を build に足す or docs 化(アプリ + 公式GSフォルダを
  1zipへ)。Ghostscript バイナリはライセンス(AGPL)明示のうえ配布物に同梱。
- `--embed-gs` オプション時のみ B のシートを生成(容量・保存コストの注意を
  ビルドログに出す)。

## 文言/docs

- `docs/43_画像PDFのOCR取込設定.md` を A 方式(zip解凍だけ)に全面改訂。
  「別DL・手動配置」の記述を消し、「1zipをDL→解凍→開くだけ」に。
- 案内カードの文言・フォルダ選択導線を明記。
- IT向けに「ghostscript_search_dirs に標準配置先を1回設定すれば全社無操作」
  を運用ガイド(docs/30)へ。

## 制約
- CP932外文字禁止 / Integer禁止 / 宣言先頭 / R6ハンドラ規約。
- 検出ロジックの純粋部分(パス合成・優先順・拡張子判定)は optOcrCore か
  modShareRule 相当の純ロジックへ切り出しテスト。
- 既存 R6(optVision.ResolveGsExe)を土台に拡張(壊さない)。

## 受入条件
- Ghostscript を手動配置していない状態で、zip解凍しただけで OCR が通る
  (自動検出が sibling フォルダを見つける)経路のコード。
- 未検出時に赤エラーではなく案内カード+フォルダ選択が出て、選ぶと
  ghostscript_path に保存され次回無操作になる経路のコード。
- `gs_embed_extract=TRUE`(+ --embed-gs ビルド)で手動配置ゼロ・sibling無しでも
  OCR が通る経路のコード。
- lint ERROR 0 / テスト全PASS / 両ビルド自己検証OK。
