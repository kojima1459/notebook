  Declare文はLOコンパイル通過を実験で確認済み(#If VBA7 Then + PtrSafe 形式もPASS)。

- verdict=parts: 論点ごとに (i)検索: modAskRetrieve.RunMultiRetrieve を expand無効・

  (iii)統合1回: ■見出し=副質問ごと。出典タグは一字一句保持・削除禁止・新事実追加禁止を
  プロンプトで明示。(iv)critique 1回+verify 1回は統合文に対して実行(論点ごとには回さない)。
