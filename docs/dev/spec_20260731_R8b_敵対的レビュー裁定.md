# R8b: R8敵対的レビュー(読取専用Opus)の裁定 — 修正16件/受容4件

対象: 445325d。レビュー総合判定は「条件付き出荷」。司令塔裁定で以下を確定。
実装は R9 完了後に排他で実施(同一ファイル競合とLOテスト多重起動の回避)。

## 修正(B1〜B16)

- **B1【最重要・データ喪失封鎖】** modGuard:238 付近: WipeKnowledge の直前に
  `If act <> "wipe" Then Exit Function` を追加(ホワイトリスト化)。
  OERNで act が空のまま落ちても絶対に消さない。加えて ExpiryDecision の
  実引数を作る GetStatText 読みの上流でエラー値セル対策があるか確認のみ
  (直すのはB1の1行で足りる。過剰防衛で複雑化しない)。
- **B2【必須】** modPublish.AcquireLock: `AcquireLock = WriteShared(lockPath,…)`
  (ロック作成失敗を成功と報告しない)。
- **B3【必須】** modShare.ReportFailure の呼び出しから modBoard.ReadBeacon を
  外す(他人の1ファイルが読めないことは共有断の証拠にならない。誤降格で
  感謝状・同期・発行が全滅し「未設定」と誤案内される連鎖の根)。
  WriteBeacon 側は残す。
- **B4【必須】** modHub 受信箱: 起動中プレースホルダ分岐を qaN/gapN/
  IsBudgetTight(いずれもローカルのみ)の**後ろ**へ移す。共有I/Oを伴わない
  通知(Q&A受信箱)を起動状態で塞がない。
- **B5【必須・出荷既定】** build_config_rows: `knowledge_expire_days` の
  既定を 30 → **0**(PoC中は失効無効)。説明文に「本格展開時に30以上を設定」
  を明記。ダミーパス到達(下記受容1)と組み合わさる消去確率を出荷既定でゼロに。
- **B6** modGuard ドメイン監視: USERDOMAIN/USERDNSDOMAIN が**両方空**
  (ワークグループ端末)は「不一致」に数えない(シグナル無し扱い)。
  実ドメイン不一致の消去は現行どおり。
- **B7** modPublish ロックの残骸対策2件: (a) AcquireLock 成功時にフルパスを
  モジュール変数へ控え、ReleaseLock はそれを直接 Kill(セッション降格で
  SubDir が空になっても解放できる)。(b) PublishLockAction: ageMin<0(時計ズレ)
  は stale 扱い(+err_log 1行)。時計が遅れた端末が永久に発行不能になる方が
  同時発行より害が大きい。
- **B8** modBoard.RefreshBoard: `mAggAt = Timer` とゼロ化・mLoaded=True を
  BoardDir 空判定の**後ろ**へ。失敗時は旧集計と旧称号を保持(0分・称号消失の
  10分固定を防ぐ)。
- **B9** modBoot: StartupJitter を EnsureLayout 群の後・EnsureHubLayout
  (最初の共有I/O)の直前へ移動。ガードシート露出+DoEvents 3秒の操作受付窓を
  塞ぐ。F3の要件(最初の共有I/Oの前)は維持。
- **B10** modShare のプローブ: ProbeIsReachable が偽のとき、末尾 \ を
  **落とさない**形でもう1回だけ GetAttr を試す(UNC共有ルート直指定
  \\srv\share での err52/76 対策)。modShareRule に純ロジックで
  ProbeRetryPath を切り、テスト追加。
- **B11** modBoard.PublishBeacon: スロットルを「内容同一なら10分、
  内容が変わったら60秒」に変更(前回送信ペイロードをモジュール変数で保持)。
  起動後10分以内の✅が丸ごと落ちる取りこぼしを解消。
- **B12** modInsight.GcOldInsights: 共有側GC(qa/gap)の実行を発行者端末のみに
  限定(modPublish 系の既存の発行者判定を再利用。無ければ config
  `insight_gc_publisher_only` 既定TRUE+発行者用ビルドで実行)。削除件数を
  usage_log に1行記録。自端末ローカルのGC(nonce/既読印)は全端末のまま。
- **B13** modGuard:152: `CLng(Date - CDate(s))` → `Int(...)`(四捨五入で1日
  早く消える芽)。
- **B14** modPublishUI.OnPublish ほか: dest 空の案内文言を「共有フォルダが
  未設定か、共有フォルダに接続できません」に(到達不能を未設定と断定しない)。
- **B15** R8新規コメントの ✅(U+2705) と —(U+2014) をCP932安全な表現へ置換
  (既存モジュールの既出分は対象外)。
- **B16** modLog.FriendlyMessage とエラーコード表に E0806 を追加。

## 受容(修正しない・理由の記録)

1. ローカルの実在フォルダ(ダミーパス)が Reachable=True になる件:
   到達判定に書込可否/UNC判定まで持ち込むと誤NGの害が勝る。B5(既定0)で
   消去リスクは遮断済み。本格展開時の設計課題として記録。
2. AcquireLock の TOCTOU(非アトミック): PoC規模では窓縮小で十分。
   本格展開時に Open For Output / リネーム排他へ(記録)。
3. Dir(vbDirectory) イディオムの残存6箇所: 実害軽微。次期クリーンアップで
   ProbeIsReachable へ統一(記録)。
4. SyncSubscribed 未配線 / OverflowCount 初回非表示: 前者は次期で配線か削除。
   後者はF3のトレードオフとして受容済み。
