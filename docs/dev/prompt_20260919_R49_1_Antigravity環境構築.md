# プロンプト① Antigravity へ投げる：AIリボン環境の構築と検証

**用途**: 高橋さんから借りた Windows PC の Antigravity に、社内Excelアドイン
「AIリボンちゃん」の実行環境を作らせ、**本当に動くところまで**確認させる。
**この①が終わってから②（Claude Code の実機テスト）へ進む。**

## 渡すファイル（この3つだけ）

| # | 渡すもの | 置き場所 |
|---|---|---|
| 1 | `AI_____202609.zip`（AIリボン ver202609 の配布zip一式） | デスクトップ等、日本語を含まないパス推奨 |
| 2 | `MyBookshelf_配布.zip`（R49 ビルド。このセッションで出すもの） | 同上 |

> ⚠️ **リボンのソースには会社の生きている Azure キーが平文で入っています。**
> zip をそのまま社内PCへ置くのは通常運用どおりで構いませんが、
> **中身を外部サービスへ貼らない・GitHub へ置かない・チャットに値を写さない。**
> Antigravity にも「キーの値は出力するな」と下のプロンプトで指示してあります。

## 貼り付けるプロンプト（ここから下をそのままコピー）

```
あなたはこの Windows PC のセットアップ担当です。社内Excelアドイン
「AIリボンちゃん」が動く環境を作り、動いたことを証拠つきで報告してください。
わたしは非エンジニアなので、専門用語は使わず、画面で見えることで報告してください。

## 絶対に守ること

1. **APIキーの値を画面にも報告にも絶対に出さないでください。**
   ソースの中にキーが平文で入っています。「どのファイルの何行目にある」
   までは言って構いませんが、値そのものは伏せてください。
2. **ファイルを外部のサービスへアップロードしないでください。**
   GitHub、Gist、pastebin、翻訳サイト、どれもだめです。
3. 途中で分からないことがあったら、**勝手に決めずに止めて聞いてください。**
   特に「既存のアドインを消す」「レジストリを触る」は必ず先に聞いてください。

## 前提（すでに分かっていること。調べ直さなくてよい）

- アドインの版は **ver202609**（`log.bas` の `UpDate` が `20260916_R`、
  利用期限 `LimitDay` が 2027/3/31）
- zip の中には **すぐ使える `リボンちゃん.xlam` と、登録用の
  `【アドイン登録】Ver34.xlsm`** が入っている。`.xlam` を自分で作る必要はない
- 登録用ブックは、**同じ場所に `アドインファイル` フォルダが並んでいること**を
  前提にしている。zip を展開したフォルダ構成を崩さないこと
- 登録用ブックはアドインのダイアログを **Alt+L / Alt+U のキー操作で自動操作する**。
  実行中にマウスやキーボードを触ると失敗する
- 抽出モジュール（`リボンちゃん_xlam/` の `.bas`）は **UTF-8**（旧版は CP932）。
  文字化けして見えたら開き方の問題で、ファイルが壊れたわけではない
- Excel は **32bit** を前提にしている

## やってほしいこと

### 手順1: Excel の状態を確認して報告
- Excel のバージョンと **32bit か 64bit か**
- マクロのセキュリティ設定（「信頼センター」のマクロ設定）
- 「信頼できる場所」に何が登録されているか

→ ここまでを報告してから次へ進んでください。

### 手順2: AIリボンの zip を展開して登録
1. `AI_____202609.zip` を、**日本語を含まないパス**（例 `C:\work\ribbon\`）へ展開
2. 展開後のフォルダの中身を一覧で報告（どこに `リボンちゃん.xlam` と
   `【アドイン登録】Ver34.xlsm` と `アドインファイル` フォルダがあるか）
3. `【アドイン登録】Ver34.xlsm` を開き、マクロを有効化して、指示どおりに登録
   - **登録マクロの実行中は PC に触らないこと**（Alt+L/Alt+U を自動で送るため）
4. Excel を一度終了して開き直し、**リボンに「AIリボン」のタブが出るか**を確認
   - 出たらスクリーンショットを撮って報告

### 手順3: リボンが本当に応答するか確かめる（ここが一番大事）
新しいブックを開いて、どれかのセルに次の数式を入れてください。

    =ChatGPT("1たす1はいくつですか。数字だけ答えてください。","","","","","","","","","","gpt-5.6-luna")

- **数秒〜十数秒で「2」が返る**のが合格です
- 何か別の文字列が返った場合、**その文字列をそのまま**報告してください
  （`(error:401)…` `(error:404)DeploymentNotFound` `接続切れ`
  `content_filterに該当しました` など。これは例外ではなく戻り値なので、
  エラーダイアログは出ません）
- `#NAME?` になる場合はアドインが読み込まれていません。手順2へ戻ってください

同じ形で、**モデルを変えて3回**試してください。使うモデル名は次の3つです。

| 何のためか | モデル名 |
|---|---|
| すぐ聞く | `gpt-5.6-luna` |
| しっかり調べる | `gpt-5.6-terra` |
| 入念に調べる | `gpt-5.6-sol` |

**3つとも「2」が返るか**を表にして報告してください。
1つでも返らなかったら、**返ってきた文字列をそのまま**教えてください。
（`gpt-5.6-sol` だけ通らない、というのが一番知りたいことです）

### 手順4: 埋め込み（ベクトル化）も動くか
別のセルで次を試してください。

    =GetEmbeddings("テスト")

- 長い数字の列が返れば合格です（**値は報告しなくて構いません。
  「返ってきた/返ってこない」だけ**教えてください）
- `error` という文字が返ったら、そのことを報告してください

### 手順5: マイ本棚AI を置く
1. `MyBookshelf_配布.zip` を、**別のフォルダ**（例 `C:\work\mybookshelf\`）へ展開
2. 中の `MyBookshelf.xlsm` をダブルクリックして開き、マクロを有効化
3. **最初に出る画面（Hub）のスクリーンショット**を撮って報告
4. まだ何も操作しないでください（ここから先は次の担当が引き継ぎます）

## 最後に出してほしい報告

次の6点だけ、箇条書きで。

1. Excel の版と 32/64bit
2. AIリボンのタブが出たか（はい/いいえ）
3. `ChatGPT()` が 3モデルとも「2」を返したか（表で）
4. 返らなかったモデルがあれば、その戻り値の文字列（そのまま）
5. `GetEmbeddings()` が数字を返したか（はい/いいえ）
6. マイ本棚AI の最初の画面が出たか（はい/いいえ）＋スクリーンショット

**うまくいかなかったことを隠さないでください。**
「動かなかった」は失敗ではなく、こちらが知りたい情報そのものです。
```

## この①で何が分かるか（司令塔メモ・Antigravity には渡さない）

- 手順3が**このラウンドの本丸**。R48 で `quick=luna / recommended=terra /
  thorough=sol` へ切り替えたが、**`gpt-5.6-sol` のデプロイが実在して社員権限で
  叩けるか**は誰も実機で確かめていない。アドインのソース上は
  `deployments/gpt-5.6-sol` を指す本物だが、`Select Case model` に `Case Else`
  が無いので、**一覧に無い名前を渡すと url/apiKey が空のまま進む**。
  つまり「静かに変なことが起きる」型のリスクがある。
- 手順4は R48 で触った埋め込み経路（`RibbonEmbedRange`）の前提確認。
  `GetEmbeddings` は引数1つ・デプロイ `text-embedding-3-small-g`・次元1536 で
  **ver202606 から変わっていない**ことをソースで確認済み。実機で裏を取る。
- **キーの値を出すなという指示を冒頭に置いたのは意図的**。
  Antigravity は文脈を知らないので、「デバッグのため」と称して平文キーを
  そのまま画面へ出すことがありうる（CLAUDE.md §3-6 と同じ構図）。
