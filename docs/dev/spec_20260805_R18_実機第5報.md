  chunk_count を保持(status/エラーメモの更新は従来どおり)。UpsertManifestRow に
  keepCount 相当の経路を追加するか store 側で前値維持。

  my_knowledge 実行数を数え、manifest の chunk_count と不一致なら実行数を正として

R18-2d 起動時整合性チェック: 終了時ではなく保存時(SaveCheckpoint成功時)に
  (my_knowledge行数, ThisWorkbook.FullName) を ui_state へ記録。起動時に突合し、
  行数が減少していれば警告モーダル1回+usage_log("integrity_warn")。
  加えて ThisWorkbook.Path が Temp/Temp1_*.zip 配下なら「保存が次回に残らない場所で
  開いています」を起動時1回モーダル。実装は modDiag(または新modIntegrity)に置き、
  modBoot へのフックは1行(同量圧縮で捻出)。
