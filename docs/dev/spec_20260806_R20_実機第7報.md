# R20-1【⑦最優先】右・下余白の3層根治（波A）

R18/R19が直したのは「帯（ヘッダーShape）の寸法」だけで、(層1)中身が窓幅に追随しない、(層2)行高の明示範囲が巨大なスクロール域を作る、(層3)測定系の穴、が残っていた（調査A班で file:line 確定済み）。3層を同時に塞ぐ。

## 1a 横幅測定の頑健化（modUIMain.ViewportWidth, modUIMain.bas:70-79）
- R19H FB-5 と同型に: `ActiveWorkbook Is ThisWorkbook` でないときは**一切測らず**前回値/既定値を返す。`VisibleRange.Width` フォールバックはガード内へ移し、それも失敗なら既定 900pt。
- 上限クランプ 1600→**3000pt**。modViewport.ViewportHeight の上限 1200→**2000pt**（modViewport.bas:268）。
- modUIMain は残2,035字。増分は最小に（コメントは1行まで）。

## 1b ダッシュボードの中身を幅追随に（modDashStat / modDash）
- KPIカード: `KPI_CARD_W=130` 固定（modDashStat.bas:26-32）→ 可変 `cardW = Clamp((bandW - 2*KPI_X0 - 3*KPI_GAP)/4, 130, 220)`。bandW = FitBandToViewport 後の帯実幅（ContentRight から取得）。
- バッジカード（BADGE_W=130×4, modDashStat.bas:39-45）も同式で可変。
- `ContentRightX()`（modDash.bas:263-265）は固定590を返すのをやめ、**実配置の右端**を返す。ChartNote 等の他要素も帯内配置に追随。
- 全画面化の順序を修正: `EnsureAppView` を `DrawDashboard` の**前**に（modDash.bas:80,93 の逆順を是正）。

## 1c マイ本棚の中身を幅追随に（FA-4の本棚適用）
- 右肩ピル: `tbRight` アンカー（modKnowledge.bas:127-135）→ `ContentRight(ws, SHELF_BAND, 8)` 基準へ。
- gallery: 3列固定（modVaultGallery.bas:25,398-400）→ `cols = Clamp(Int((bandW - 左端X - GAP) / (CARD_W + GAP)), 3, 6)`。カード群は帯左寄せのまま列数だけ増やす。
- table: 本文が A:J=588.75pt 固定（modUIShelf.bas:55,159,168,189）。J列（メモ列）を可変幅にし、本文右端 ≒ 帯右端 −（吸収列N最小幅）になるよう配分。K/L/M の死に列は幅最小化。

# R20-3【②】再取込ゼロの「資料の仕上げ」バックフィル（波C）
