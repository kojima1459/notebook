# 「Nexus Agent」を独立リポジトリへ切り出す手順

## 現在の状態(2026-07時点で完了していること)

`notebook`リポジトリの`mybookshelf/`サブディレクトリの内容は、同リポジトリ
内の新ブランチ **`product/nexus-agent`** のルートへ既に展開済み。
V2チャットボット関連ファイル(旧ルートの`src/`/`build/`/`docs/`等)は
このブランチには含まれない(完全分離)。仕様書・設計書・ER図・エッジ
ケースカタログ等のドキュメント一式も同ブランチに追加済み
(`docs/dev/ARCHITECTURE.md`が入口)。

加えて、このブランチと同内容の**独立したローカルgitリポジトリ**を
`/tmp/nexus-agent-standalone/`(または成果物として提示されたパス)に
用意している。GitHub等へ新規リポジトリとして押し込む場合はこちらが
最短(履歴付き・依存関係なし)。

## 選択肢A: `notebook`リポジトリ内のブランチのまま運用する

追加の作業は不要。`product/nexus-agent`ブランチに対して通常どおりPRを
出し合えばよい(`docs/dev/CONTRIBUTING.md`参照)。**GitHubのリポジトリ
アクセス権はそのままで済む**という利点がある一方、V2と同じリポジトリ
内に同居する点は変わらない(ブランチ一覧に両者が並ぶ)。

## 選択肢B: 完全に独立したGitHubリポジトリへ移す

GitHubで新しい空リポジトリを作成してから:

```bash
# ローカル成果物(スタンドアロンrepo)を使う場合
cd /path/to/nexus-agent-standalone
git remote add origin https://github.com/<org>/<new-repo>.git
git push -u origin main
```

または、`notebook`リポジトリから直接pushする場合:

```bash
git clone https://github.com/kojima1459/notebook.git
cd notebook
git checkout product/nexus-agent
git push https://github.com/<org>/<new-repo>.git product/nexus-agent:main
```

## 切り出し後の確認(共通・5分)

```bash
python3 build/build_mybookshelf.py --dev   # ビルドが通るか
python3 tools/vba_lint.py                  # 静的チェックが通るか
python3 tools/run_lo_tests.py              # 構文コンパイル検証(LibreOfficeが必要)
```

3つとも成功すれば切り出し完了。

## 注意

- `notebook`リポジトリの`main`ブランチ(V2チャットボット)は本切り出しの
  影響を一切受けない。
- 新リポジトリ移行後、`product/nexus-agent`ブランチを`notebook`側から
  削除するかどうかは運用判断(履歴保全のため残しておいても実害はない)。
