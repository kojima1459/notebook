# 情シス確認チェックリスト

**この1枚を持って情シス担当に相談すること**。

| API バージョン | 例: `2024-10-21` | |
| chat デプロイメント名 | 例: `gpt-4o`, `gpt-5.5` | |
| embedding デプロイメント名 | 例: `text-embedding-3-small` | |

→ 回答に応じて `config/config.sample.ini` の `[api]` セクションを書き換える。
