# ユーザーガイド (営業担当者向け)

## 起動

1. 配布された `Chatbot.xlsm` をダブルクリック。
2. 初回のみ、部署名と職位を入力するダイアログが2回出る。
3. チャット画面が表示されるまで数秒待つ (ナレッジindexの読み込み中)。

## 使い方

1. 上部のテキストボックスに質問を入力。
2. 「送信」ボタンをクリック。
3. 数秒〜10秒程度で AI からの回答が表示される。
4. 回答の末尾に **出典 (ファイル名と該当ページ)** が表示されるので、必ず原典で確認する。

## 注意事項

- **個人情報は質問に含めないでください**。契約番号・氏名・電話番号などが検知された場合、警告が出ます。
- 回答は **参考情報** です。引受可否などの最終判断は必ずアンダーライターに確認してください。
- 質問数は **1日100件・1時間30件** が上限です。
- 「ナレッジ改善に質問本文を提供する」チェックを ON にすると、質問本文が管理者の集計対象になります (既定 OFF)。

## トラブルシュート

| 症状 | 対処 |
|---|---|
| 「ナレッジindexの読み込みに失敗しました」 | ネットワーク接続を確認。改善しない場合は管理者に連絡。 |
| 「embed失敗」「Chat failed」 | プロキシ認証が切れている可能性あり。一度ブラウザで社内ポータルにアクセスして認証を更新し、再試行。 |
| 「本日の質問上限に達しました」 | 上限値は管理者に確認。 |
| 起動が遅い | indexサイズに依存。30秒以内なら正常。 |

## 質問のコツ

- 一文に絞る。複数の質問は分けて投げる。
- 「○○のときの△△は？」のように、約款条文や商品名を含めると精度が上がる。
- 回答に納得できない場合は、出典の原典を読んで判断する。
