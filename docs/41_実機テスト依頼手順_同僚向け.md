# Nexus Agent 実機テスト手順（依頼を受けた方向け）

> **この文書は誰向けか**: 実機テストを依頼された方（エンジニアでなくて構いません）向けです。
> **お願いしたいこと**: 手順どおりに触っていただき、**「思ったとおりに動かなかったところ」をそのまま報告**していただくことです。直し方を考えていただく必要はありません。
> **所要時間**: パターンA（1台で完結）約30分 / パターンB（2台・部門配信まで）追加で約20分

---

## 0. はじめに ― このテストで一番ありがたい報告

「エラーが出た」よりも、**「エラーは出ないが、期待と違った」**の方が価値があります。

直前の点検で見つかった不具合は、大半が**落ちずに静かに間違える**類でした。

- 出典のボタンが1枚も出ない（エラーは出ない）
- 部門を切り替えても前の部門の資料が残る（エラーは出ない）
- 聞き返しへの返信に数字が入っていると、打った文章が捨てられる（エラーは出ない）
- 獲得したバッジが画面に出ない（エラーは出ない）

**「これで合ってるのかな？」と一瞬でも思ったら、それは報告に値します。** 遠慮なく書いてください。

## 1. 事前準備（依頼者側で済ませてあります）

以下は**依頼者が設定済み**のはずです。ファイルを受け取ったら、念のためご確認ください。

| 確認すること | 期待 |
|---|---|
| 受け取ったファイル名 | `MyBookshelf.xlsm`（発行テストも行う場合は `MyBookshelf_発行者用.xlsm` も） |
| PC | **Windows 版の Excel（デスクトップ版）**。Mac・Excel Online・スマホでは動きません |
| 社内 AI（リボンちゃん） | リボンが表示され、ご自身で使える状態 |
| Word | インストール済み（**PDF の読み取りに Word を使います**。Word が無いと PDF が一切取り込めません） |

> **PDF / Word の資料を取り込むときは、Word を開いたままにしてください。**
>
> 端末の設定により、Excel から Word を自動で起動できない場合があります
> （社内のセキュリティ製品が他アプリからの Word 起動を止めていることがあります）。
> その場合、**すでに開いている Word があればそちらを使って読み取ります**。
> Word（空の文書でも構いません）を開いた状態で取り込むと確実です。
>
> 取り込みが失敗したときは、Word を開いてもう一度お試しください。
> それでも失敗する場合は、**そのこと自体が重要な報告事項**です。
> `err_log` シートの内容をそのまま送ってください。

## 2. パターンA：1台で行うテスト（約30分）

### A-1. 開く（3分）

1. `MyBookshelf.xlsm` をダブルクリック
2. 黄色い警告バーが出たら **「コンテンツの有効化」**
3. 数秒待つ
4. 初回のみ名前の入力を求められます（ニックネーム可・空欄でも進みます）

**見るべきポイント**

- [ ] 画面が組み上がる
- [ ] **⚠️ 起動して1〜2秒後に、画面が一瞬ちらついたり、古い画面が重なって見えたりしないか**（直したばかりの箇所です）
- [ ] メッセージボックスが**2回続けて**出ないか（同上）

### A-2. 閉じて、すぐ開き直す（2分）

1. Excel を閉じる（保存を聞かれたら保存）
2. **10秒ほど待つ**
3. もう一度開く

**見るべきポイント**

- [ ] **⚠️ 閉じたあと、数秒後に Excel が勝手に開き直さないか**（直したばかりの箇所です）
- [ ] 2回目の起動でも A-1 と同じように正常に開くか

### A-3. 🩺 診断（1分）

1. 「ホーム」タブ右上の **「🩺 診断」** を押す

**見るべきポイント**

- [ ] `diag_report` シートが出て、行の先頭が**すべて ✅**
- [ ] ⚠️ があれば、その行を**そのままスクリーンショット**して報告

### A-4. 質問してみる（5分）

最初から入っている資料（会社のガイドライン類）に対して質問できます。

1. チャット画面で、画面に出ている**質問例のボタンを1つ押す**
2. 回答を待つ

**見るべきポイント**

- [ ] 待っている間、**「考えています…」のまま無反応にならず**、何をしているか表示が変わるか
- [ ] 回答が返る
- [ ] **⚠️ 回答の下に「出典（クリックで原文を確認）」のボタンが出るか**（← **最重要。直前まで1枚も出ていませんでした**）
- [ ] 出典ボタンを押すと、元の文章が出るか
- [ ] 回答の中に **`?`（半角のはてな）が混ざっていないか**（例：`部分的に一致 ? 下の出典で…`）
- [ ] 自分で質問文を打っても同じように動くか

### A-5. 聞き返しの動作（3分）

わざと曖昧な質問をします。

1. 「**条件は？**」のように、**短くて何の話か分からない質問**を打つ
2. 「もう少し教えてください」と番号付きの選択肢が出たら…

**やっていただきたいこと（2通り）**

- [ ] （1）**番号だけ**打つ（例：`2`）→ 選んだとおりに進むか
- [ ] （2）もう一度曖昧な質問をして、今度は**普通の文章で質問を書き直す**。**このとき文章に数字を入れてください**（例：`第1条の適用範囲について教えて` / `3日以内に必要な手続きは？`）
      → **⚠️ 打った文章がそのまま質問として使われるか**（← **直前まで、数字が入っていると打った文章が捨てられていました**）

### A-6. 資料を入れる（7分）

1. 入力欄の左の **「📁 資料を入れる」** から、**PDF を1つ**取り込む
2. 続けて **Excel ファイル（.xlsx）を1つ**取り込む。**`#N/A` などのエラー表示が入っているシート**があると理想的です

**見るべきポイント**

- [ ] PDF が取り込める
- [ ] **⚠️ 取り込み中に Word のウィンドウが開いたり閉じたりしないか**（直したばかりの箇所です）
- [ ] **⚠️ `#N/A` を含む Excel が取り込めるか**（← 直前まで、エラー値が1つあるだけでファイル全体が失敗していました）
- [ ] 取り込んだ資料について質問すると、その資料が出典に出るか
- [ ] **いま開いている Excel ファイル**を取り込もうとすると、「閉じてから取り込んでください」と出るか（**⚠️ 編集中のブックが勝手に閉じられたら重大な不具合です。すぐ報告してください**）

### A-7. 画面まわり（3分）

- [ ] 回答の吹き出しを**クリックしても選択されない**か（枠に白い丸が付かない）
      → 付いてしまい、Delete キーで回答が消えるようなら報告してください
- [ ] 右上の ❓ を押してヘルプが出る → もう一度押すと**きれいに消える**（ボタンが残らない）
- [ ] ダッシュボードを開き、**バッジが12個**表示されているか（8個しか出ない場合は報告）
- [ ] バッジの表示が下のグラフ枠と**重なっていない**か

### A-8. 引き継ぎ（5分・新機能）

新しい版に差し替えても資産が消えないための機能です。

1. ❓ヘルプ → **「📤 引き継ぎファイルを作る」** → 保存
2. ❓ヘルプ → **「📥 引き継ぎファイルを読む」** → いま作ったファイルを選ぶ
3. 置き換えの確認が出るので OK

**見るべきポイント**

- [ ] 書き出しできる
- [ ] 読み込みできる
- [ ] 読み込み後、**「マイ本棚」の一覧に資料が並んでいる**か（← ここが空だと引き継ぎ失敗です）
- [ ] 取り込んだ資料について、引き続き質問できるか

### A-9. 意地悪テスト（歓迎します・時間があれば）

**壊しにいってください。** 想定外の操作こそ実機でしか試せません。

- [ ] 送信ボタンを**連打**する
- [ ] 回答を待っている間に、**画面上部のモード切替や言語切替を押す**
- [ ] 回答を待っている間に **ESC キー**を押す
- [ ] 非常に長い文章（数千文字）を貼り付けて送信する
- [ ] 資料を取り込んでいる最中に他のボタンを押す
- [ ] 資料が0件の状態で質問する

**どの場合も、「Excel が固まったまま戻らない」「意味の分からない英語のエラーが出る」なら報告対象**です。

## 3. パターンB：部門配信のテスト（約20分）

> **Q. 共有サーバが無いとテストできませんか？**
> **A. できます。** 「2台の PC から読み書きできる場所」であれば何でも構いません。テストだけなら **1台の PC のローカルフォルダ**（例：`C:\Temp\NexusShare\`）でも通せます。

### B-0. 置き場所について（よくある疑問）

| 疑問 | 答え |
|---|---|
| 部門ごとに別々の場所に置いてもいい？ | **いけません。** 全部門の正典は**1つの場所の下**にぶら下げます。各 PC は `nexus_share_path` という**1つの設定値**だけを見て、その下の `channels\<部門名>\` を探すためです |
| 発行側と受け取り側で別の場所を指定できる？ | **できません。** 同じ場所を指す必要があります（発行側が書き、受け取り側が読むため） |
| どんな構造になる？ | 下記のとおり。**フォルダは自動で作られます**ので、手で作る必要はありません |

```
<nexus_share_path>\               ← ここだけを config で指定する
    channels\
        商品部\
            pack.xlsx             ← 正典の本体
            version.txt           ← 版番号
            _archive\             ← 過去版（巻き戻し用）
        人事部\
            ...
    thanks\      ← 「ありがとう」のやりとり
    insights\    ← 解決済みQ&A・困りごと
    telemetry\   ← 利用統計
```

**権限**: 全員に**読み書き両方**が必要です（読み取り専用では動きません）。発行担当者はさらに `channels\` 配下にフォルダを作れる必要があります。

### B-1. 準備

1. 2台の PC から見えるフォルダを1つ決める（テストなら1台のローカルフォルダでも可）
2. **両方の PC** で、Nexus Agent の ❓ヘルプ → **「⚙ P2P接続設定（共有フォルダ）」** にそのパスを入れる
3. 発行側の PC には `MyBookshelf_発行者用.xlsm` を使う

**見るべきポイント**

- [ ] 存在しないパスを入れると「そのフォルダが見つかりませんでした」と出て、**設定が変わらない**か

### B-2. 発行（発行者用ブック）

1. ナレッジ画面を開く
2. **「📤 正典を発行」** ボタンがあることを確認（**一般配布版にはこのボタンが出ません**。それが正しい動作です）
3. 部門名を入れて発行

**見るべきポイント**

- [ ] 確認ダイアログの件数が「**自分で入れた資料のみ**」の件数になっているか（本棚の総数より小さくて正常です）
- [ ] 共有フォルダに `channels\<部門名>\pack.xlsx` と `version.txt` ができるか
- [ ] 部門名に `/` や `:` を入れて発行しようとすると、**書き出す前に**「使えない文字」と教えてくれるか

### B-3. 受け取り（一般配布版）

1. もう1台（または同じ PC の一般配布版）を開く
2. Hub のお知らせに「**部門の公式ナレッジをまだ読み込んでいません**」が出る
3. 押して取り込む

**見るべきポイント**

- [ ] 取り込める
- [ ] 取り込んだ内容について質問すると、**その部門の資料が出典に出る**か
- [ ] **自分で入れた資料が消えていない**か

### B-4. 更新配信（ここが最重要）

1. 発行側で資料を1つ足す、または内容を変える
2. **もう一度発行**する
3. 受け取り側を開き直す

**見るべきポイント**

- [ ] Hub に「**【部門名】に更新があります**」と出るか
- [ ] **⚠️ 表示される部門名が正しいか**（← 直前まで、更新があるのと違う部門名が出ていました）
- [ ] 押すと最新版に入れ替わるか
- [ ] **⚠️ 押したあと、お知らせが消えるか**（← 直前まで、押しても消えない状態でした）
- [ ] **⚠️ 古い内容と新しい内容が混ざっていないか**（← **最重要**。古い記述で回答されたら重大な不具合です）

### B-5. 複数部門

1. 発行側で**別の部門名**でもう1つ発行する
2. 受け取り側で取り込む

**見るべきポイント**

- [ ] **両方の部門の資料から回答できる**か（片方が消えたら報告）
- [ ] 自分で入れた資料も残っているか

### B-6. 共有フォルダが使えないとき

1. 共有フォルダのパスを、**存在しないパス**に書き換える（例：`\\存在しないサーバ\share\`）
2. Excel を閉じて開き直す

**見るべきポイント**

- [ ] **⚠️ 起動が異常に遅くならないか**（30秒以上待たされたら報告）
- [ ] エラーで止まらず、**普通に質問できる**か
- [ ] **⚠️ 閉じるときに数十秒待たされないか**
- [ ] （終わったら元のパスに戻してください）

## 4. 報告のしかた

**エンジニアでなくても書ける形で構いません。** 次の3点だけ書いてください。

```
【何をしたか】 例：PDFを取り込んだあと「第3条の適用範囲は？」と質問した
【どうなったか】例：回答は出たが、下の「出典」ボタンが1つも出なかった
【どう思ったか】例：本当にその資料を見て答えたのか確認できず、不安に感じた
```

**画面のスクリーンショット**があると非常に助かります。

### エラーが出た場合

1. 「🩺 診断」を押す
2. `diag_report` シートの内容をスクリーンショット
3. 可能なら `err_log` シートも(このアプリは通常起動中シートタブを隠しているため、
   出すには: ①アプリの「🚪保存して閉じる」でいったん閉じる → ②再度開く際、
   セキュリティの警告バーで「コンテンツの有効化」を押さずに開く → ③タブが
   見える状態になるので右クリック→「再表示」→ `err_log` を選ぶ。
   **手間がかかるので、難しければ手順1・2だけで十分です**)

### 「これは不具合か分からない」とき

**分からないまま報告してください。** 判断はこちらでします。
「気持ち悪い」「なんとなく分かりにくい」も立派な報告です。**使う気にならなかった理由**が一番知りたい情報です。

## 5. 付録：うまくいかないときの早見表

| 症状 | 考えられること |
|---|---|
| 開いてもタブが増えない | マクロが無効。黄色いバーの「コンテンツの有効化」を確認 |
| 質問すると「AI に接続できません」 | リボンちゃんが入っていない／利用申請が切れている。リボン単体で使えるか確認 |
| PDF が取り込めない | Word がインストールされているか確認。画像だけの PDF（スキャン）は取り込めません |
| 起動・終了が異常に遅い | 共有フォルダのパスが到達できない可能性。§B-6 と同じ状態 |
| 何をしても反応しない | 「処理中です」と出るなら待つ。10分以上続くなら報告 |
