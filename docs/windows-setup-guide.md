# Chatbot.xlsm セットアップ手順（Windows版）

パソコン操作に詳しくなくても大丈夫です。順番通りにやれば15分で完了します。

---

## 必要なもの

- Windows 10 または Windows 11 のパソコン
- Microsoft Excel（デスクトップ版）
- インターネット接続
- 管理者から渡された **APIキー**（英数字の長い文字列）

---

## ステップ 1：ファイルをパソコンに保存する

**配布パッケージのフォルダ**（USBや共有フォルダから受け取ったもの）を、
**デスクトップ**か**Dドライブ**にそのままコピーしてください。

> 例えば `デスクトップ\ChatbotPackage\` に置いた場合、
> 中に `Chatbot.xlsm`・`config.ini`・`disclaimer.txt`・`index\` フォルダがあればOKです。

---

## ステップ 2：設定ファイルを所定の場所に置く

このツールは「ユーザーごとの設定フォルダ」を使います。
**エクスプローラー（フォルダを開くやつ）**を開いて、上のアドレスバーに以下をそのままコピペして Enter を押してください：

```
%LOCALAPPDATA%\InternalNotebookLM
```

> 「%LOCALAPPDATA%」はWindowsが自動で
> `C:\Users\あなたのユーザー名\AppData\Local` に変換してくれます。
> 手入力しなくて大丈夫です。コピペすれば開きます。

フォルダが存在しなかったら、**右クリック→新しいフォルダー** で作ってください。

フォルダを開いたら、配布パッケージの中の **以下のファイル/フォルダ** をここにコピーします：

| コピーするもの | コピー先 |
|---|---|
| `config.ini` | `%LOCALAPPDATA%\InternalNotebookLM\config.ini` |
| `disclaimer.txt` | `%LOCALAPPDATA%\InternalNotebookLM\disclaimer.txt` |
| `index\` フォルダごと | `%LOCALAPPDATA%\InternalNotebookLM\index\` |

---

## ステップ 3：APIキーを設定ファイルに書き込む

コピーした `config.ini` をダブルクリックして**メモ帳**で開きます。

> メモ帳で開かない場合：`config.ini` を右クリック → 「プログラムから開く」→「メモ帳」を選択

ファイルを開いたら、この行を探してください：

```
api_key =
```

イコールの右側（スペースの後）に、受け取った **APIキー** を貼り付けます：

```
api_key = ここにAPIキーを貼り付ける
```

**Ctrl+S** で保存して、メモ帳を閉じます。

> ⚠️ APIキーは他の人に教えないでください。このファイルを誰かに送らないでください。

---

## ステップ 4：Excelのマクロ設定を確認する（初回のみ）

Excelを起動して、**ファイル → オプション → トラスト センター → トラスト センターの設定 → マクロの設定** を開きます。

- 「**警告を表示してすべてのマクロを無効にする**」または「**署名済みマクロを除き、すべてのマクロを無効にする**」になっていればOKです。
- 「すべてのマクロを有効にする」は不要です（セキュリティ上あまり良くないため）。

> 情シスから「信頼できる場所に登録済み」と言われている場合は、このステップはスキップできます。

---

## ステップ 5：Chatbot.xlsmを開く

配布パッケージの `Chatbot.xlsm` をダブルクリックします。

**「マクロを有効にする」または「コンテンツの有効化」ボタンが出たら → クリックしてください。**

> このボタンが出ない場合は、情シスが設定済みのサインです（問題ありません）。

しばらく（5〜10秒）するとExcelのシートに自動で以下が表示されます：

- 青いタイトルバー：「社内ナレッジQAボット (デモ版)」
- 黄色い入力欄
- 「> 送信」ボタン
- 下にシステムメッセージと注意書き

---

## ステップ 6：初回の部署・役割入力

初めて開いたとき、**「部署名を入力してください」** というダイアログが出ます。

| ダイアログ | 入力例 |
|---|---|
| 部署名 | 営業1部 |
| 役割 | 営業担当 |

入力してOKを押すと保存され、次回からは聞かれません。

---

## ステップ 7：使ってみる

1. 黄色い入力欄に質問を入力します
   - 例：「火災保険の免責事項を教えて」
   - 例：「引受可否の判断基準は？」
2. **「> 送信」** ボタンをクリックします
3. 数秒〜10秒で回答と出典が下に表示されます

---

## うまくいかないときは

| こんな表示が出たら | 原因と対処 |
|---|---|
| 「ファイルが見つかりません」 | config.ini または index フォルダがステップ2の場所にない → 再確認 |
| 「APIキーが無効です」 | config.ini のapi_keyの記入ミス → コピペし直す |
| マクロが動かない | 「コンテンツの有効化」を押した後に再起動 |
| 「レート制限」 | 1時間に30回、1日100回を超えた → しばらく待つ |
| 「個人情報が含まれている可能性があります」 | 質問に電話番号・メールアドレスが含まれていたら消して再送信 |

エラーメッセージが出たら、そのまま管理者（配布した人）に連絡してください。

---

## 注意事項

- **質問に個人情報（氏名・電話番号・契約番号など）を入れないでください**
- 回答はあくまでナレッジベースに基づく参考情報です。最終判断はアンダーライターへ
- このツールの利用ログは管理者が確認できます
