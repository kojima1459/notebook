# リボンちゃん関数シグネチャ採取手順書（ルートB）

> 社内PCで、AIリボンのアドインから**関数宣言部だけをテキストでコピー**してChatに貼るための手順。
> ファイル添付ではないので上司承認が不要な可能性が高く、情報の質は仕様書回答より高い
> （実装が読めるのでエラー挙動・上限値・保存先まで確定できる）。
> 所要：15〜30分。前回 `ver202606` の解析（`docs/v2/30_リボンちゃん仕様.md`）と同じ要領。

---

## ⚠️ 最重要：コピーしてはいけないもの

**アドインの `GPT.bas` と `Embeddings.bas` にはAPIキーの実値がハードコードされている**
（`Public apiKey As String` への直書き。30_リボンちゃん仕様.md §4に申し送り済み）。

- `apiKey` / `key` / `Bearer` を含む行、および **長い英数字リテラル（32文字以上の "..." ）は絶対に貼らない**
- 貼る前に、コピーしたテキスト全体を目視で1回スキャンする
- うっかり含めた場合はそのチャットに送信せず、該当行を削除してから送る
- エンドポイントURL（`*.openai.azure.com`）は既にリポジトリに記録済みの情報なので貼っても問題ないが、迷ったら伏せてよい（`<URL>`に置換）

## 手順

### 1. VBエディタでアドインを開く

1. AIリボンが入った状態のExcelを起動
2. `Alt + F11` でVBエディタを開く
3. 左側のプロジェクトエクスプローラーで、AIリボンのアドインプロジェクト（`.xlam`）を探す
   - 見えない場合：`Ctrl + R` でプロジェクトエクスプローラーを表示
   - パスワード保護されていた場合はここで終了 → ルートA（質問状）一本に切替
4. プロジェクトを展開し、標準モジュールの一覧を確認

### 2. 対象モジュールと採取箇所

対象は以下の7モジュール（ver202606時点の名前。多少違っても類推できる）：

| モジュール | 目当ての関数 | 優先度 |
|---|---|---|
| `GPTV` | `ChatGPTV`（Vision） | ★高（画像PDF取込・画像質問の可否が決まる） |
| `Tts` | `ttsFile` / `ttsSpeak` | ★高（読み上げ・聴く約款の可否が決まる） |
| `Whisper` | `GetWhisper` | 中 |
| `Tool` / `ExcelTool` | `CellMarkDown` / `OpenWordMark` / `RangeToTable` | 中 |
| `AI2` | `Translate` / `TranslateS` | 低（設計上は非依存） |
| `DALL` | `Dalle` / `GptImage` / `StableImage` | 低 |
| `GPT` | `LimitCheck` / `IsAgreed` の**呼び出され方と閾値だけ**（⚠️キー直書きモジュール。コピーは最小限に） | ★高（取込バッチの安全設計に直結） |

各モジュールで採取するのは次の3種類：

1. **関数宣言行**：`Public Function ...(引数リスト) As 型` の行（複数行にまたがる場合は `_` の続きも全部）
2. **モジュール先頭の定数・設定**：`Const` 行、対応形式やサイズ上限が書かれた行
3. **エラー処理と戻り値**：`On Error` 周辺、`= "error"` のような失敗時の戻り値、ファイル保存先（`SaveToFile`／パス組み立て）の行

丸ごとコピーできるならモジュール全文でもよい（**GPT.basだけはキー行があるため必ず宣言部と該当箇所のみ**）。

### 3. 貼り付けテンプレート

チャットに貼るときは以下の形式で（1モジュール1ブロック）：

```
■モジュール名: GPTV（アドインver: 202606）
--- 宣言部 ---
Public Function ChatGPTV(text As String, imageInputs As ..., ...) As String
--- 定数 ---
（あれば）
--- エラー処理・戻り値 ---
（該当行を数行）
--- 気づいたこと ---
（例：画像はファイルパスの配列で渡すらしい、上限らしき数字があった、等）
```

### 4. ついでに実行して確かめられる人向け（任意・+15分）

VBエディタのイミディエイトウィンドウ（`Ctrl + G`）で1関数1回だけ試すと確度が★になる：

```vba
? Application.Run("ttsSpeak", "テストです")
? Application.Run("CellMarkDown", Range("A1"))   ' A1に "# 見出し" 等を入れておく
? Application.Run("RangeToTable", Range("A1:C3"))
```

- **1回ずつ・小さい入力で**。大量実行はしない（LimitCheckに触れないため）
- 結果（戻り値・セルの変化・音が出たか・エラーメッセージ）をそのままメモして貼る
- ChatGPTV/GetWhisperは入力ファイルの準備が要るので、宣言部の採取だけで一旦OK
