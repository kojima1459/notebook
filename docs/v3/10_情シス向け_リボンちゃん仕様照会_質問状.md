件名：【G-1コンテスト出場に伴う照会】社内AIリボン（生成AIアドイン）の関数仕様について

〇〇部 〇〇様

お世話になっております。新種保険部 ニューリスクGの小島です。

このたび当部では、「業務効率化ツール活用コンテスト（G-1コンテスト）」組織部門に、
社内生成AIツール（AIリボン）とVBAを活用した業務効率化の取組みでエントリーを予定しております。

当部では既に、AIリボンの ChatGPT関数・GetEmbeddings関数 を Application.Run 経由で
呼び出す社内ナレッジQAツール（Excelマクロ）を内製し、部内で運用を開始しています。
コンテストに向けた機能拡張にあたり、AIリボンが提供するその他の関数の仕様を
確認させていただきたく、下記のとおり照会いたします。

なお、本照会で必要なのは**関数の呼び出し仕様（引数・戻り値・制限値）のみ**であり、
APIキー等の秘匿情報・接続情報は一切不要です。仕様書やヘルプ文書の抜粋、
あるいは該当モジュールの関数宣言部のご提示など、ご負担の少ない形式で構いません。

■ 共通事項（全関数）
1. Application.Run による外部ブックからの呼び出しは公式にサポートされる使い方でしょうか
   （サポート外の場合、推奨される呼び出し方法があればご教示ください）
2. 各関数のエラー時の挙動（エラー文字列を返す／例外を発生させる／空文字を返す 等）
3. 利用回数・サイズの制限（LimitCheck等）：1日あたりの呼び出し上限、1回あたりの
   入力サイズ上限、超過時の挙動
4. アドインのバージョンアップ予定と、その際に関数シグネチャが変わる可能性の有無

■ 関数別の照会事項

| 関数 | 確認したいこと |
|---|---|
| ChatGPTV（画像理解） | 引数一覧（画像の渡し方：ファイルパス／セル上の図形／Base64等）、複数画像の可否、対応モデル、画像サイズ・枚数の上限 |
| GetWhisper（音声書き起こし） | 引数一覧、対応音声形式（wav/m4a/mp3等）、ファイルサイズ・録音時間の上限、戻り値の形式 |
| ttsFile／ttsSpeak（読み上げ） | 引数一覧、出力音声の形式と保存先、選択可能な音声の種類、入力文字数の上限、ttsSpeakは再生完了まで待機するか |
| Translate／TranslateS（翻訳） | 引数一覧、対応言語（指定方法）、TranslateSが対象とするオブジェクトの範囲（図形・SmartArt・グラフ等） |
| CellMarkDown（Markdown整形） | 引数一覧、対応するMarkdown要素（表・見出し・箇条書き・強調等）、出力先Rangeの指定方法 |
| RangeToTable（表テキスト化） | 引数一覧、出力テキストの形式（Markdown表／TSV等） |
| Dalle／GptImage（画像生成） | 引数一覧、出力形式と保存先、サイズ指定の可否 |

ご多忙のところ恐れ入りますが、コンテストのエントリー準備の都合上、
〇月〇日頃までにご回答いただけますと大変助かります。
一部の関数のみ先行してご回答いただく形でも問題ございません。

どうぞよろしくお願いいたします。
