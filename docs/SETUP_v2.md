# Chatbot v2 セットアップ手順（社内AIリボン版）

**ここがポイント**: v2は **社内AIリボン** を使うので、APIキーもconfig.iniもindexフォルダも一切要らない。

---

## 必要なもの

1. Windows社内PC（Excel入り）
2. **社内AIリボンが有効になっていること**
   - リボンの「生成AI」タブが見えていればOK
   - 見えていなければ、まず「リボンちゃん.xlam」のインストール手順を済ませる（社内マニュアル参照）

それだけ。USB・config.ini・indexフォルダ全部不要。

---

## ファイル取得

### ステップ1：ZIPダウンロード

EdgeかChromeで以下を開く：

```
https://github.com/kojima1459/notebook
```

緑色の **「< > Code」** → **「Download ZIP」** をクリック → `notebook-main.zip` がダウンロード。

### ステップ2：展開

ダウンロードフォルダの `notebook-main.zip` を **ダブルクリック** → エクスプローラーの上のリボンから **「すべて展開」** → 「展開」。

中身に `notebook-main\dist\Chatbot_v2.xlsm` ができる。

> ⚠️ **以前の Chatbot.xlsm（v1）は使いません。** Chatbot_v2.xlsm を開いてください。

---

## 起動

### ステップ3：Chatbot_v2.xlsm を開く

#### 通常の方法

エクスプローラーで `Chatbot_v2.xlsm` をダブルクリック。

#### マクロブロックされて開けない場合（前回ハマったやつ）

1. Excelを起動
2. `Alt + F11` で VBAエディタを開く
3. イミディエイトウィンドウ（`Ctrl + G`）に貼り付け：

```vb
Workbooks.Open "\\s1401.vds.iij.jp\vol00$\Home-01\2104520\Downloads\notebook-main\notebook-main\dist\Chatbot_v2.xlsm"
```

ユーザー番号（2104520）の部分はあなたの番号に合わせて。

> ✅ **v1と違ってv2はファイル1個だけ**。Mark of the Web が外れていれば普通に開けるはず。

### ステップ4：初回のみ部署選択

開くと初回だけ：

1. 「**所属部署を番号で選択**」ダイアログ → `1` （費用利益保険チーム）→ OK
2. 「**役割**」ダイアログ → 例：`アンダーライター` → OK

部署情報は `config` シートに保存されます。次回以降は聞かれません。

### ステップ5：使ってみる

「main」シートが表示される。

1. **黄色い質問欄**に質問を入力（例：「告知義務違反した場合の対応を教えてください」）
2. **「> 送信」** ボタンをクリック
3. **60〜90秒** 待つ（裏で4段階の処理が走る：ルーター→FB検索→ドラフト→検証）
4. 青い回答欄にAI回答が出る、下に出典

### フィードバックを残す（ナレッジ蓄積）

- 回答が良かった → **「○ 良かった」** ボタン → 任意で理由入力
- 回答が間違っていた → **「× 修正」** ボタン → 正しい回答を入力

これが `feedback` シートに溜まる。**同じ質問が次回来たら、その認定回答が優先される**。

## 仕組み

各質問で社内AIを4回呼ぶ：

| Step | 何をする | 所要 |
|---|---|---|
| 1 | ルーター：501チャンクの要約を見て関連する4〜8個を選ぶ | 〜10秒 |
| 2 | フィードバック検索：過去の認定済みQ&Aを最大3件採用 | 即時 |
| 3 | ドラフト：選んだチャンクで構造化回答を生成 | 〜30秒 |
| 4 | 検証：ドラフトの主張をナレッジと照合、嘘・盛り過ぎを削除 | 〜30秒 |

これで「コスト爆発」「ハルシネーション」を抑えつつ精度を担保。

## カスタマイズ（管理者）

### モデル変更

`config` シートの `router_model` `drafter_model` `verifier_model` を編集。
ただし**現状はリボン側の設定が優先**されるので、リボンの「ChatGPTモデル設定」を変えるのが本筋。
configシートは **将来「モデル別呼び分け」対応時に有効になる予備設計**。

### 検証パスOFF（コスト半減・速度倍）

`config` シートの `verifier_enabled` を **FALSE** に。

### ナレッジ追加（マニュアル増えた時）

→ Claudeに新PDFを渡してください。enrich後のCSV行を返すので、`knowledge_base` シートの末尾に追記。

## トラブル

| 症状 | 対処 |
|---|---|
| マクロを有効化しても何も起きない | リボンに「生成AI」タブがあるか確認。なければリボンちゃんアドインが未インストール |
| 「Application.Run('ChatGPT'…)が失敗」 | リボン側でモデル設定済みか確認 |
| 「knowledge_base シートが空」 | ファイル破損。ZIPから取り直す |
| 起動時にエラー | `Alt+F11` でデバッグログを見る |

## v1（古い版）との違い

| v1 (Gemini直叩き) | v2 (社内リボン経由) |
|---|---|
| Gemini APIキー必要 | 不要 |
| config.ini 編集必要 | 不要 |
| index/embeddings.bin (19MB) 必要 | 不要 |
| プロキシ・MOTW・信頼できる場所 全部問題 | リボン経由なので全部回避 |
| 配布物 21MB | 配布物 360KB |
| 回答精度: 自己検証2パス | ルーター+FB蓄積+自己検証 |

**v2が本流。v1は捨てて良い。**
