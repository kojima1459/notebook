# 実機スモークテスト手順 — 15分チェックリスト(R11完成版)

> **この文書は何か**: 配布zip・実機での「全機能を一通り動かす確認」。探索ではなく、
> 決められたチェック項目(全16項目・各1-2分。項目13は大きめの本棚がある人だけ)を
> 順番に進めるだけです。
> 不具合が見つかったら err_log のコードをメモして報告してください。

**前提**:
1. 配布zip(`MyBookshelf_配布.zip` 等)を右クリック → すべて展開
2. 解凍されたフォルダの `dist` 内にある `MyBookshelf.xlsm` を開く
3. 黄色い警告バーが出たら「コンテンツの有効化」を押す(セキュリティ許可)
4. 画面が自動で組み上がるまで待つ(初回は10-30秒)

**注**: 別ドキュメント `docs/44_P2P実機テスト手順.md` は「複数台・共有フォルダ連携」の詳細手順です。
このドキュメントとは独立した内容なので、P2P機能は不要な場合は 44 を読む必要はありません。

---

## チェックリスト(スクリーンショットは不要・問題があったら err_log をメモ)

### 1. 起動 — ホーム画面(Hub)が表示される
**期待**: ホーム画面が見え、エラーメッセージやマクロ警告が無い

**NGだったら**: err_log を開いて E0801 / E0901 / E0102 などを探し、コードを報告

---

### 2. チャットで質問1回 — 即答モードで回答 + 出典チップ表示
**操作**:
1. 「💬 チャット」ボタンを押す(またはサイドバーの「💬」を選択)
2. 入力欄に「Excel の SUM 関数の使い方を教えて」と入力
3. 左の「⚡ すぐ聞く」を押す(またはCtrl+Enter)
4. 数秒〜10秒待つ

**期待**: 
- AIが回答を返す
- 回答の下に「📚 出典」セクションが出て、資料名のボタンが見える
- (フォルダ同期をしていない場合は「本棚に資料がありません」と出るのは正常)

**NGだったら**: err_log で E0602 / E0601 / E0201 などを確認

---

### 3. テキストPDF取込(Wordは閉じた状態)
**操作**:
1. 「📚 マイ本棚」タブを開く
2. 上のツールバーで「📁 追加」をクリック
3. テキストが入ったPDF(1-3ページ程度)を選ぶ
4. 取込を待つ

**期待**: 
- 進捗バナー(「1/1件 変換中」など)が画面上部に表示される
- OLE/COM待機のモーダルダイアログが**出ない**(出たら要報告)
- 数秒〜十数秒で「取込完了」のトースト(画面右下の通知)が出る

**NGだったら**: err_log で E0302 / E0303 / E0401 を確認

---

### 4. err_log確認 — Ghostscript実行の記録
**操作**:
1. 「ホーム」タブの右上「❓」を押す
2. 「🩺 診断」をクリック
3. 下へスクロールして「直近のエラー」欄を見る
4. さらに詳しく見たい場合: 診断画面のどこかのシートタブを右クリック → 「再表示」で `err_log` シートを開く

**期待**: 
- err_log に `pdf_text_gs` の行があり、`detail` に `rc=0`(リターンコード0=成功)が記録されている
- これはGhostscriptが実機で正常に動作したことの証拠

**NGだったら**: `rc=` の値と `cand=` の候補パスをメモして報告

---

### 5. 複数ページPDF1本取込 → チャットで質問 → ページ番号確認
**操作**:
1. 「📚 マイ本棚」で、複数ページ(5ページ以上が理想)のPDFを1本追加
2. 完了を待つ
3. 「💬 チャット」へ戻り、そのPDFの内容について質問する
   (例えば「このPDFの5ページに何が書いてありますか」)
4. 回答の下の「📚 出典」で出典チップを見る

**期待**: 
- チップに「ページ: 5」など、ページ番号が表示される
- その番号が実際のPDFのページと一致する(ページ分割が正確に動作している証拠)

**NGだったら**: ページ番号のズレと、PDF名をメモして報告

---

### 6. 画像PDF取込 — OCR経路への確認
**操作**:
1. 「📚 マイ本棚」で「📁 追加」から、スキャンした画像PDF(紙をスキャンしたもの)を選ぶ
2. 進捗を見る

**期待**: 
- 進捗が「OCR中」と表示される(Ghostscript+Vision API で読み取り中の表示)
- 案内カード「このPDFは画像です。フォルダを選んでください」が出たら、
  Ghostscript フォルダをそのまま選ぶ(またはスキップ)
- 完了する

**NGだったら**: err_log で E0303 と card= の状態をメモして報告

---

### 7. ナレッジ画面の切替 — ギャラリー・本棚・解決事例
**操作**:
1. 「📚 マイ本棚」タブを開く
2. 上のピル(小さいボタン)「ナレッジ倉庫 / マイ本棚 / みんなの解決事例」を次々クリック
3. 右肩のピル「🚪 / ⚙️」(終了・着せ替えなど)が画面内に見えるか確認

**期待**: 
- 3つのビュー(カード表示・一覧・解決事例)が全て反応して表示内容が変わる
- 右肩のピルが全て画面内に見える(切れていない)
- スクロールできるなら全ての要素が見える

**NGだったら**: ピルが見えない画面があれば、その画面名と座標をメモして報告(#30対応)

---

### 8. ギャラリーのページ送り — 最終ページで警告
**操作**:
1. 「📚 マイ本棚」→ 「ナレッジ倉庫」(カード表示)
2. ページ送りボタン(「→」)を繰り返し押す
3. 最後のページに到達

**期待**: 
- 最後のページで「最後のページです」というトースト(右下の通知)が出る
- それ以上ページを進められない(無言で止まらない)

**NGだったら**: 無言で先頭にワープしたり、エラーが出たら err_log で E0801 を確認

---

### 9. 取込中に終了ボタン — 防止動作の確認
**操作**:
1. 「📚 マイ本棚」から複数ファイル(3個以上)を一度に追加
2. 進捗バナーが「変換中」を表示している最中に、右上の「🚪 終了」ボタンを押す

**期待**: 
- 画面に「取り込み中のため終了できません。お待ちください」というメッセージが出る
- 終了できず、処理の完了を待たされる(途中で止められない)

**NGだったら**: 即座に終了してしまったら E0503 系の問題。err_log を確認

---

### 10. ダッシュボード表示 + ヘルプ参照
**操作**:
1. 「📊 ダッシュボード」タブを開く
2. 節約時間・レベル・バッジなどが表示されるのを見る
3. 右上「❓」を押す
4. メニューから「ツアーをもう一度見る」や「このツールについて」を選ぶ

**期待**: 
- ダッシュボードが正常に表示される
- ヘルプメニューが開き、各項目が選択できる
- 案内が読める

**NGだったら**: err_log で E0801 を確認

---

### 11. Word相乗り保護 — docx取込後もWordが開いたまま
**操作**:
1. Excel以外のWord 文書(`.docx`)を**事前に開く**(ファイルを開いたまま)
2. 「📚 マイ本棚」で「📁 追加」から、その開いているWordファイルを選ぶ
3. 取込完了後も Wordが開いたままか確認
4. Wordで別の箇所を編集した後、保存するか聞かれるか確認

**期待**: 
- Wordが取込後も開いたまま(閉じられない)
- Wordの内容が保護されている(利用者が編集を続けられる)
- 編集後に「保存しますか」の確認が出て、データが失われない

**NGだったら**: Wordが勝手に閉じたり、編集が失われたら C2 対応不十分。err_log を確認

---

### 12. 終了 → 再起動 — データ保持確認
**操作**:
1. 取込した資料やチャット履歴がある状態で、「🚪 終了」を押す
2. 「保存して終了する」を選ぶ(または何もしなければ自動保存)
3. ファイルを閉じる
4. もう一度 `dist/MyBookshelf.xlsm` を開く

**期待**: 
- 起動時の「数秒待機」中に共有フォルダへの接続を試みる(設定されている場合)
- 以前のデータ(資料・チャット履歴・ダッシュボード情報)が全て残っている
- データが消えていない

**NGだったら**: データ消失は重大。err_log + 再起動時の e_log をメモして報告

### 13.(大きめの本棚がある人だけ)検索の待ち時間を測る
**なぜ**: 検索の速さは資料の量で決まります。開発環境では実際の待ち時間を
測れないため(ロジックしか実行できない)、**ここだけは実機の数字が正**です。

**操作**:
1. 診断画面で現在のチャンク数をメモする(例: 1,200件 / 5,000件 / 20,000件)
2. アプリを開き直した直後に、1回目の質問をして**回答が出るまでの秒数**を測る
3. 続けて別の質問を2回して、**2回目・3回目の秒数**を測る

**期待**:
- 1回目は「🔍 検索の準備をしています… N/N件」という表示が出て、そのあと回答。
  ここでベクトルを1回だけ読み込むため、**1回目だけ数秒〜十数秒長くなる**のは正常です
- 2回目以降はその準備表示が出ず、1回目より明確に速い
- 待っている間、画面が真っ白(応答なし)にならない。必ず「検索中 N/N件」等が動く

**報告してほしい数字**: チャンク数 / 1回目の秒数 / 2回目以降の秒数 / 途中で
無反応になったか。この3つの数字が、公称値(docs/70)を実測で裏づける根拠になります。

**NGだったら**: 2回目以降も1回目と同じだけ待つ場合は、usage_log に
`veccache_fallback` の行が無いか確認してください(メモリ不足でキャッシュを
諦めて従来の経路で動いています)。あれば、その行の内容も一緒に報告してください。

### 14. 深掘り: 一度質問→深掘りボタン→入力欄のチップ表示→送信で、引用済み資料に絞った回答になること
**操作**:
1. チャットで1回質問し、回答(出典つき)を受け取る
2. 「🔍 深掘り」ボタンを押す
3. 入力欄の脇に「↳ 続きの質問」チップが出ることを確認する
4. そのまま続けて質問を入力し、送信する

**期待**:
- チップが出た状態で送信すると、直前の回答が引用した資料の中だけに絞って
  検索した回答が返る(本棚全体を広く検索する「入念に調べる」とは違う挙動)
- チップは送信後に消える

**NGだったら**: usage_log に `deep_scope_fallback` が出ていないか確認してください
(スコープ内のヒットが2件未満で無スコープへ自動フォールバックした印です。
これ自体はNGではなく設計どおりの安全側動作ですが、頻発する場合は報告してください)。

### 15. 開いたまま取込: Excelで開いたままの.xlsxと、Acrobat/Edgeで開いたままの.pdfを取り込めること
**なぜ**: 実務では「開いて確認しながら本棚に入れる」が普通に起きます。共有読み
(Shared)でコピーできる限り、開いたままでも取り込めるのが正しい姿です。

**操作**:
1. 適当な .xlsx を Excel で開いたままにする
2. 別の .pdf を Acrobat または Edge で開いたままにする
3. 「📚 マイ本棚」→「📁 追加」から、その2つを取り込む

**期待**:
- どちらも取込が完了する(状態が ✅ / ⏳ になり、⚠️ にならない)
- 開いていたファイルが勝手に閉じない・編集内容が失われない
- カードのメモに「他のアプリで開かれている可能性があります」が出ない

**NGだったら**: err_log の E0302 と、usage_log の `localcopy_fail` の行
(`locked` / `size_mismatch` / `load_fail` のどれか)をメモして報告

---

### 16. スキャンPDF全量: 20ページ超のスキャンPDFが全ページ取り込まれ、部分失敗時はカードに理由が出ること
**なぜ**: OCRは20ページずつのバッチで動きます。2バッチ目以降が落ちても
「取込完了」に見えてしまうと、欠けたページに誰も気付けません。

**操作**:
1. 20ページを超えるスキャンPDF(画像PDF)を1本取り込む
2. 進捗バナーの文字を見る
3. 完了後、本棚カードの状態とメモを見る
4. チャットで「そのPDFの最後のページの内容」を質問する

**期待**:
- バナーは総ページ数が分かるまで「OCR中… 3頁目 (バッチ 1)」のように
  **分母を出さない**。分かってからは「3/44頁 (バッチ 1/3) 残り約○秒」になる
- 最後のページまで取り込まれている(質問に最終ページの内容で答えられる)
- 途中で失敗・時間切れになった場合は、状態が ⏳(partial)になり、カードのメモに
  「読み取りを○頁で中断しました(変換エラーまたは時間切れ)。もう一度取り込むと
  再試行します」が出る(**✅ 完了に見えないこと**が確認点)
- 設定上限で切れた場合のメモは「設定上限○ページのうち先頭○ページを取り込みました」

**NGだったら**: err_log の E0303(`GS_TIMEOUT` / `GS起動失敗` / `b=… 読取失敗`)と、
usage_log の `vision_page_ms` の行数をメモして報告

## 不具合が見つかったら

各項目の説明の「NGだったら」に従い:
1. err_log シートを開く(診断画面 → 下へスクロール)
2. 最新のエラー行を見つけて **「コード」列の値(E0xxx)** をメモ
3. 「detail」列に書かれている詳細情報も一緒にメモ
4. 報告する際は、チェックリストの項目番号 + エラーコード + 詳細 の順で報告するとスムーズです

**例**: 「項目3のPDF取込でE0302が出ました。ファイルは PDF形式で権限もあります」

## 注記

- このチェックリストは「問題がないか確認」が目的です。深掘りの探索ではありません。
- チェック順は意図的に設計されており(初期化→質問→取込→ナレッジ→ダッシュボード→終了)、
  スキップすると隔たりが出る可能性があるため、できるだけ順番に進めてください。
- 各項目で「問題なし」なら「✓」をつけて進めると管理しやすいです。
- ネットワーク接続・共有フォルダが無い環境でも、チェックリスト 1-10 は全て動作します。
- 共有機能を使う場合はヘルプ→共有フォルダ設定で部の共有パスを入力してください
  (未設定なら「みんな」統計は動きません)。
