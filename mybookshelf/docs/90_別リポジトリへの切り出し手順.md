# 「マイ本棚AI」を別リポジトリへ切り出す手順

> このプロダクトは `mybookshelf/` フォルダで**完全に自己完結**するように作られています
> (リポジトリ内の他のフォルダ `src/`, `build/`, `docs/` はV2チャットボットのもので、マイ本棚AIからは一切参照していません)。
> そのため、以下の手順でフォルダごと新しいリポジトリに移せます。

## 方法1: 履歴ごと切り出す(推奨・きれい)

GitHubで新しい空リポジトリ(例: `kojima1459/mybookshelf`)を作ってから、手元のPCで:

```bash
# 1. このリポジトリをクローン
git clone https://github.com/kojima1459/notebook.git
cd notebook

# 2. マイ本棚の開発ブランチに切り替え
git checkout claude/internal-notebook-lm-chatbot-B6BE7

# 3. mybookshelf/ フォルダだけの履歴を持つブランチを作る
git subtree split --prefix=mybookshelf -b mybookshelf-only

# 4. 新リポジトリへ押し込む
git push https://github.com/kojima1459/mybookshelf.git mybookshelf-only:main
```

これで新リポジトリの直下に `src/`, `build/`, `tools/`, `docs/`, `dist/` が来ます。

## 方法2: ファイルだけコピーする(手っ取り早い)

履歴が要らなければ、`mybookshelf/` フォルダの中身を新リポジトリにそのままコピーして
`git add . && git commit` するだけでも動きます(ビルド・テストは全てフォルダ内の相対パスで動くため)。

## 切り出し後の確認(5分)

```bash
# ビルドが通るか
python3 build/build_mybookshelf.py --dev

# 静的チェックが通るか
python3 tools/vba_lint.py

# ロジックテストが通るか(LibreOfficeがある環境のみ)
python3 tools/run_lo_tests.py
```

3つとも成功すれば切り出し完了です。

## 注意

- 旧リポジトリ(notebook)の `mybookshelf/` はその後削除してよいですが、**V2チャットボット側のファイルは消さない**こと。
- この開発ブランチ(`claude/internal-notebook-lm-chatbot-B6BE7`)は main にマージしない方針です
  (マイ本棚AIは別プロダクトのため)。
