# 顧客ペルソナ作成スキル（保険商品向け）

## 目的
新しい保険商品のアイデアについて、「実際に困っているのはどんな人・会社か」を
2〜3種類の具体的な顧客像（ペルソナ）に落とし込み、ニーズの解像度を上げる。

## 大前提（shinshu-hoken-kikakuと共通）
- 実データ・機密情報は使わない。実在の顧客ではなく、合成した典型例として作る。
- 決めつけではなく「＜仮説＞」と明記しながら進めてよい。裏付けとなる調査データが
  あれば使い、なければ一般的に知られている傾向・業界動向から合理的に組み立てる。

## 進め方
1. 対象（保険アイデア）を1〜2行で要約し、認識を合わせる。
2. 想定される顧客層を2〜3パターンに分ける（例：業種別、企業規模別、
   リスクへの感度別など）。
3. 各パターンについて、以下を具体的に描く：
   - **基本像**：業種・企業規模（法人の場合）／年齢層・世帯構成（個人の場合）
   - **一番困っていること（ペイン）**：このリスクに関して今、何が一番の悩みか
   - **今どう対処しているか**：保険に入らず我慢している／自己資金で備えている／
     既存の不十分な商品で妥協している、等
   - **本当に欲しいもの（ゲイン）**：安心の中身は何か（金額の大小だけでなく、
     手続きの速さ、事故時の対応品質なども）
   - **意外な着眼点**：一見ニーズが無さそうでも実は困っている、等の気づき
4. この保険商品が各ペルソナのペインにどう刺さるか（刺さらない場合はそれも正直に）
   を一言評価する。

## 出力の型
- ペルソナ2〜3個、それぞれ上記の型で
- 全体まとめ：どのペルソナが一番刺さりそうか、その理由

## 注意
- 「＜仮説＞」と「実データに基づく事実」を混同しない。
- 本格的に進める際は、実際のヒアリング・アンケートでの検証が必要であることを
  最後に一言添える。
