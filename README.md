# Nexus Agent(旧: マイ本棚AI)

**ポータルで見つけたマニュアルを、読まずに、承認も待たずに、ぶちこんで、すぐ聞ける。**

Excel(.xlsm)1つで動く、社内版NotebookLM。ファイルサーバー申請もIT部門への依頼も不要、自分のPCだけで完結します。

> **リポジトリ構成の注記**: 本リポジトリは`notebook`(V2チャットボット)から
> 分離した独立プロダクトである。旧`mybookshelf/`サブディレクトリの内容は
> このリポジトリのルートへ展開済みで、以降このリポジトリ内で
> `mybookshelf/`プレフィックスは付かない。詳細は
> `docs/90_別リポジトリへの切り出し手順.md`参照。

## 何ができるか

- 📚 PDF・Word・Excel・テキストなどの資料を、フォルダに入れるだけ/ボタンで選ぶだけで取り込める
- 🔍 取り込んだ資料は自動で「AIが読める形(ベクトル化)」に変換される
- ⚡🔍 質問すると2つの速さで回答が選べる(⚡すぐ聞く=10〜20秒 / 🔍しっかり調べる=1〜2分)
- 📖 回答には必ず「どの資料の何ページから」という出典が付く
- 📦 自分の本棚を「パック」として同僚に渡したり、もらったりできる

## 動作要件

- Windows版 Excel(マクロ有効化に加えて、初回起動時に「VBAプロジェクトオブジェクトモデルへのアクセスを信頼する」設定が必須。自己インストール方式のため、この設定が無いと初回起動が必ず失敗します。詳しくは [docs/00_はじめての方へ.md](docs/00_はじめての方へ.md) ステップ2を参照)
- 社内AIリボン「リボンちゃん」(`ChatGPT()` / `GetEmbeddings()`)が入ったExcel
  - リボンが無いPCでも、config の `mock_llm` が TRUE のビルド(開発版)ならダミー応答で全画面の動きを試せます
- Mac版Excelでの完全動作は保証外です(一部のファイル形式が取り込めません)
