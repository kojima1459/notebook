# ⚽ サンガキッズ — 京都サンガ＆サッカー こども応援サイト

サッカーや京都サンガが大すきな子ども（6〜12歳くらい）が楽しめる、モバイル対応のファンメイド応援サイトです。

> 💡 **このサイトのねらい**
> YouTubeでサッカーを見ていると、いつの間にか関係ない“消費系”動画に流れてしまう——
> その**脱線（ジャンク動画への流れ）だけを断つ**のが目的です。サッカーは制限しません。
> 「サッカー専用ゾーン」で動画・ニュース・練習・栄養まで完結させ、**見る → やってみる**へつなげます。

## できること

- 🎬 **サッカー動画（自動・キュレーション不要）** — サッカー専門チャンネル（技・Jリーグハイライト・日本代表など）の最新動画を**自動で再生**。関連動画でジャンクに流れないよう `rel=0` で制御（`shorts.html`）
- 📰 **さいしんニュース（自動）** — 京都サンガ・Jリーグ・海外サッカー・海外組（日本人選手）・速報を **Google ニュースRSSから自動取得**。手動でニュースを選ぶ必要なし（`news.html`）
- 🔥 **れんしゅう＆技** — スター選手の技（シザース／ルーレット／エラシコ等）の step 解説、見本動画さがし、レベル別の週間プログラム（`training.html`）
- 🎯 **毎日チャレンジ＆バッジ** — ミッションをチェックすると連続記録（ストリーク）が貯まる。最高記録・累計日数・ごほうびバッジを `localStorage` に保存
- ⏱️ **すきま時間トレーニング** — 1分〜でできるかんたんメニュー
- 🍙 **つよくなるごはん（栄養）** — 子ども向けに、強い体をつくる食事・水分・睡眠をやさしく解説
- 🎮 **サッカークイズ** — 子ども向けのやさしい7問クイズ。スコアとメダル
- ⭐ **ポジション紹介 / 📅 しあい日程 / 💜 応援メッセージ**

## 子ども向けの工夫（UI/UX）

- 📱 **モバイルファースト / レスポンシブ** — スマホ・タブレット・PC対応
- 🔠 **ひらがな多め・大きなボタン・絵文字** — 低学年でも読める／押しやすい
- 🎉 **達成感の演出** — チェック完了で紙ふぶき、ストリークやバッジで「続けたくなる」設計
- 🧭 **セクションチップス**で長いページもすぐジャンプ
- ☰ ハンバーガーメニュー、♿ `aria` 属性・`prefers-reduced-motion` 対応
- 🧩 依存ライブラリなしの素のHTML/CSS/JavaScript（ビルド不要）

## ファイル構成

```
.

├── shorts.html         # サッカー動画ゾーン（自動・チャンネル再生）
├── news.html           # さいしんニュース（自動取得）＋こども向けサンプル
├── training.html       # れんしゅう・チャレンジ・バッジ・プログラム・すきま時間・栄養
├── quiz.html           # サッカークイズ

│   ├── channels.json   # 動画ゾーンのサッカーチャンネル設定
│   ├── feeds.json      # ニュースの検索キーワード設定
│   ├── news.json       # こども向けサンプルニュース
│   └── shorts.json     # キッズ技あつめ用の動画ID
└── assets/
    ├── css/style.css   # スタイル
    └── js/
        ├── main.js        # ナビ・サンプルニュース表示
        ├── shorts.js      # サッカー動画ゾーン（チャンネル自動再生）
        ├── news-feed.js   # ニュース自動取得（GoogleニュースRSS＋プロキシ）
        ├── training.js    # 技・チャレンジ・バッジ・プログラム
        └── quiz.js        # クイズ
```

## 動かし方

ビルド不要。簡易サーバーで開くと自動取得（JSON / ニュース）も動きます。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## しくみ（保護者の方へ）

### 🎬 サッカー動画
`data/channels.json` の `categories` に、サッカー専門チャンネルの**アップロード再生リスト ID**（`UU…`）を登録しています。
登録チャンネルの動画だけが流れ、サッカー以外のジャンルへ移動しにくくなっています（YouTube `youtube-nocookie` 埋め込み・`rel=0`）。
ながすチャンネルを変えたいときは、このファイルを編集してください（チャンネルIDの `UC…` を `UU…` に置き換えたものが再生リストIDです）。

> ⚠️ 初期登録のチャンネル／動画は一般に公開されているサッカー系チャンネルの例です。視聴は保護者の見まもりのもとでお願いします。

### 📰 ニュース
`data/feeds.json` の `query`（検索キーワード）をもとに **Google ニュースの検索RSS** を取得して表示します。
静的サイトのため取得は公開CORSプロキシ経由で、取得結果はブラウザにキャッシュされます。
通信状況により読み込めない場合は、Jリーグ公式・京都サンガ公式などの本物のニュースサイトへのリンクを表示します。
キーワードを変えれば、表示するニュースを調整できます。

## ご注意

このサイトは **ファンが作った非公式サイト** です。「こども向けニュース」「しあい日程」は **デモ用のサンプル** です。
公式の最新情報は **京都サンガF.C. / Jリーグ 公式サイト** をご確認ください。
「さいしんニュース」「サッカー動画」は外部（Googleニュース／YouTube）のコンテンツへリンク・埋め込みしています。
