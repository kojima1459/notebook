# ⚽ サンガキッズ — 京都サンガ＆サッカー こども応援サイト

サッカーや京都サンガが大すきな子どもが楽しめる、モバイル対応のファンメイド応援サイトです。

## できること

- 🔥 **れんしゅう＆技** — スター選手の技（シザース／ルーレット／エラシコ等）の step 解説と、見本動画さがしリンク、レベル別の週間練習プログラム（`training.html`）
- 🎯 **毎日チャレンジ＆バッジ** — 6つのミッションをチェックすると連続記録（ストリーク）が貯まる。最高記録・累計日数・ごほうびバッジを `localStorage` に保存
- 🎬 **サッカーショート** — サッカー動画だけを**サイト内で**再生（`shorts.html`）。無限スクロールではなく、`data/shorts.json` に登録した動画だけが流れる**保護者がキュレーションする有限リスト**
- 📰 **ニュース** — サッカーやサンガの楽しいできごとを、やさしいことばで紹介（`news.html`）
- 🎮 **サッカークイズ** — 子ども向けのやさしい7問クイズ。スコアとメダルが出ます（`quiz.html`）
- ⭐ **ポジション紹介** — GK / DF / MF / FW をかんたん解説
- 📅 **しあい日程** — 次の試合の見方（サンプル）
- 💜 **応援メッセージ** — みんなで応援しよう！

> 💡 **ねらい**：YouTubeのショート動画を「見るだけ」から、技を覚えて外で**やってみる**へ。
> 毎日チャレンジのストリークで、続ける楽しさ（達成感）をつくります。

## 特長

- 📱 **モバイルファースト / レスポンシブ** — スマホ・タブレット・PCに対応
- ☰ ハンバーガーメニューでスマホでも使いやすいナビゲーション
- ♿ `prefers-reduced-motion` 対応、`aria` 属性など軽いアクセシビリティ配慮
- 🧩 依存ライブラリなしの素のHTML/CSS/JavaScript（ビルド不要）


## 動かし方

ビルド不要です。簡易サーバーで開くと `news.json` も読み込めます。

```bash
# 例：Python の簡易サーバー
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

`index.html` をそのままブラウザで開いても動きます（その場合ニュースは埋め込みデータを使用）。

## ご注意

このサイトは **ファンが作った非公式サイト** です。掲載しているニュースや試合日程は
**デモ用のサンプル** であり、実際の情報ではありません。
公式の最新情報は **京都サンガF.C. 公式サイト** をご確認ください。

### 🎬 ショート動画の管理（保護者の方へ）

`data/shorts.json` の `shorts` 配列を編集すると、サイト内で再生される動画を管理できます。
**ここに登録した動画だけ**が表示され、YouTube のような無限スクロールにはなりません。

```json
{
  "shorts": [
    { "id": "YouTubeの動画ID", "title": "ひょうじ名", "category": "技れんしゅう" }
  ]
}
```

- `id` は YouTube URL（`watch?v=XXXX` や `youtu.be/XXXX`、`/shorts/XXXX`）の `XXXX` 部分です。
- 初期登録されている動画は**サッカーの練習動画の例**です。必ず内容をご確認のうえ、
  お子さまに見せたい動画へ差し替え・追加・削除してください。
- 再生はプライバシー強化モード（`youtube-nocookie.com`）の埋め込みを利用しています。
